A project can hold several repositories, and each task still works in exactly one of them (the app's `docs/architecture.md`, decision D5a).
Settings → Projects lists projects: a project of one repository keeps its row exactly as before, and a project of several is one group in the same list box, where its first repository sat.

**The group's row.**
The closed row names the project in the UI font, then, in quiet mono words, its task key and how many repositories it holds: "Eddie's Wallet  EDW · 2 repositories", with the row's chevron.
It opens in place, like a project row, and draws the same focus ring; Tab reaches it, and Enter or Space opens and closes it.

**Inside the group.**
The first row is the project's Name: an Input and a small secondary Save, with the description "Your project keeps its key EDW and its history.
Each repository keeps its own name."
It names the project alone; renaming a repository never renames a project of several.
Under a hairline, the uppercase micro label "Repositories" heads one row per repository, inset by `--space-4`, each the project row of `Settings → Projects` with today's controls: Where changes go, Ask before merging, Rigor, cost limit, Runs on and Remove.
Those settings stay with each repository, so one repository can take Careful while another takes Default.
The group ends with the Add a repository row.

**Add a repository.**
The row is `AddProject.prompt.md`'s, with the label "Add a repository", the same pills (Folder on this computer, one "{host name} repo" per host, and New repository in place of New project) and no Task key field.
A quiet line under the pills says "A repository added here joins Eddie's Wallet, and its tasks take the task key EDW."
A project of one shows the same row inside its open row, above Remove, so its first second repository can be added from Settings.
Adding says "Added eddies-wallet-backend to Eddie's Wallet.", opens the group and the new repository's row.
The feed line reads "Project Eddie's Wallet · added eddies-wallet-backend".
Scratch and the personal workspace never offer it.

**Words.**
A project's repositories are called repositories wherever a project holds several or can take another: "2 repositories", "Add a repository", "Repositories".
What work, task keys and Tasks belong to is still the project.

**The task record.**
The record's Project fact names the project; in a project of several it adds the repository the task works in: "Eddie's Wallet · eddies-wallet-backend".

**The phone.**
The phone's Projects page draws a project of several as its own list, with the project's name as its section label and its key and count as a caption above its rows; each row opens the repository's page as before.
The phone adds no repository: adding stays on the computer, as adding a project does.

There is no Move to another project: a repository joins another project by being removed and added again.
