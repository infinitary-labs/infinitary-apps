Eine Eingangsrunde ist eine Aufgabe, die liest, was andere in deinem Projekt geschrieben haben, etwa neue Issues und Pull Requests, und für jeden Eintrag entwirft, was zu tun ist.
Du baust sie aus Teilen, die Infinitary schon hat: einer Automatisierung, einem Crewmitglied, das nur liest, und einer Vorgabe in deinen eigenen Worten.
Sie funktioniert für jedes Projekt, das Infinitary dort erreicht, wo es liegt, auf GitHub, GitLab oder Bitbucket.

## Eine Runde nach Zeitplan starten {#start-a-round-on-a-schedule}

1. Öffne die **Einstellungen** und dann **Automatisierung** und wähl **Neue Automatisierung**.
2. Wähl unter **Wann**, wie oft sie läuft.
3. Wähl unter **Projekt** das Projekt, um das es geht.
4. Schreib unter **Sag deinem ersten Offizier** deine Methode: was gelesen wird, wie jeder Eintrag beurteilt wird und wie eine einfache Antwort aussieht.
5. Wähl **Einschalten …**, um sie zu prüfen und einzuschalten.

Zum Beispiel: „Lies mit einem Crewmitglied, das nur liest, die Issues und Pull Requests, die seit der letzten Runde eröffnet oder beantwortet wurden. Entwirf für jeden eine Antwort und starte eine Aufgabe, die jede einfache Antwort postet.“

## Das Crewmitglied, das liest {#the-crewmate-that-reads}

Texte in Issues und Pull Requests können von jedem stammen, darum liest die Runde sie als Crewmitglied, das nur liest.
Es behandelt alles, was es liest, als Information, nie als Anweisung.
Was immer es senden will, wartet auf einer einzigen Genehmigungskarte auf dich, egal was eine Vorgabe sagt.
Siehe [Ein Crewmitglied, das Texte liest, die jeder schreiben kann](/de/integrations/#a-crewmate-that-reads-words-anyone-can-write).

## Einfache Antworten ohne deinen Klick gehen lassen {#let-plain-replies-go-without-your-click}

Eine Antwort kann ohne Karte hinausgehen, wenn du in deinen eigenen Worten gesagt hast, dass sie das darf.

1. Sag deinem ersten Offizier eine Vorgabe für das Projekt, die sagt, welche Antworten ohne Rückfrage gehen dürfen.
   Zum Beispiel: „Sendeaufgaben der Eingangsrunde dürfen Antworten posten, die eindeutig unserer Eingangsmethode folgen, und sonst nichts; alles Seltsame oder Unklare wartet auf meinen Klick.“
2. Bitte deinen ersten Offizier in deiner Methode, für jede entworfene Antwort eine eigene Aufgabe zu starten, die sie postet und keinen Text der Fremden liest.
3. Ist eine Antwort eindeutig eine, die deine Vorgabe abdeckt, postet das Crewmitglied dieser Aufgabe sie einmal, ohne Karte, und nennt dabei deine Vorgabe.
   Eine Antwort, die es seltsam findet oder die deine Vorgabe nicht abdeckt, wartet auf einer Karte auf deinen Klick.

Infinitary prüft nur, dass deine Vorgabe noch gilt: Ihr aktueller Wortlaut wurde von dir gehört, und sie ist nicht zurückgezogen.
Ob eine Antwort eine ist, die deine Worte erlauben, beurteilt dein Crewmitglied.
Ein Ja, das du schon auf einer Karte für dieselbe Arbeit gegeben hast, lässt eine Antwort auf dieselbe Weise gehen.
Siehe [Wer einer Vorgabe folgt](/de/knowledge/#who-follows-a-direction).

## Was weiter auf dich wartet {#what-still-waits-for-you}

- Alles, was das Crewmitglied, das liest, selbst sendet, egal was eine Vorgabe sagt.
- Eine Änderung über eine Integration, die ihre Regel unter **Einstellungen** → **Integrationen** behält.
- Eine Änderung an einem anderen Projekt.
  Eine Aufgabe ohne Projekt auf GitHub, GitLab oder Bitbucket arbeitet stattdessen über deine Anmeldung bei GitHub, und dort kann ein Ja von dir eine Änderung an jedes Repository gehen lassen.
- Ein Zusammenführen, das nur über seine Karte zum Zusammenführen geht.

## Sehen, was hinausging {#see-what-went-out}

Jede ohne Karte gepostete Antwort fügt der **Aktivität** ihrer Aufgabe eine Zeile hinzu, die deine Worte zitiert, auf die sie sich stützte.
Eine Antwort, deren Ergebnis unbekannt ist, wird nie wieder gesendet; lies den Eintrag dort, wo dein Projekt liegt, um zu sehen, ob sie angekommen ist.

## Anhalten {#stop-it}

Damit Antworten nicht mehr von selbst hinausgehen, sag deinem ersten Offizier, dass er die Vorgabe zurückziehen oder ändern soll.
Von da an wartet jede Antwort wieder auf deinen Klick.
Um die Runde selbst anzuhalten, wähl bei ihrer Automatisierung unter **Einstellungen** → **Automatisierung** **Pausieren**.
