## Eine Frage stellen oder ein Problem melden {#ask-a-question-or-report-a-problem}

- Tritt unserem [Discord-Server](https://discord.gg/Wsy2NpnZDu) bei und frag dort.
- Oder schreib an [help@getinfinitary.com](mailto:help@getinfinitary.com).

Schreib, was du getan hast, was du erwartet hast und was stattdessen passiert ist.
Ein Bild vom Fenster hilft.

## Feedback aus der App senden {#send-feedback-from-the-app}

Du kannst dem Macher von Infinitary ein Problem oder eine Idee mitteilen, ohne die App zu verlassen.

1. Schreib `/feedback` und ein paar Worte in irgendein Nachrichtenfeld und sende es ab.
   Auch **Feedback senden …** im Menü „Hilfe“ und **Feedback senden** in der Befehlssuche starten es.
2. Ein Crewmitglied entwirft ein Issue für das öffentliche Projekt von Infinitary auf GitHub und bringt dir eine Karte.
   Die Karte zeigt das genaue Issue.
3. Lies es, dann drück **Feedback absenden**.

Dein Klick veröffentlicht das Issue einmal, öffentlich, unter deinem eigenen GitHub-Konto.
Vor diesem Klick wird nichts veröffentlicht.
Hat Infinitary keine GitHub-Anmeldung, gibt dir die Karte stattdessen einen Link.
Er öffnet das Issue-Formular von GitHub mit dem ausgefüllten Bericht, damit du ihn dort veröffentlichst.

Der Bericht lässt deine Namen, Ordner, Projekte und Anmeldungen weg.
Siehe [Was deinen Computer verlässt](/de/what-leaves-your-computer/#feedback-you-send).

## Eine Sicherheitslücke melden {#report-a-security-issue}

Schreib privat an [help@getinfinitary.com](mailto:help@getinfinitary.com).
Bitte poste eine Sicherheitslücke nicht auf Discord.
