## Ask a question or report a problem

- Join our [Discord server](https://discord.gg/Wsy2NpnZDu) and ask there.
- Or write to [help@getinfinitary.com](mailto:help@getinfinitary.com).

Say what you did, what you expected, and what happened instead.
A picture of the window helps.

## Send feedback from the app

You can tell Infinitary's maker about a problem or an idea without leaving the app.

1. Type `/feedback` and a few words in any message box, and send it.
   **Send Feedback…** in the Help menu and **Send feedback** in command search start it too.
2. A crewmate drafts an issue for Infinitary's public project on GitHub, and brings you a card.
   The card shows the exact issue.
3. Read it, then press **Submit feedback**.

Your click publishes the issue once, publicly, under your own GitHub account.
Nothing is published before that click.
If Infinitary has no GitHub sign-in, the card gives you a link instead.
It opens GitHub's issue form with the report filled in, for you to publish there.

The report leaves out your names, folders, projects and sign-ins.
See [What leaves your computer](/what-leaves-your-computer/#feedback-you-send).

## Report a security issue

Write privately to [help@getinfinitary.com](mailto:help@getinfinitary.com).
Please do not post a security issue on Discord.
