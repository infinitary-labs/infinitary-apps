## Ask a question or report a problem

- Join our [Discord server](https://discord.gg/Wsy2NpnZDu) and ask there.
- Or write to [help@getinfinitary.com](mailto:help@getinfinitary.com).

Say what you did, what you expected, and what happened instead.
A picture of the window helps.

## Report a security issue

Write privately to [help@getinfinitary.com](mailto:help@getinfinitary.com).
Please do not post a security issue on Discord.
