始める前に、[必要なもの](/ja/install/)を確認してください。
このページでは、Infinitary を初めて開いたときの流れと、その後に変わることを説明します。

## ウインドウに表示されるもの {#what-the-window-shows}

Infinitary を初めて開くと、ウインドウの中央で一等航海士があいさつします。
その上には **Infinitary へようこそ、船長** と表示され、一等航海士からのひと言が添えられています。

> 私はあなたの一等航海士です。
> ほかの乗組員の管理をお手伝いします。
> できるだけ電源が入ったままのコンピューターで私を準備してください。
> ほかのデバイスからは、私が起きている必要があります。

その下には、一等航海士が使える各プロバイダーのボタンがあります：Codex、Grok、Claude、Kimi Code、Copilot、OpenRouter、Amazon Bedrock、カスタム API です。

下部のメッセージ欄は薄く表示され、「先にサブスクリプションを接続してください」と書かれています。
サブスクリプションが一等航海士に応答できるようになるまで、ほかには何も使えません。

## サブスクリプションを接続する {#connect-a-subscription}

1. プロバイダーのボタンを選びます。
2. そのプロバイダーの求める方法でサインインします。
   ブラウザでサインインページを開くものもあります。
   Copilot と Kimi Code ではコードが表示されるので、**コードをコピー** を押してから、プロバイダーのサイトで入力します。
   OpenRouter では、API キーを貼り付けます。
   Amazon Bedrock では、リージョンを選び、このコンピューターの AWS プロファイルを使うか、Bedrock の API キーを貼り付けます。
   両方の方法があるプロバイダーでは、**ブラウザでサインイン** するか **API キー** を貼り付けるかを尋ねられます。
3. ウインドウに接続中と表示されている間、待ちます。
   サブスクリプションが応答できるようになると、ようこそ画面が消えてメッセージ欄が使えるようになります。

Claude を使う場合、Infinitary はこのコンピューターにインストールされている Claude Code を使います。
Claude Code がないと、Claude のボタンに、先に Claude Code をインストールするよう表示されます。

サブスクリプションを接続しても応答できない場合は、ウインドウに **このコンピューターで一等航海士を準備** と表示され、まだ足りないものが示されます。

## 一等航海士がすでに別のコンピューターにいる場合 {#if-your-first-mate-already-lives-on-another-computer}

プロバイダーのボタンの下には、「一等航海士は別のコンピューターにいます」という 2 つ目のグループがあります。
Mac または x64 の Linux コンピューターでは **一等航海士のコンピューターから設定する** が最初にあり、一等航海士がいるコンピューターで入力する、このコンピューターのアドレスが表示されます。
そのコンピューターがこのコンピューターを追加すると、サインインやプロジェクトなど、このウインドウでまだ何も設定していなければ、このウインドウが自動で一等航海士を開きます。
すでに何かを設定したウインドウは自分の一等航海士のままなので、代わりに **リンクを貼り付ける** または **アドレスで参加** を使って、その一等航海士をここから操作します。
そのコンピューターがこのコンピューターを追加したときに Infinitary が閉じていた場合は、何を設定していても、次に起動したときに一等航海士を開きます。
「ターミナル」から自分で起動した Infinitary の横にあるウインドウはその Infinitary の一等航海士のままでどちらの方法も表示されないため、使うには先にその Infinitary を停止します。
Windows PC と Arm の Linux コンピューターには、ほかの 2 つの方法だけが表示されます。
[ほかのコンピューター](/ja/your-other-computers/)を参照してください。

## 診断のお知らせ {#the-diagnostics-notice}

メッセージ欄の下のお知らせには、診断で何が送られるかと、入力した内容は決して含まれないことが書かれています。
オンのままにするには **OK** を、やめるには **オフにする** を選びます。
あとで[設定](/ja/settings/#general)で変更できます。
[コンピューターの外に出るもの](/ja/what-leaves-your-computer/)を参照してください。

## ようこそカード {#the-welcome-card}

一等航海士が応答できるようになると、**私たちの進め方** という題のカードが表示されます。
ウインドウを小さく描いた図で、一度に 1 つの部分を示します。
**次へ** と **戻る** を押すと、メッセージ欄、カード、左のアクティビティ、右のタスクを順に見られます。

図の下には 3 つの書き出しがあります。

- **プロジェクトをクローン**
- **新しいプロジェクトを始める**
- **手元のコンピューターのフォルダで作業**

1 つを押すと、「次の場所にあるプロジェクトをクローンしてください：」のような文の書き出しがメッセージ欄に入ります。
文を書き終えて送信します。
書き出しだけでは何も送信されません。

ようこそカードには返信欄がありません。入力するのは、その下のメッセージ欄です。
カードはいつでも閉じられます。

## 最初のプロジェクトを追加する {#add-your-first-project}

一等航海士が作業するには、プロジェクトが必要です。
いちばん簡単なのは、ようこそカードの書き出しを使うか、同じ内容を自分のメッセージで伝えることです。

頼むと、一等航海士はプロジェクトの名前と準備の方法を示したカードを表示します。
カードの選択内容を確認し、**プロジェクトを追加** を押します。やめる場合は **今はしない** を押します。
**プロジェクトを追加** を押すまで、何も追加されません。

設定 → プロジェクトの **プロジェクトを追加** で、自分でプロジェクトを追加することもできます。
そこでの選択肢については、[プロジェクト](/ja/projects/)を参照してください。

## 2 回目以降の起動 {#later-launches}

サブスクリプションが応答できる状態なら、Infinitary はすぐにメッセージ欄を開きます。
カード、タスク、乗組員は、前回のままです。

Infinitary がアップデートされると、新しいバージョンと変更点を示すカードが表示されます。
あとで[設定 → 一般](/ja/settings/#general)のバージョンからもう一度読めます。
Mac では、「ヘルプ」メニューの **Infinitary の新機能** からも開けます。

サインアウトしたなどの理由で最後のサブスクリプションが使えなくなると、どれかが再び応答できるようになるまで、ようこそ画面が戻ってきます。
プランの利用枠がなくなった場合は、代わりに一等航海士がそれを伝えるカードを表示し、応答できるようになるまでメッセージを保持します。
[サブスクリプションと利用枠](/ja/subscriptions-and-quota/)を参照してください。

コンピューターにサインインしたときに Infinitary を開くには、設定 → 一般で **サインイン時に起動** をオンにします。
