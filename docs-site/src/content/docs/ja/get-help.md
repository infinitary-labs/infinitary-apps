## 質問する、問題を報告する {#ask-a-question-or-report-a-problem}

- [Discord サーバー](https://discord.gg/Wsy2NpnZDu)に参加して、そこで質問してください。
- または、[help@getinfinitary.com](mailto:help@getinfinitary.com) にご連絡ください。

何をしたか、何を期待していたか、実際には何が起きたかを書いてください。
ウインドウの画像があると助かります。

## セキュリティ上の問題を報告する {#report-a-security-issue}

[help@getinfinitary.com](mailto:help@getinfinitary.com) に非公開でご連絡ください。
セキュリティ上の問題は Discord に投稿しないでください。
