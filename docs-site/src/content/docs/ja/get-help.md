## 質問する、問題を報告する {#ask-a-question-or-report-a-problem}

- [Discord サーバー](https://discord.gg/Wsy2NpnZDu)に参加して、そこで質問してください。
- または、[help@getinfinitary.com](mailto:help@getinfinitary.com) にご連絡ください。

何をしたか、何を期待していたか、実際には何が起きたかを書いてください。
ウインドウの画像があると助かります。

## アプリからフィードバックを送る {#send-feedback-from-the-app}

アプリを離れずに、Infinitary の開発者に問題やアイデアを伝えられます。

1. どのメッセージ欄でも、`/feedback` に続けて短い説明を入力して送信します。
   「ヘルプ」メニューの **フィードバックを送信…** や、コマンド検索の **フィードバックを送信** からも始められます。
2. 乗組員が、GitHub にある Infinitary の公開プロジェクト向けの Issue を下書きし、カードを届けます。
   カードには、Issue の内容がそのまま表示されます。
3. 読んでから、**フィードバックを送信** を押します。

あなたのクリックで、Issue はあなた自身の GitHub アカウントで、一度だけ公開されます。
クリックするまでは、何も公開されません。
Infinitary に GitHub のサインインがない場合、カードには代わりにリンクが表示されます。
リンクを開くと、報告が入力済みの GitHub の Issue フォームが開き、そこであなたが公開できます。

報告には、あなたの名前、フォルダ、プロジェクト、サインインは含まれません。
[コンピューターから送られるもの](/ja/what-leaves-your-computer/#feedback-you-send)を参照してください。

## セキュリティ上の問題を報告する {#report-a-security-issue}

[help@getinfinitary.com](mailto:help@getinfinitary.com) に非公開でご連絡ください。
セキュリティ上の問題は Discord に投稿しないでください。
