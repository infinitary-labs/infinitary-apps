iPhone と iPad 版の Infinitary には、コンピューターにいる一等航海士が表示されます。
一等航海士、そのタスク、タスクの作業はコンピューターに残ります。
スマートフォンには一等航海士のカード、タスク、アクティビティが表示され、メッセージや回答はスマートフォンからコンピューターへ送られます。

iOS 18 以降が必要です。

## 入手する {#getting-it}

iPhone と iPad 版の Infinitary は、TestFlight で非公開に提供しています。
[help@getinfinitary.com にメールして招待を申し込む](mailto:help@getinfinitary.com?subject=Infinitary%20TestFlight%20request)。

## コンピューターに接続する {#join-your-computer}

1. コンピューターで設定 → **デバイス** を開き、**+ スマートフォン** を押します。
   スキャン用のコードが表示され、その横にリンクが表示されます。
2. スマートフォンで Infinitary を開きます。
   **コードをスキャン**、**リンクを貼り付け**、**アドレスで接続** の 3 つの方法が表示されます。
3. **コードをスキャン** を選び、カメラをコンピューターのコードに向けます。
4. コンピューターの名前を確認し、その名前の入った **〜に接続** を押します。

コードは 1 回だけ、10 分間使えます。
カメラが許可されていない場合は、代わりにリンクを貼り付けます。
**アドレスで接続** では、コンピューターで「リモートログイン」がオンになっていれば、そのコンピューターに SSH で接続するときのアドレス（例：`you@studio.local`）を使えます。

スマートフォンとコンピューターは、同じネットワークにある必要があります。同じ Wi-Fi か、外出先では同じプライベートネットワークです。
接続するのは自分のコンピューターだけにしてください。

## 表示される内容 {#what-it-shows}

上部のバーには **ホーム**、**タスク**、**アクティビティ** があります。

- **ホーム** にはカードが 1 枚ずつ表示されます。スワイプすると次のカードに移ります。
  カードには、コンピューターと同じようにスマートフォンで回答できます。
- **タスク** には、**あなた待ち**、**作業中**、**待機中** など、コンピューターと同じグループでタスクが一覧表示されます。
  タスクをタップするとそのカードや記録が開き、そこでタスクを開始したり続けたりできます。
- **アクティビティ** には、起きたことが新しいものほど下に表示されます。

パネルがオンのときは、4 つ目のタブ **パネル** に、パネルが縦に並んで表示されます。

## 開いた折りたたみ式 iPhone でカードを読む {#read-a-card-on-an-open-foldable-iphone}

設定 → 外観 で **折り目で分ける** をオンにしていると、カードを読んでいる間は Infinitary がサイドのパネルをたたみ、カードに広く場所を取ります。
設定の横にある **パネルを表示** で「タスク」「アクティビティ」とあなたのパネルを戻し、**パネルをたたむ** でカードに戻ります。
表示したパネルは、新しいカードが届いても開いたままです。
入力中にパネルが自動でたたまれそうなときは、キーボードが閉じるまで Infinitary が待ちます。
カードが開いていないときは、パネルが表示されます。
カードに触れると最後の返信が隠れ、メッセージ欄をタップするとまた表示されます。
カードの隅にある **カードを最大化** を使うと、メッセージ欄も隠れます。

横向きの iPad では、カードにもっと場所が必要な場合を除き、サイドバーは表示されたままです。
カードを脇に置くと、次のカードが収まる場合やカードが開いていない場合に、サイドバーが戻ります。
ウインドウが十分に広くなったときにも戻ります。

## 一等航海士と話す {#talk-to-your-first-mate}

メッセージ欄は **ホーム** の下部にあります。
入力するか、キーボード自体の音声入力を使い、ライブラリから写真を添付できます。
最近のメッセージと一等航海士の返信は、メッセージ欄の上に表示されます。

## スマートフォンの設定 {#settings-on-the-phone}

スマートフォンの設定には、コンピューターの **プロジェクト**、**インテリジェンス**、**ランブック**、**使用量**、**自動化** が、コンピューターと同じ言葉で表示されます。
コンピューターにアップデートの準備ができているときは、先に確認したうえで、スマートフォンからアップデートを開始できます。
[Infinitary のアップデートと削除](/ja/update-and-remove/#your-other-computers-and-your-phone)を参照してください。

## コンピューターと連絡がつかないとき {#when-your-computer-is-out-of-reach}

スマートフォンを使うには、コンピューターがスリープしておらず、Infinitary が開いている必要があります。
連絡がつかない場合は、「コンピューターと連絡がつきません。Infinitary が開いていて、両方のデバイスが同じネットワークにあることを確認してください。」と表示されます。

スマートフォンが新しいカードを知らせるのは、アプリが開いている間だけです。

## 離脱または削除 {#leave-or-remove}

コンピューターの表示をやめるには、スマートフォンの上部バーの右にあるコンピューターのボタンをタップし、コンピューターの名前の入った **離脱** を選びます。
スマートフォンはそのコンピューターの登録を解除します。
コンピューター側では、設定 → **デバイス** のスマートフォンのメニュー（行の右にある 3 つの点）で **削除** を選ぶと、すぐに切り離されます。
もう一度接続するには、新しいリンクを作ります。

[ほかのコンピューター](/ja/your-other-computers/)も参照してください。
