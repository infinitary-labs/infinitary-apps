ランブックは、変更の計画、レッスンの進め方、コミットの名付け方など、作業の種類ごとに一等航海士と乗組員が従う手引きです。
言葉、例、画像でできていて、コンピューター上で何かを実行することはありません。
Infinitary には最初からいくつかのランブックが入っていて、自分で作ったり追加したりすることもできます。

## ランブックの場所 {#where-runbooks-live}

**設定** を開き、**ランブック** を選びます。
コマンド検索で **ランブックを開く** を検索することもできます。

このセクションには 3 つのグループがあります。

- **組み込み** には、Infinitary に最初から入っているランブックが並びます。
- **あなたのランブック** には、あなたが追加したランブックや、一等航海士と一緒に作ったランブックが並びます。
- **自分で作る** には、**ランブックのフォルダ** と、頼み方の例があります。

各行には、ランブックの名前、用途、スイッチが表示されます。

## ランブックをオン・オフする {#turn-a-runbook-on-or-off}

ランブックのスイッチでオンとオフを切り替えます。
「レッスンをオフにして」のように一等航海士に頼むこともできます。

一等航海士は、今している作業を終えたところで変更に従います。そのあとに始まる乗組員も同じです。
すでに作業中の乗組員は、始めたときの手引きのまま作業を続けます。

オフのランブックは誰の指針にもなりませんが、一覧には残るので、またオンにできます。

## 組み込みのランブック {#the-built-in-runbooks}

組み込みのランブックのほとんどは、最初からオンになっています。
**一括プルリクエスト**、**プルリクエストのコメント**、**ハートビート**、**高度なアーキテクチャ** の 4 つは、オンにするまでオフのままです。

- **一般的なワークフロー**：一等航海士が計画、作成、修正、調査にどう取り組むか。
- **届け方の判断**：プルリクエストを通る作業で、乗組員がチェックや修正をどう判断し、いつ変更をマージできる状態とみなすか。
- **テストのルール**：乗組員がプロジェクトを計画したり変更したりするときに、何をテストするか。
- **慎重さのレベル**：**クイック**、**標準**、**慎重** の各レベルが変更に何を求めるか。
  [慎重さ](/ja/tasks-and-crewmates/#rigor)を参照してください。
- **コミットと PR の命名**：コミット、プルリクエスト、作業ブランチの名前の付け方。
  これがオフで、名前の付け方を決めたあなたのランブックもない場合、Infinitary は名前をチェックしません。
- **プログラム**：スクリプトで分けられる作業では、乗組員が短いスクリプトを書き、各パートをそれぞれ独立したタスクとして登録します。
- **気軽なプロジェクト**：趣味や個人で使う小さなプロジェクトを、一等航海士がどう準備するか。
  [頼めること](/ja/what-you-can-ask-for/#a-small-project-for-fun)を参照してください。
- **レッスン**：何日もかけて 1 つのテーマを学ぶための手引きとカードのパーツ。
  [頼めること](/ja/what-you-can-ask-for/#a-subject-learned-across-days)を参照してください。
- **一括プルリクエスト**：承認した変更をまとめて 1 つの一括プルリクエストとしてマージし、チェックを 1 回で済ませます。
  オンにすると、設定 → **プロジェクト** で、プロジェクトの届け方に一括プルリクエストを選べるようになります。
  [プロジェクト](/ja/projects/#how-changes-reach-your-project)を参照してください。
- **プルリクエストのコメント**：乗組員が、自分のプルリクエストがマージされるまで、そこに付いたコメントに対応します。
  明らかな修正は自分で行い、はっきりしないものは選択肢としてあなたに持ってきます。
- **ハートビート**：知らせるものがないまま作業が待ち始めたときや、静かな時間が長く続いたあとに、一等航海士が待っている作業を見直し、先に進めるか、あなたに一度だけ尋ねます。
  設定 → **自動化** で一時停止できる自動化を追加し、ランブックをオフにするとその自動化はなくなります。
- **コンピューターの片付け**：あなたの同意を得てから読み取るだけの調査を行い、どの残りものを停止するかを選ぶカードを表示します。
  [頼めること](/ja/what-you-can-ask-for/#a-look-at-a-computer-under-strain)を参照してください。
- **シークレットの移行**：どのエージェントにも値を見せずに、乗組員がほかのツールから **シークレット** へシークレットを移す方法。
  乗組員がこれを読むのは、その移行の間だけです。
  [シークレット](/ja/secrets/)を参照してください。
- **フィードバック**：どのメッセージ欄でも `/feedback` と数語を入力すると、クルーが Infinitary の開発者向けの Issue を下書きし、あなたが読んで自分で公開します。
  アプリとシステムについての事実を含み、あなたの名前、パス、プロジェクトは含みません。
- **高度なアーキテクチャ**：プロジェクトの各部分とそのつながりを図にし、変更がその図の上で何を動かすかを示します。
  これは試験的な機能です。

一括プルリクエストを使っているプロジェクトがある間、Infinitary は **一括プルリクエスト** をオフにできないようにし、そのプロジェクトの名前を示します。

## ランブックを読む {#read-a-runbook}

組み込みのランブックの横にある **表示** を押します。
コンピューター上で、そのランブックのフォルダの読み取り専用のコピーが開きます。
組み込みのランブックの動きを変えたいときは、下で説明するように、一等航海士に頼んで自分のものにします。

## 自分で作る {#make-your-own}

あなた自身の言葉で一等航海士に頼みます。
設定の **自分で作る** には、次のような例があります。

- 「リリースノートをわかりやすい言葉で書くスキルを、すべての乗組員に持たせて。」
- 「私は短い回答が好きだと一等航海士に伝えるランブックを作って。」

乗組員が、新しいランブックを **ランブックのフォルダ** に書きます。
そのランブックは **あなたのランブック** に表示され、オフで始めるよう頼んでいない限り、すぐにオンになります。

**フォルダを開く** を押すと、コンピューター上で **ランブックのフォルダ** が開きます。
そこでランブックを変更すると、スイッチを切り替えたときと同じように、一等航海士と乗組員に反映されます。

## 組み込みのランブックを自分のものにする {#make-a-built-in-runbook-yours}

「一般的なワークフローをコピーして、作る前に必ず計画するようにして」のように、組み込みのランブックのコピーを一等航海士に頼みます。

1. 一等航海士が、ランブック全体を新しい名前で **ランブックのフォルダ** にコピーします。
2. コピーは **あなたのランブック** に表示され、オフで始まるので、まだ何も変わりません。
3. コピーを自分で変更するか、一等航海士に変更を頼みます。
4. コピーをオンにします。
   同時に、組み込みのほうはオフになります。

組み込みのランブック自体は元のままです。
元に戻すには、コピーをオフにして、組み込みのほうをオンにします。

## 共有されたランブックを追加する {#add-a-runbook-someone-shared}

「誰かが共有してくれた Web アドレスかフォルダにあるランブックを追加して」のように、Web アドレスやフォルダからランブックを追加するよう一等航海士に頼みます。

「リリースノートを追加しますか？」のように、ランブックの名前をタイトルにしたカードに答えるまで、何も追加されません。
カードには、ランブックの出どころ、作った人、アクセスする範囲、オフになる組み込みのランブックがあればその名前が示されます。

- **追加** を押すと、ランブックが追加されてオンになります。
- **追加しない** を押すと、追加を断り、取得したものが削除されます。

カードを後回しにしている間、追加の提案はそのまま待っています。
追加したランブックが更新されたときも、同じ種類のカードで改めて確認されます。

追加したランブックを削除するには、名前を挙げて削除を一等航海士に頼みます。
そのランブックによってオフになった組み込みのランブックは、あなたが再びオンにするまでオフのままです。

**あなたのランブック** にあるランブックを Infinitary が読み取れない場合は、スイッチの代わりにその理由が表示され、直るまで誰の指針にもなりません。

## 別のコンピューターから {#from-another-computer}

別の場所から一等航海士を操作しているコンピューターでは、スイッチを切り替えると、一等航海士がいるコンピューターのランブックが変わります。
**表示** と **フォルダを開く** はそのコンピューターでしか使えず、フォルダの行にそのコンピューターの名前が表示されます。
[ほかのコンピューター](/ja/your-other-computers/)を参照してください。

## キーボードを使う {#use-the-keyboard}

Tab キーで、各 **表示** ボタンとスイッチに移動できます。
コマンド検索には **ランブックを開く** と **ランブックのフォルダを開く** があり、どちらにも設定 → **キーボード** でキーを割り当てられます。
[キーボード](/ja/keyboard/)を参照してください。
