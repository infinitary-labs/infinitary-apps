一等航海士と乗組員は、すでに契約している AI サブスクリプションを通じて作業します。
サブスクリプションは、設定の **インテリジェンス** にある **AI サブスクリプション** の一覧で管理します。

## サブスクリプションを追加する {#add-a-subscription}

1. 設定を開き、**インテリジェンス** を選びます。
2. **AI サブスクリプション** のいちばん下の **アカウントを追加** で、プロバイダーを選びます：Codex、Grok、Claude、Kimi Code、Copilot、OpenRouter、Amazon Bedrock のいずれかです。
3. プロバイダーの求める方法でサインインします。
   ブラウザが開くもの、サイトで入力するコードが表示されるもの、キーを貼り付けるものがあります。
4. サインインが終わると、新しいアカウントが一覧に表示されます。

同じプロバイダーのアカウントを複数追加できます。
そのときボタンは、たとえば **Codex アカウントをもう1つ追加** となります。

## アカウントに名前を付ける {#name-your-accounts}

各アカウントにはラベルがあるので、個人用と仕事用のアカウントを見分けられます。
サインインでアカウント名がわからない場合は、名前を入力する欄が開きます。
あとで変えるには、アカウントのメニューを開いて **名前を変更** を選びます。

Claude アカウントは扱いが異なります。
コンピューター上の Claude Code のサインインに従うため、その行には今そこでサインインしている人が表示されます。
**名前を変更** はなく、Claude Code のサインインを切り替えると、行もそれに合わせて変わります。

各アカウントには、プロバイダーが設けている利用枠ごとに小さなメーターが表示されます（例：セッションごと、週ごと）。
数字は残りの量です。
メーターにポインタを合わせると、いつリセットされるかがわかります。

- 時間に対して使いすぎているとき、つまりリセットまで均等に使うペースより速く使っているときは、バーが琥珀色になります。
- 数字は半分を切ると琥珀色に、5 分の 1 を切ると赤になります。
- メーターの横には、アカウントの状態を一言で表す言葉が表示されます：**ペースどおり**、「〜で使い切り」と時間、または **使い切りました** です。
- **3時間前の時点** は最後の読み取りが古いことを表し、その数字は薄く表示されます。
- ダッシュは、その利用枠が読み取られなかったことを表します。

一覧の上部にある **更新** を押すと、すべての利用枠をもう一度読み取ります。
OpenRouter とカスタム API の利用枠は Infinitary が読み取らず、行にもそう表示されます。
Amazon Bedrock は AWS アカウントで使用量に応じて請求されます。その行には、Infinitary が記録した作業から推定した今月の金額が表示されます。

## どのアカウントに何をさせるか選ぶ {#choose-which-account-does-what}

アカウントの行にある 3 つの点を押してメニューを開くと、次の項目を選べます。
設定項目が先頭に並び、それぞれのスイッチでオンかオフかがわかります。
選ぶとオンとオフが切り替わり、メニューは開いたままです。

- **乗組員の作業で優先** を選ぶと、乗組員はこのアカウントを最初に使います。
  このアカウントには ✱ が付きます。
- **一時停止中** のスイッチがオンのあいだ、このアカウントでの作業はすべて止まります。
- **接続を解除** を選ぶと、アカウントが Infinitary から外れます。

一等航海士が使うプロバイダーのアカウントが 2 つ以上あるときは、一等航海士がどのアカウントで応答するかを設定で選べます。
そのアカウントには **航海士** のタグが付きます。

## 利用枠がなくなったとき {#when-an-allowance-runs-out}

乗組員は自分で次へ進みます。
新しい作業は、利用枠の残っているモデルに回されます。
そのレベルに残っているモデルがなければ、乗組員の作業はより弱いモデルに移るか、利用枠がリセットされるまで待ちます。

一等航海士自身のアカウントの利用枠がなくなると、まず同じプロバイダーでまだ残りのある別のアカウントに移ります。
そうしたアカウントがなければ、カードに「一等航海士が利用枠を使い切りました」と表示されます。
入力した言葉は待機し、何も失われません。
カードでは、**利用枠を再確認** を選ぶか、一等航海士を別のプロバイダーに移すか、**設定を開く** を選べます。
再確認で何も変わっていなければ、カードはプロバイダーをもう一度試す選択肢（**Try Claude again** など）も表示します。一等航海士が別のサインインでプロバイダーに届く場合のためのもので、利用枠がまだ使い切られていれば、再び一時停止します。

プロバイダーによっては、そこで用意したクレジットで応答を続けられます。
Claude または Codex のアカウントでは、メニューに **クレジットで続ける** があります。
その場合、乗組員がクレジットを使うのは、プランに含まれる利用枠をすべて使い切ったあとだけです。
Infinitary がクレジットを購入したり、その上限を設定したりすることはありません。それはプロバイダー自身のサイトで行います。

## もう一度サインインする {#sign-in-again}

サインインは期限切れになることがあります。
そのときは、アカウントの行に **もう一度サインイン** と表示され、**サインイン** ボタンが現れます。
ボタンを押し、最初と同じ方法でサインインします。
これで同じアカウントが更新され、ラベルと選んだ設定はそのまま残ります。

## カスタム API {#custom-api}

組織が独自の AI サーバーを運用している場合は、**アカウントを追加** の下で **カスタム API** を選びます。
名前、サーバーのアドレス、必要ならキー、使うモデルを入力します。
**保存** を押すと、乗組員が使えるようになる前に各モデルが確認されます。
そのあと、乗組員がこれらのモデルを使うかどうかを **モデル** ボードで選びます。

## 使用量 {#usage}

設定 → **使用量** には、すべてのプロジェクトで一等航海士と乗組員がどれだけ使ったかが表示されます。
**トークン** または **推定 $** で、**期間** と **作業** の種類ごとに表示できます。
推定の金額は価値の目安であり、請求額ではありません。
**最近のタスク** には、各タスクが使った量が一覧表示されます。

**インテリジェンス** の **タスクがこの金額を超えて使う前に確認** で金額を設定できます。
その金額を超えたタスクは安全なところで止まり、さらに使う前にカードであなたに確認します。
