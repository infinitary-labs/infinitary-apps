乗組員は、タスクのために専用のブラウザを持てます。
Web サイトやプロジェクトが提供するページを開き、読み、クリックや入力をし、タスクの記録用にスクリーンショットを撮ります。
作業の様子を見守り、ページに人の手が必要なときは操作を引き継ぎ、終わったら戻せます。
購入、予約など、あなたが責任を負うことになる操作は、常にあなた自身が行います。

## タスク専用のブラウザ {#a-tasks-own-browser}

ブラウザはタスクが実行されるコンピューターで動き、そのタスク 1 つだけのものです。
何も入っておらず、どこにもサインインしていない状態で始まり、あなた自身のブラウザとは切り離されているので、あなたのブラウザのサインイン、履歴、保存されたパスワードを使うことはありません。
そのコンピューターに Google Chrome または Microsoft Edge がインストールされている場合、タスクのブラウザはそれを使って同じように切り離された状態で動きます。どちらもない場合は Infinitary 自身のブラウザを使います。
ページが何を求めても、あなた自身のブラウザやほかのアプリで開かれることはありません。

乗組員のブラウザが開けるのは次のものです。

- https で接続する公開 Web サイト。
- 同じコンピューター上のページ（たとえば、乗組員がそこで実行しているプロジェクト）。
- 職場、自宅、VPN のネットワーク上のサイト（[プライベートサイト](#private-sites)に登録したあと）。

乗組員が操作している間、カメラ、マイク、クリップボード、通知を求めるページには、ブラウザが「いいえ」と答えます。
パスキーを求めるサイトにはパスキーがないと伝えるので、サイトはパスワードやコードなど別の方法を提示します。
ページでサインイン、コード、支払いが必要になると、乗組員があなたに頼みます（[後述](#when-a-page-needs-you)）。

ブラウザは、乗組員が閉じたとき、あなたが **ブラウザを停止** を押したとき、タスクが閉じたとき、誰も見ていない状態で 30 分間使われなかったとき、または Infinitary を終了したときに停止します。
1 台のコンピューターで同時に動かせるタスクのブラウザは、最大 4 つです。

## 作業を見守る {#watch-it-work}

タスクのカードを開き、**ブラウザ** タブを選びます。タブには **ブラウザ** とページのタイトルが表示されます。
タスクに関するカードを開いているときは、コマンド検索の **ブラウザを表示** でも開けます。
乗組員のカードに「試す」や「予約を見る」などのボタンが付いていることもあり、押すとそのカードの横にブラウザが開きます。

ページの上の行には、**戻る**、**進む**、**再読み込み**、誰が操作しているか、**操作を引き継ぐ**、**その他** があります。
見守っている間、ページは乗組員が見ているものの画像で、クリックしてもページには届きません。
**その他** には、**合わせる** または **実際のサイズ**、**ブラウザを停止**、**ページのアドレスをコピー**、**問題を報告**（一等航海士へのメッセージを書き始め、続きをあなたが書きます）があります。

ページの下には折りたたまれた「乗組員」の行があり、乗組員の最新の言葉が表示されます。
開くと、ページの横で乗組員との会話を読み、メッセージを書けます。
「隠す」または Escape で表示を片付けても、ブラウザは動き続けます。

停止したブラウザには、停止した理由が表示されます。
**もう一度開く** を押すと、どこにもサインインしていない新しいブラウザが、停止前のページで起動します。タスクが閉じたあとは表示されません。

## 操作を引き継ぐ {#take-control}

1. ページの上の行にある **操作を引き継ぐ** を押します。
   乗組員はまず今の操作を終わらせ、その間、行には「乗組員の現在の操作を終えています…」と表示されます。
2. 行に「あなたが操作中 · 乗組員にはこのページは見えません」と表示されます。
   これで、クリック、スクロール、入力、貼り付けがページに届きます。
3. 戻すには **操作を戻す** を押します。
   押す前に、「操作を戻すと、乗組員はこのブラウザを読み取り、使えるようになります。サインイン済みのページも含みます。」と表示されます。

それ以外に操作が移ることはありません。ページのクリック、サインイン、リダイレクト、「隠す」、カードが閉じること、タイマーのどれでも移りません。
コマンド検索の **ブラウザの操作を引き継ぐ/戻す** でも、画面に表示されているブラウザについて同じことができます。

あなたが操作している間は、次のようになります。

- ページでの操作は何も記録されず、その間にページに表示された内容が乗組員に伝わることもありません。
- カメラ、マイク、クリップボード、通知を求めるページは、ページの上の行で **今回のみ許可** と **今はしない** を示してあなたに尋ねます。許可したものは「操作を戻す」で取り消されます。
- ファイルを求めるページでは、Infinitary 自身のファイル選択画面が開きます。

操作を戻すと、乗組員はページを改めて確認します。
ページのフィールドに入力した内容は読み取りません。フィールドは入力済みとして表示され、中の文字は隠されます。
乗組員がページのスクリーンショットを撮るのは理由を示したときだけで、その理由はタスクのアクティビティに記されます。あなたが入力した内容を含むページを撮ることは決してありません。

## ページにあなたが必要なとき {#when-a-page-needs-you}

サインイン、コード、支払いのためにページで人の手が必要になると、乗組員は判断カードであなたに頼みます。
カードにはサイトと理由が示され、あなたがすること（例：「ブラウザを開いてサインイン」）のボタンが、「待たせておく」などのボタンと並びます。
その間ブラウザはあなたを待ち、タスクの「ブラウザ」の行には「あなたの手助けを待って一時停止中」と表示されます。

カードのボタンを押すと、あなたが操作する状態でページが開き、その横にカードが表示されます。
カードには手順やコピーする値が表示されたままになり、作業しながらカードの欄から乗組員にメッセージを書けます。
終わったら **操作を戻す** を押します。
カードが閉じて乗組員が作業を続け、カードの欄に残っていた言葉は、操作を戻すときに一緒に送られます。

## サインイン済みのサイト {#signed-in-sites}

乗組員に頼まれてサインインした場合、サインインした内容はそのコンピューター自身のブラウザプロファイルに残ります。
**操作を戻す** を押すと、ページの上に、あとのタスクに何を許すかを尋ねる質問が表示されます（例：「example.com へのサインインはこのコンピューターに残ります。あとのタスクは：」）。

- **毎回確認する** が先頭にあります。
  あとでそのサイトが必要になったタスクはカードで尋ね、カードには **自分でサインインする** の横に **example.com のサインインを使う** が加わります。
  1 回クリックするだけで、そのタスクのブラウザがサインインした状態でサイトを使えるようになり、あなたは何も入力しません。
- **確認せずに使う** を選ぶと、あとのタスクはカードなしでサインインした状態でサイトを開けるようになり、そのたびにタスクのアクティビティにそのことが記されます。
  支払いや最終的な送信には決して適用されません。

このルールは、そのコンピューター上のすべてのプロジェクトのタスクに適用されます。
サインイン済みのサイトを使うブラウザが開けるのは、そのサイトと、サインインの途中で経由したページだけです。それ以外のサイトはサインインしていない状態で開きます。
自分で **操作を引き継ぐ** を押したあとなど、それ以外の理由でサインインした場合、サインインは通常、そのブラウザが停止するまでしか続きません。
どちらなのかはページの下の行に表示されます（例：「一時的 · 停止するまでサインインした内容を保持します」）。

各コンピューターはそれぞれ独自のサインインを保持し、ほかのコンピューターやファイルにコピーされることはありません。
サインインは保護されたストレージではなく、そのコンピューターのブラウザプロファイルに残るので、安全性はそのコンピューター自身のログインとディスクと同じです。

一等航海士がいるコンピューターでは、一覧は設定 → **シークレット** の **サインイン済みのサイト** にあり、各コンピューターのサイトがその名前の下に表示されます。
別の場所から一等航海士を操作するコンピューターでは、設定 → **一般** の **Web サイトのサインイン** にあります。
各サイトには、サインインした日時、**あとのタスク** のルール、**削除** が表示されます。**削除** を押すと、そのコンピューターでそのサイトからすぐにサインアウトします。
**すべて削除** を押すと、そのコンピューターはすべてのサイトからサインアウトします。一覧に追加されなかったサインインも含みます。

サイトは自らサインインを終了することがあり、そのときは乗組員がもう一度あなたに頼みます。
保持していたサインインでページにサインインできなかった場合、次のカードでは **自分でサインインする** が先頭になり、**自分のサインインを使う（前回はうまくいきませんでした）** が 2 番目の選択肢として残ります。

## プライベートサイト {#private-sites}

職場、自宅、VPN のネットワーク上のサイトには、一覧に登録して初めて接続できます。
乗組員がそうしたサイトを必要とすると、一等航海士がカードであなたに尋ねます（例：「タスクのブラウザから wiki.corp.example への接続を許可しますか？」）。
**許可** を押して追加するか、**今はしない** を押します。一等航海士が自分で追加することはありません。

一覧は設定 → **連携** の **プライベートサイト** にあり、すべてのコンピューターに適用されます。

- **サイト** を押し、`wiki.corp.example` のような名前を入力して、**追加** を押します。
- `.corp.example.com` のような末尾部分を登録すると、その下のすべての名前が対象になります。
- 登録するのは名前で、数字のアドレスは登録できません。
- **削除** を押すとサイトが一覧から外れ、タスクのブラウザはすぐにそのサイトに接続しなくなります。

登録したサイトは、通常のブラウザと同じように、どのページからでも https または http で開けます。
コンピューターの内部だけで待ち受けているプログラムには、決して接続しません。

## 購入と予約はあなたが行います {#purchases-and-bookings-are-yours}

購入、予約など、あなたが責任を負うことになる送信は、サイト自身のページで、あなたが操作して行います。
乗組員は最後のボタンの手前まで入力し、そこで止まります。

そのうえで乗組員は確認用のカードで尋ねます。カードには、今のページから読み取った、あなたが責任を負う内容が示されます。
旅行の場合は、経路、日付と時刻、乗客、販売者、合計金額と通貨、手荷物と運賃の規則です。
まだ不確かな点や、前回あなたが選んでから変わった点もカードに示されます。
カードのボタンにはあなたがすること（例：「ブラウザを開いて支払う」）が書かれ、「ここで止める」などのボタンと並びます。

- 確認のあとで価格や条件が変わった場合、乗組員は止まってもう一度尋ねます。
- 支払いを済ませて操作を戻すと、乗組員はページに表示された結果を読み、予約番号などの結果だけを保持します。
  あなたが入力したカード情報は乗組員には隠されたままです。
- ページで完了が確認できない場合、乗組員は、手続きが済んだかどうかわからないとはっきり伝えます。
  決して再送信はせず、あなたに尋ねる前に、サイトで手続きが一覧表示される場所（予約の一覧など）を確認します。
- ブラウザがフォームを 2 回送信することはありません。フォームに応答したページを再読み込みしても、もう一度送信されることはありません。

## ファイルとダウンロード {#files-and-downloads}

ページがダウンロードしたファイルは、あなたが操作中にダウンロードしたものも含めてタスクの証拠と一緒に保存され、1 件ごとにタスクのアクティビティに記されます。
ページがファイルを求めたとき、乗組員が渡せるのはタスクの作業コピーにあるファイルだけです。
乗組員が持っていないファイルはあなたが渡します。乗組員はブラウザをあなたに引き渡すカードで頼みます。

## ほかのコンピューターで {#on-your-other-computers}

ほかのコンピューターで実行されるタスクのブラウザは、そのコンピューターにあります。
このコンピューターのブラウザと同じように、どのウインドウからでも見守り、操作を引き継げます。
そのコンピューターは独自のサインイン済みのサイトを保持し、[プライベートサイト](#private-sites)の一覧はそこにも適用されます。
あなたが操作中にそこでファイルを求めるページは、乗組員を待ちます。Infinitary のファイル選択画面はそのコンピューターには届かないためです。
[ほかのコンピューター](/ja/your-other-computers/)を参照してください。
