以下の各問題は、Infinitary に表示される言葉から始まります。

## サブスクリプションにもう一度サインインする必要がある {#a-subscription-needs-you-to-sign-in-again}

「一等航海士がもう一度サインインを求めています」という題のカードが表示されるか、設定 → **インテリジェンス** のサブスクリプションに「もう一度サインイン」と表示されることがあります。
そのサブスクリプションでの作業は待機します：「もう一度サインインするまで作業は一時停止します。」

1. カードの **サインイン** を押すか、設定 → **インテリジェンス** を開きます。
2. プロバイダーの案内に従って、そのサブスクリプションにサインインします。
3. 待機していた作業は自動的に再開します。

別のコンピューターで実行されるタスクはそのコンピューター自身のサインインを使うので、そのコンピューターの名前の下で、そのコンピューター用にもう一度サインインします。

## プランの利用枠を使い切った {#your-plans-allowance-ran-out}

一等航海士が「一等航海士が利用枠を使い切りました」という題のカードを表示します。
そのサブスクリプションで動いている乗組員への返信には「保存済み、まだ送信されていません」と、利用枠がリセットされる時刻が表示されます。
リセットされると、作業は自動的に再開します。

もっと早く続けるには、次の方法があります。

- プロバイダー側で何かを変更した場合は、**利用枠を再確認** を押します。
- 再確認で何も変わっていなければ、カードはプロバイダーをもう一度試す選択肢（**Try Claude again** など）も表示します。言葉は一度だけ送られ、利用枠がまだ使い切られていれば、一等航海士は再び一時停止します。
- カードに別のプロバイダーが提示されている場合は、**移動先** を押してそのプロバイダーを選びます。
- 一等航海士に、作業を別のモデルへ移すよう頼みます。

設定 → **インテリジェンス** には、各プランの利用枠の残りと、リセットされる時刻が表示されます。
Claude と Codex では、**クレジットで続ける** を使うと、プロバイダーで用意したクレジットでアカウントの作業を続けられます。

## 一等航海士が応答しない {#your-first-mate-is-not-answering}

メッセージに何も返ってこなかった場合は、「一等航海士がメッセージに応答していません」というカードが表示されます。
**もう一度尋ねる** を押してもう一度送るか、**そのままにする** を押します。

プロバイダー自体が応答していない場合は、そのプロバイダーが「今は一等航海士に応答していません」というカードが表示されます。
**Claude をもう一度試す**（またはプロバイダー名の入った同じボタン）を押すか、**設定を開く** を押して別のサブスクリプションを選びます。
プロバイダーに短時間の問題が起きたときは、アクティビティにそう表示され、アプリが自動的に再試行します。

## 乗組員が待っている {#a-crewmate-is-waiting}

**あなた待ち** と表示されているタスクには、あなた宛てのカードがあります。
タスクを開いて **カードを表示** を押し、判断してください。

タスクに表示されるほかの言葉は、何がそのタスクを止めているかを示します。

- 「チェックを待っています」：担当の乗組員が、プルリクエストのチェックを待っています。
- 「プロバイダーで再試行中」：プロバイダーで失敗が起き、アプリが自動的に再試行しています。
- 「プロバイダーで停滞中」：プロバイダーが同じリクエストを 3 回拒否し、一等航海士が次の対応を選んでいます。
- 「別のタスク待ち」：そのタスクが終わると開始します。

## プルリクエストのチェックに失敗した {#the-checks-failed-on-a-pull-request}

チェックに失敗すると、プルリクエストを作った乗組員がそれを修正し、新しいバージョンを用意します。
するとマージカードに **エラーを修正してからマージ** が表示されます。
これを押すと、マージの承認はそのまま残ります：「マージは修正待ちです：チェックに失敗しました。」
修正のチェックに合格するとマージが実行されます。修正で作業が変わった場合は、乗組員が新しいカードで改めて確認します。

## 別のコンピューターと連絡がつかない {#another-computer-is-out-of-reach}

別のコンピューターのウインドウに、もう一方のコンピューターが「戻るまで変更はできません。スリープ中か、別のネットワークにある可能性があります。」と表示されます。
または、そのコンピューターで「Infinitary が閉じています」と表示されます。

1. 一等航海士がいるコンピューターをスリープから復帰させ、そこで Infinitary を開きます。
2. 両方のコンピューターを同じネットワーク、または同じプライベートネットワークに入れます。
3. 設定 → **デバイス** で、そのコンピューターの行の **もう一度試す** を押します。

アドレスで追加したコンピューターのアドレスが変わった場合は、そのメニュー（行の右にある 3 つの点）を開いて **アドレスを変更** を選びます。
Mac では、その Mac の前にいる人が許可するまで、macOS が Infinitary のローカルネットワークへのアクセスを止めていることがあります。
その場合、行には代わりに **アドレスで追加** が表示されます。
[ほかのコンピューター](/ja/your-other-computers/)を参照してください。

## 同じコンピューターが 2 つ表示される {#a-computer-is-listed-twice}

設定 → **デバイス** に同じ名前が 2 つ表示されます。1 つは連絡のつく行、もう 1 つはタスクが残ったまま連絡のつかない行です。
作業を実行するコンピューターが、保存した作業を削除されたあとや、Infinitary を新しくインストールし直したあとにもう一度参加すると、こうなります。
連絡のつく行には「同じ名前とユーザーの以前の項目が連絡がつきません」と表示されます。

1. 連絡のつく行で **タスクをここで続ける** を押します。
2. 続くものと残るものを読んでから、**続ける** を押します。
3. 各タスクは、一等航海士がいるコンピューターが最後に持ち帰ったコミットから続きます。
   すべてのタスクが移ると、以前の行は一覧から消えます。

そのコミットより後のコミット、コミットしていない編集、古いタスクフォルダーのファイルは、以前の項目に残ります。
一致するものがなく連絡のつかない行では、**タスクの移動先…** を押してコンピューターを選びます。
[保存した作業が削除される操作](/ja/update-and-remove/#what-deletes-your-saved-work)を参照してください。

## ウインドウが応答しなくなった {#the-window-stops-answering}

まずは少し待ってください。
固まったままの場合は、Infinitary を終了してもう一度開きます。
一等航海士や乗組員が処理し終えていなかったメッセージは、開いたときに再び処理されます。

## Infinitary を起動できませんでした {#infinitary-could-not-start}

Infinitary が起動を終える前に 2 回続けて止まると、「Infinitary を起動できませんでした」という題の画面が表示されます。
画面には「起動が終わる前に 2 回停止しました。保存した作業は変更されていません。」と表示されます。

- **もう一度試す** は、Infinitary をもう一度起動します。
- **Infinitary をリセット** は、インストール直後の状態からやり直します。
  先に確認があり、**すべて残す** で元の画面に戻れます。そのあとコンピューターが本人であることを確認します。
  Infinitary がこのコンピューターに保存しているものはすべて削除されますが、自分のフォルダーにあるプロジェクトは、すべてのファイルとコミットがそのまま残ります。
- **終了** は画面を閉じます。次に Infinitary を起動すると、この画面がもう一度表示されます。

保存した作業を開けないときに Infinitary が表示する画面にも、**Infinitary をリセット** があります。
リセットで何が削除されるかは、[Infinitary をリセットする](/ja/update-and-remove/#reset-infinitary)を参照してください。

### ターミナルからリセットする {#reset-from-a-terminal}

ウインドウがまったく開かないときは、Infinitary を終了して、ターミナルで次を実行します。

```sh
infinitary reset
```

Mac では `/Applications/Infinitary.app/Contents/MacOS/Infinitary` を `infinitary` の代わりに入力し、AppImage の場合はファイルのパスを入力します。
コンピューターが本人であることを確認すると、コマンドは「Infinitary をリセットしました。次に開くとようこそ画面が表示されます。」と答えます。
このコンピューターで Infinitary が開いている間や、確認しなかったときは、コマンドは何もリセットしなかったと答えます。

## macOS がほかのアプリのデータについて尋ねてくる {#macos-asks-about-other-apps-data}

macOS が「“Infinitary”がほかのアプリからのデータへのアクセスを求めています。」と尋ねることがあります。
これは、乗組員の検索が、別のアプリが保管しているファイルに及んだときに起こります。
Infinitary の作業でそれらが必要になることはまれなので、通常は **許可しない** で問題ありません。
答えるまで、タスクの記録には「macOS 待ち」と表示され、答えると検索が続きます。

## Claude Code が見つからない {#claude-code-is-missing}

Claude のサブスクリプションを使うには、まずそのコンピューターに Claude Code をインストールします。
インストールされていないと、Infinitary に「このコンピューターには Claude Code がインストールされていません。ここで Claude を使うにはインストールしてください。」と表示されます。
バージョンが古すぎる場合は、必要なバージョンが表示され、`claude update` を実行するよう案内されます。
別のコンピューターでは、Claude Code はそのコンピューター上で自分でサインインします。そこで一度 Claude Code にログインすれば、Infinitary はそのログインを使います。

## それでも解決しない場合 {#still-stuck}

[ヘルプを得る](/ja/get-help/)を参照してください。
何をしたか、何を期待したか、そして実際には何が起きたかを伝えてください。
