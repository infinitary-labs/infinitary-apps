このページでは、1 つの依頼を最初から最後までたどります。
サブスクリプションが接続され、プロジェクトが追加済みであることを前提としています。
まだの場合は、[初回起動](/ja/first-launch/)から始めてください。

## 1. 頼みたいことを伝える {#1-say-what-you-want}

ウインドウ下部のメッセージ欄に依頼を入力して送信します。
人に頼むときと同じように書いてください。してほしいことと、こだわりたい点です。
たとえば、「Web サイトで、スマートフォンでも登録ボタンを見つけやすくして」のように書きます。
[頼めること](/ja/what-you-can-ask-for/)では、ほかの種類の依頼も紹介しています。

入力する代わりに話したり、画像やファイルを添えたりもできます。
[一等航海士](/ja/the-first-mate/)を参照してください。

## 2. 一等航海士が受け取る {#2-your-first-mate-takes-it}

送ったメッセージは、メッセージ欄のすぐ上に表示されます。
その下では、一等航海士の印が「作業中…」の横で回り、返事が届くとそこに置き換わります。
返事は、タスクを開始したなど、何をしたかを伝える短い一文です。

一等航海士が自分で答えられる質問には、カードで答えが返ってきます。
プロジェクトでの作業はタスクになり、`WEB-12` のようなキーが付いて、乗組員が取りかかります。
どの依頼にも、ウインドウ右側のタスクに記録が残ります。

## 3. 乗組員が作業する {#3-a-crewmate-does-the-work}

乗組員はプロジェクトの専用の作業コピーで作業するので、手元のファイルはそのまま変わりません。
作業中、乗組員はウインドウ中央で一等航海士の周りを回ります。
何をしているかを伝える短い行が、左側のアクティビティに表示されます。

見守っている必要はありません。
詳しく見るには、タスクからそのタスクを開くか、乗組員にポインタを重ねます。
[タスクと乗組員](/ja/tasks-and-crewmates/)を参照してください。

乗組員があなたの判断を必要とするときは、カードを持ってきます。
大きな依頼では、作り始める前に承認を求めるプランがそのカードになることもあります。
答えると、乗組員は作業を続けます。

## 4. マージカード {#4-the-merge-card}

作業が終わって確認も済むと、乗組員がマージカードを持ってきます。
マージカードには、変更のストーリーがすべてまとまっています。

- **理由**：一文で。
- **変更内容**：いくつかの短い項目で。
- 変更が関わる各画面の **変更前** と **変更後** の画像。
- 乗組員が何をどのように確認したか。
- カードの右上にある、変更のリスクを表す小さな図。

画像をクリックすると大きく表示されます。
リスクの図の点にポインタを重ねると、何を評価しているかとその理由を読めます。
カードの読み方について詳しくは、[カードと判断](/ja/cards-and-decisions/)を参照してください。

## 5. マージする {#5-merge-it}

カードを読んでから、次のどれかを選びます。

- **プルリクエストをマージ** を押すと、プロジェクトの保管先で変更がマージされます。
  このコンピューターに置いているプロジェクトでは、ボタンは **ブランチをマージ** になります。
- **慎重にレビュー** はプルリクエストで表示され、先に独立したレビューを依頼します。
  レビューに通ると、新しいマージカードが届きます。
- **破棄** を押すと、作業を取りやめます。

チェックがまだ実行中のときは、ボタンが **チェックに合格したらマージ** になります。
クリックすると、チェックに合格した時点で Infinitary がマージします。
チェックに失敗したときは、ボタンが **エラーを修正してからマージ** になります。
クリックすると、エラーが修正されてチェックに合格したところで Infinitary がマージします。

代わりに変更を頼むには、「補足があれば」と表示されたカードの入力欄に書いて、**チャット** を押します。
乗組員はカードの横のスレッドで答え、終わったらカードを更新します。

## 6. マージのあと {#6-after-the-merge}

タスクは閉じて、タスクの「完了」に移ります。
タスクの記録には、頼んだこと、変わったこと、根拠、あなたが決めたことが残ります。

マージ後にあなたにしかできない作業が必要な場合は、マージカードの上部の「マージ後、次の作業が必要です…」の下にそのことが書かれています。
[カードと判断](/ja/cards-and-decisions/)を参照してください。

## 確認せずにマージする {#merging-without-asking}

プロジェクトは、変更しない限り、マージする前に確認を求めます。
チェックに合格した完成済みの作業をそのままマージさせるには、設定 → プロジェクトで、そのプロジェクトの **マージ前に確認** をオフにします。
マージ後も、変更のストーリーを載せたカードは届きます。
