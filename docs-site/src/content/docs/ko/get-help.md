## 질문하거나 문제 알리기 {#ask-a-question-or-report-a-problem}

- [Discord 서버](https://discord.gg/Wsy2NpnZDu)에 들어와서 물어보세요.
- 또는 [help@getinfinitary.com](mailto:help@getinfinitary.com)으로 메일을 보내 주세요.

무엇을 했는지, 무엇을 기대했는지, 대신 무슨 일이 일어났는지 알려 주세요.
창을 찍은 사진이 있으면 도움이 돼요.

## 앱에서 피드백 보내기 {#send-feedback-from-the-app}

앱을 떠나지 않고 Infinitary 제작자에게 문제나 아이디어를 알릴 수 있어요.

1. 아무 메시지 상자에나 `/feedback`과 몇 마디를 입력하고 보내세요.
   도움말 메뉴의 **피드백 보내기…**와 명령 검색의 **피드백 보내기**로도 시작할 수 있어요.
2. 선원이 GitHub에 있는 Infinitary의 공개 프로젝트에 올릴 이슈 초안을 쓰고, 카드를 가져와요.
   카드는 올라갈 이슈를 그대로 보여 줘요.
3. 읽은 다음 **피드백 제출**을 누르세요.

선장님의 클릭이 이슈를 선장님 자신의 GitHub 계정으로, 공개적으로, 한 번 게시해요.
그 클릭 전에는 아무것도 게시되지 않아요.
Infinitary에 GitHub 로그인이 없으면 카드가 대신 링크를 줘요.
링크는 보고 내용이 채워진 GitHub의 이슈 양식을 열고, 선장님이 거기서 게시하면 돼요.

보고에는 선장님의 이름, 폴더, 프로젝트, 로그인이 들어가지 않아요.
[컴퓨터 밖으로 나가는 것](/ko/what-leaves-your-computer/#feedback-you-send)을 보세요.
