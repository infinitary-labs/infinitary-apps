[Mac](https://getinfinitary.com/downloads/#macos) 또는 [Linux](https://getinfinitary.com/downloads/#linux)용 Infinitary 안정 릴리스를 내려받으세요.
내려받은 파일을 확인하고 싶다면, 그 SHA-256 체크섬을 다운로드 페이지에서 그 파일 옆에 표시된 값과 비교하세요.

## Mac에서 {#on-a-mac}

Apple 실리콘 Mac이나 Intel Mac에 맞는 **디스크 이미지(.dmg)** 파일을 내려받으세요.
파일을 열고 Infinitary를 **응용 프로그램**으로 끌어다 놓으세요.
대신 **ZIP**을 고른 경우, 압축을 풀고 꺼낸 Infinitary 앱을 **응용 프로그램**으로 옮기세요.

## Linux에서 {#on-linux}

Ubuntu나 Debian이라면 **.deb** 패키지를, Fedora라면 **.rpm** 패키지를 고르고, 시스템의 소프트웨어 설치 프로그램으로 여세요.
Arch나 Omarchy에서는 Arch 패키지 레시피를, NixOS에서는 Nix 레시피를 쓰세요.
다른 x64 Linux 시스템에서는 **AppImage**를 내려받고, 파일 속성에서 프로그램으로 실행하도록 허용한 다음 여세요.

## iPhone과 iPad에서 {#on-iphone-and-ipad}

iPhone과 iPad용 Infinitary는 비공개 TestFlight로 제공돼요.
[help@getinfinitary.com으로 메일을 보내 초대를 요청하세요](mailto:help@getinfinitary.com?subject=Infinitary%20TestFlight%20request).
컴퓨터에 연결하는 방법은 [iPhone과 iPad](/ko/iphone-and-ipad/)를 보세요.

## 필요한 것 {#what-you-need}

- **컴퓨터.**
  macOS 12 이상의 Mac, 또는 x64 프로세서를 쓰는 Linux 컴퓨터예요.
- **AI 구독.**
  일등항해사에게는 답할 수 있는 구독이 하나 이상 필요해요: Codex, Grok, Claude, Kimi Code, Copilot, API 키를 쓰는 OpenRouter, 또는 AWS 로그인을 쓰는 Amazon Bedrock이에요.
- **Claude를 쓴다면 Claude Code.**
  Claude 구독을 쓴다면, 먼저 그 컴퓨터에 Claude Code를 설치하세요.
  Infinitary는 설치된 Claude Code를 사용해요.

## 처음 실행 {#your-first-launch}

1. Infinitary를 여세요.
   창이 환영 인사를 하고 제공자마다 버튼을 보여 줘요.
2. 제공자를 고르고, 그 제공자가 요청하는 방식으로 로그인하세요: 브라우저에서, 코드로, 또는 붙여 넣는 키로요.
3. 구독이 답할 수 있게 되면 메시지 상자가 열리고 일등항해사가 준비돼요.

일등항해사는 되도록 계속 켜져 있는 컴퓨터에 설정하세요.
다른 기기들은 일등항해사가 깨어 있어야 해요.

나중에 Infinitary를 업데이트하거나 제거하려면 [Infinitary 업데이트와 제거](/ko/update-and-remove/)를 보세요.
무언가 잘 안 되면 [도움 받기](/ko/get-help/)를 보세요.
