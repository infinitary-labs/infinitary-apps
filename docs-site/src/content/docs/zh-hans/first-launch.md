开始之前，请先看看[你需要准备什么](/zh-hans/install/)。
本页带你走一遍第一次打开 Infinitary 的过程，以及之后会有什么变化。

## 窗口显示什么 {#what-the-window-shows}

你第一次打开 Infinitary 时，大副会在窗口中央迎接你。
上方写着“**欢迎登上 Infinitary，船长**”，下面是大副的一段话：

> 我是你的大副。
> 我会帮你管理其余的船员。
> 请把我设置在一台尽量保持开机的电脑上。
> 你的其他设备需要我保持运行。

再往下，大副可以使用的每个服务商都有一个按钮：Codex、Grok、Claude、Kimi Code、Copilot、OpenRouter、Amazon Bedrock 和自定义 API。

<img class="picture-light" src="/pictures/first-launch-light.webp" alt="首次启动：窗口中央是大副，下面是欢迎语，以及每个服务商的一个按钮。" width="1280" height="652" />

底部的消息框是灰色的，写着“请先连接一个订阅”。
在有订阅可以回答你的大副之前，其他功能都无法使用。

## 连接订阅 {#connect-a-subscription}

1. 点击你的服务商的按钮。
2. 按该服务商的要求登录。
   有些会在你的浏览器中打开登录页面。
   Copilot 和 Kimi Code 会显示一个代码：点击“**复制代码**”，然后在服务商的网站上输入它。
   OpenRouter 需要你粘贴一个 API 密钥。
   使用 Amazon Bedrock 时，选择一个区域，并使用这台电脑上的 AWS 配置文件，或粘贴一个 Bedrock API 密钥。
   两种方式都支持的服务商会询问你是“**用浏览器登录**”，还是粘贴“**API 密钥**”。
3. 等待窗口显示正在连接。
   当订阅可以回答时，欢迎界面会淡出，消息框随即打开。

如果你使用 Claude，Infinitary 会使用你在这台电脑上安装的 Claude Code。
没有它的话，Claude 按钮会提示你先安装 Claude Code。

如果订阅已经连接，但仍然无法回答，窗口会显示“**在这台电脑上设置你的大副**”，并说明还缺少什么。

## 如果你的大副已经在另一台电脑上 {#if-your-first-mate-already-lives-on-another-computer}

在服务商按钮下面，第二组按钮写着“你的大副在另一台电脑上”。
在 Mac 或 x64 Linux 电脑上，“**从你大副的电脑上设置**”排在最前：它会显示这台电脑的地址，供你在大副所在的电脑上输入。
那台电脑添加这台电脑后，只要这个窗口里还没有设置过任何东西（例如登录或项目），它就会自己打开你的大副。
已经设置过东西的窗口会保留它自己的大副：请改用“**粘贴它的链接**”或“**通过地址加入**”，从这里控制那位大副。
如果窗口旁边是你自己从“终端”启动的 Infinitary，它会保留那个 Infinitary 的大副，两种方式都不提供；要使用它们，请先停止那个 Infinitary。
Windows PC 和 Arm Linux 电脑只显示另外两种方式。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。

## 诊断通知 {#the-diagnostics-notice}

消息框下方的通知会说明“诊断”发送什么，以及它从不包含你输入的内容。
选择“**好**”保持开启，或选择“**关闭**”。
你之后可以在[设置](/zh-hans/settings/#general)中更改。
请参阅[哪些内容会离开你的电脑](/zh-hans/what-leaves-your-computer/)。

## 欢迎卡片 {#the-welcome-card}

当你的大副可以回答后，会出现一张标题为“**我们如何协作**”的卡片。
它是窗口的一幅小图，每次展示一个部分。
点击“**下一步**”和“**上一步**”，依次查看消息框、一张卡片、左侧的动态和右侧的任务。

图下面有三个开头语：

- “**克隆一个项目**”
- “**新建一个项目**”
- “**在我电脑上的一个文件夹里工作**”

点击其中一个，会把一句话的开头放进消息框，例如“克隆这个地址的项目：”。
把句子写完，然后发送。
开头语本身不会发送任何内容。

欢迎卡片没有回复框：你在它下面的消息框中输入。
你可以随时关闭它。

## 添加你的第一个项目 {#add-your-first-project}

你的大副需要一个项目来工作。
最简单的方法是使用欢迎卡片上的开头语，或者在你自己的消息中写同样的话。

当你提出要求时，大副会显示一张卡片，写明项目是什么，以及它将如何设置。
检查卡片上的选择，然后点击“**添加项目**”，或点击“**暂不**”放弃。
在你点击“**添加项目**”之前，不会添加任何内容。

你也可以自己在设置 → 项目中用“**添加项目**”添加项目。
那里的各项选择请参阅[项目](/zh-hans/projects/)。

## 之后的启动 {#later-launches}

当有订阅可以回答时，Infinitary 会直接打开到消息框。
你的卡片、任务和船员都留在你离开时的样子。

Infinitary 更新后，会有一张卡片写明新版本以及改动了什么。
你之后可以在[设置 → 通用](/zh-hans/settings/#general)的“版本”下再次阅读。
在 Mac 上，“帮助”菜单中的“**Infinitary 新功能**”也会打开它。

如果你的最后一个订阅停止工作，例如因为你退出了登录，欢迎界面会回来，直到再次有订阅可以回答。
如果你的套餐额度用完了，你的大副会显示一张卡片说明此事，并保留你的消息，直到它能回答。
请参阅[订阅和额度](/zh-hans/subscriptions-and-quota/)。

要在你登录电脑时打开 Infinitary，请在设置 → 通用中打开“**登录时启动**”。
