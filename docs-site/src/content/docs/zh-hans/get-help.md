## 提问或报告问题 {#ask-a-question-or-report-a-problem}

- 加入我们的 [Discord 服务器](https://discord.gg/Wsy2NpnZDu)并在那里提问。
- 或者写信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。

请说明你做了什么、你预期会发生什么，以及实际发生了什么。
附上一张窗口的图片会有帮助。

## 报告安全问题 {#report-a-security-issue}

请私下写信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。
请不要在 Discord 上发布安全问题。
