## 提问或报告问题 {#ask-a-question-or-report-a-problem}

- 加入我们的 [Discord 服务器](https://discord.gg/Wsy2NpnZDu)并在那里提问。
- 或者写信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。

请说明你做了什么、你预期会发生什么，以及实际发生了什么。
附上一张窗口的图片会有帮助。

## 在应用中发送反馈 {#send-feedback-from-the-app}

你不必离开应用，就可以向 Infinitary 的开发者报告问题或提出想法。

1. 在任意消息框中输入 `/feedback` 和几句话，然后发送。
   “帮助”菜单中的 **发送反馈…** 和命令搜索中的 **发送反馈** 也能开始。
2. 一名船员会为 Infinitary 在 GitHub 上的公开项目起草一个议题，并给你送来一张卡片。
   卡片上显示的就是将要发布的议题。
3. 阅读后，点击 **提交反馈**。

你的点击会用你自己的 GitHub 账户把议题公开发布，仅一次。
在你点击之前，不会发布任何内容。
如果 Infinitary 没有 GitHub 登录，卡片会改为给你一个链接。
它会打开 GitHub 的议题表单，其中已填好报告，由你在那里发布。

报告中不包含你的名字、文件夹、项目和登录。
请参阅[哪些内容会离开你的电脑](/zh-hans/what-leaves-your-computer/#feedback-you-send)。

## 报告安全问题 {#report-a-security-issue}

请私下写信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。
请不要在 Discord 上发布安全问题。
