你的大副、船员、自动化和面板都以同样的方式访问它，使用同一个登录、遵守同样的规则。

## 集成在哪里 {#where-integrations-live}

打开“**设置**”，然后打开“**集成**”。
你也可以在命令搜索中搜索“**打开集成**”。

每一行是一个连接。
它显示连接的名称、它以谁的身份登录或运行的是什么，以及它有多少个操作已打开。
打开一行即可查看它的操作，以及它能通知你的自动化什么。

行末的菜单包含：

- “**已暂停**”：开关打开时，谁都无法访问它。
- “**立即检查**”，用于检查连接是否仍然可用。
- “**退出登录并移除**”，MCP 服务器则为“**移除**”。

列表下方的按钮用于连接新的东西，例如“**GitHub**”“**Google**”或“**MCP 服务器**”。
你也可以让大副去连接某个东西。
登录始终由你本人完成，因此大副会给你送来一张卡片，用来打开这个标签页。

## GitHub、GitLab、GitHub Enterprise 和 Bitbucket {#github-gitlab-github-enterprise-and-bitbucket}

你在项目托管处的登录保存在这里。
Infinitary 如何用它克隆项目和提交改动，请参阅[项目](/zh-hans/projects/#your-github-gitlab-or-bitbucket-sign-in)。

- **GitHub**：你在浏览器中打开的 GitHub 页面上输入一个代码。
  如果这台电脑上装有 GitHub CLI，而你的组织阻止 Infinitary 这类应用，“**使用 GitHub CLI**”会使用 GitHub CLI 已有的登录。
- **GitLab**：你在浏览器中登录或粘贴密钥，可以在 gitlab.com 上，也可以在你自己的 GitLab 服务器上。
- **GitHub Enterprise**：你在自己的服务器上生成一个密钥并粘贴到这里。
- **Bitbucket**：你在 Atlassian 账户中生成一个 API 令牌并粘贴到这里，用于 bitbucket.org。
  对于你自己的 Bitbucket Data Center 服务器（8.19 或更新版本），你输入它的地址，并粘贴你在上面生成的 HTTP 访问令牌，令牌需要 Project read 和 Repository write 权限。
  Data Center 这一行也提供同样的读取和写入操作，使用服务器自己的路径，“**在此任务剩余期间允许**”只覆盖一个仓库。

每一行都有两个操作：一个用于读取，一个用于更改，例如“**在 GitHub 上更改内容**”。
大副和船员在任务本身的工作之外，在那里查找信息或执行操作时，用的就是它们。
任务的分支、拉取请求、检查和合并则遵循你项目的设置。

如果另一台电脑在为你运行工作，它自己用于在那里克隆和推送的 GitHub 登录也会在这里占一行。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。

退出 GitHub 登录后，私有仓库的克隆和拉取请求都会停止，直到你重新登录。

## Google：Gmail 和 Calendar {#google-gmail-and-calendar}

Google 用一个登录同时连接 Gmail 和 Calendar。

1. 点击“**Google**”。
2. 阅读“**连接 Google 之前**”：Infinitary 会使用你账户中的哪些内容、这些内容会去往哪里，以及保留多久。
3. 点击“**接受并继续前往 Google**”，或点击“**取消**”，不向 Google 请求任何东西。
4. 在浏览器中打开的 Google 页面上完成登录，并允许它列出的每一项权限。

如果你有某项权限没有勾选，Infinitary 不会保留任何内容，你可以重新登录。
每次登录 Google 时，都会先显示这份说明。

连接 Google 后，大副和船员可以搜索和阅读你的邮件、把附件保存到任务的文件夹中、为邮件添加标签或将其归档、起草邮件以及发送邮件。
在 Calendar 中，它们可以列出你的日历和日程、阅读某个日程、查看你的忙碌时间，以及创建或更新日程。
没有任何操作会删除日历日程。

大副和船员读到的内容会在它们保存的对话中保留 30 天。
之后由一条说明取而代之。
要更早删除，请在标签页底部“**数据**”下的“**删除 Gmail 和 Calendar 内容**”一行中点击“**删除**”。
保存的附件会留在任务的文件夹中，直到任务结束或满 30 天。
船员在保存的附件中读到的文字，在 30 天后仍会留在它的对话中。
大副和船员自己写下的内容，包括卡片、笔记和文件，会一直保留，直到你删除该任务。
移除 Google 不会删除它们已经读到的任何内容。

任何人都可以给你发送意在操纵 AI 的文字。
Infinitary 把你的邮件和日程交给大副和船员时，会标记为来自外部的信息，绝不作为指示。
即便如此，一封邮件仍可能误导 AI 模型。
船员可以不经询问访问互联网，因此被误导的船员可能会把它读到的内容发往别处。

## MCP 服务器 {#mcp-servers}

MCP 服务器是向 AI 应用提供操作的程序或网址。

1. 点击“**MCP 服务器**”。
2. 为它填写“**名称**”。
3. 在“**运行**”下，输入一个程序及其参数，或服务器的 https 地址。
4. 点击“**连接**”。

程序会在有人使用它时在这台电脑上启动。
Infinitary 会立即连接，并打开新的一行，显示服务器自己的操作列表。
如果无法连接，表单会说明原因。

如果服务器需要密钥，请自己把它放在“**运行**”一行的开头，例如 `EXAMPLE_KEY=your-key npx -y @example/mcp-server`。
Infinitary 会把密钥移到[机密](/zh-hans/secrets/)中，这一行只保留对它的引用。
服务器每次启动时都会得到这个密钥，不会询问你。
你的大副和船员永远看不到它。
移除服务器会忘记它的密钥。

## 每个操作可以不经询问做什么 {#what-each-action-may-do-without-asking-you}

打开的一行会列出每个操作及其作用：“**读取**”“**更改**”或“**发送**”。
每个操作一开始都是“**询问你**”，读取操作也一样。
点击它的规则，可在“**询问你**”和“**始终允许**”之间切换。
只有你能更改规则。
操作旁边的开关可以关闭该操作，关闭后谁都无法运行它。

当大副或船员使用一个需要询问你的操作时，Infinitary 会给出它自己的批准卡片。
卡片会准确显示将要运行的内容，以及给出的理由。

- “**始终允许**”会运行它，之后该操作不再询问你，直到你在设置中更改它、替换该连接，或该操作发生变化。
- “**在此任务剩余期间允许**”只出现在船员的请求上，它会运行该操作，并让这名船员在同一个地方运行同一操作时不再询问，直到它的任务结束。
  卡片会说明这个地方是什么，例如 GitHub 上的某个仓库，或某封邮件的收件人。
- “**仅此一次**”只运行一次。
- “**暂不**”什么也不运行。

当一名船员在同一个连接上多次请求时，这些请求会合并到一张卡片上，每个请求占一行，各带一个已勾选的“**允许**”框。
取消勾选某一行，它就永远不会运行。
把卡片放到一边，它的请求会继续等待。

如果 Infinitary 无法确定某项更改是否已送达，它绝不会再次发送。
集成返回的内容是给大副和船员的信息，绝不是指示。

面板也可以使用它声明的集成。
它的请求会弹出同样的卡片，并注明是哪个面板。
请参阅[面板](/zh-hans/panels/)。

## 集成能通知什么 {#what-an-integration-can-tell}

有些连接会在某件事发生时发出通知，自动化可以等待这类通知。
打开的一行会列出这些通知，并标记为“**通知**”。

- GitHub：在你指定的仓库中，“**工作流运行失败**”和“**工作流运行结束**”。
- Gmail：“**收到邮件**”。
- Calendar：“**日历日程有变化**”。
- 提供此功能的 MCP 服务器：“**资源已更改**”。

在“自动化”中的“**当某事发生时**”下选择其中一项。
请参阅[自动化](/zh-hans/automation/#when-it-runs)。

## Infinitary 命令 {#the-infinitary-command}

“**Infinitary 命令**”框适用于你在这台电脑上运行的程序，以及你自己的 AI 智能体。
只需一条命令，它们就能以你的身份读取和处理你的卡片和任务，并与你的大副交谈。
船员永远得不到它。

在你打开之前，它一直处于关闭状态。
打开后，这个框会显示要运行的命令行，并附有“**复制**”按钮；在可行时，“**链接它**”会提供一个更短的名称。
第一次打开时，它还会打开一项自动化“**Infinitary 收件箱事件**”，这样程序发来的每条便笺都会告知你的大副。
便笺是信息，绝不是指示。

关闭它后，这条命令会返回错误，而已保存的便笺仍会保留。
“**数据**”下的“**删除 Infinitary 收件箱便笺**”会移除这些便笺并将其关闭。

## 私有站点 {#private-sites}

“**私有站点**”框列出你办公室、家庭或 VPN 网络中任务浏览器可以打开的站点。
这个列表适用于你所有的电脑。
点击“**站点**”添加一个，或点击“**移除**”去掉一个。
大副绝不会自己添加站点：它会在卡片上询问你，只有你点击“**允许**”才会添加。
请参阅[船员的浏览器](/zh-hans/the-crews-browser/#private-sites)。
