操作手册是你的大副和船员在某类工作中遵循的书面指导，例如规划改动、上课或为提交命名。
它包含文字、示例和图片，不会在你的电脑上运行任何东西。
Infinitary 自带一些操作手册，你也可以制作或添加更多。

## 操作手册在哪里 {#where-runbooks-live}

打开 **设置**，然后打开 **操作手册**。
你也可以在命令搜索中搜索 **打开操作手册**。

这个部分有三组：

- **内置** 列出 Infinitary 自带的操作手册。
- **你的** 列出你添加的操作手册，或你和大副一起制作的操作手册。
- **自己制作** 包含 **你的操作手册文件夹**，以及可以提出哪些要求的示例。

每一行显示操作手册的名称、用途和它的开关。

## 开启或关闭操作手册 {#turn-a-runbook-on-or-off}

用操作手册的开关来开启或关闭它。
你也可以告诉大副，例如“关闭课程”。

大副会在完成手头的事情后遵循这项更改，之后开始的每名船员也一样。
已经在工作的船员会继续使用它开始时的指导。

关闭的操作手册不会指导任何人，但它会留在列表中，你可以再次开启它。

## 内置操作手册 {#the-built-in-runbooks}

大多数内置操作手册一开始就是开启的。
有三本一开始是关闭的，直到你开启它们：**批量拉取请求**、**拉取请求评论** 和 **高级架构**。

- **常用工作流程**：大副如何着手规划、构建、修复和调研。
- **交付判断**：对于通过拉取请求进行的工作，船员如何判断检查、修复，以及改动何时可以合并。
- **测试规则**：船员规划或更改项目时应该测试什么。
- **把关级别**：每个级别对改动的要求：**快速**、**默认** 和 **谨慎**。
  请参阅[把关](/zh-hans/tasks-and-crewmates/#rigor)。
- **提交与 PR 命名**：提交、拉取请求和工作分支如何命名。
  关闭它，且没有你自己的操作手册为它们命名时，Infinitary 不检查任何名称。
- **程序**：对于可以用脚本拆分的工作，船员会编写一个简短的脚本，把每个部分作为单独的任务放入。
- **休闲项目**：大副如何搭建为了好玩或个人使用的小项目。
  请参阅[你可以提出哪些要求](/zh-hans/what-you-can-ask-for/#a-small-project-for-fun)。
- **课程**：跨越多天学习一门学科的指导和卡片组件。
  请参阅[你可以提出哪些要求](/zh-hans/what-you-can-ask-for/#a-subject-learned-across-days)。
- **批量拉取请求**：把你批准的改动合在一起，作为一个批量拉取请求合并，让它们的检查只运行一次。
  开启它之后，才能在设置 → **项目** 中为某个项目选择批量拉取请求。
  请参阅[项目](/zh-hans/projects/#how-changes-reach-your-project)。
- **拉取请求评论**：船员会回复它的拉取请求上的评论，直到它合并。
  明确的修复它会自己完成，不明确的则作为选择交给你。
- **电脑清理**：经你同意后进行的只读查看，以及一张让你选择停止哪些残留项的卡片。
  请参阅[你可以提出哪些要求](/zh-hans/what-you-can-ask-for/#a-look-at-a-computer-under-strain)。
- **迁入机密**：船员如何把机密从另一个工具迁入 **机密**，且没有任何代理看到值。
  船员只在这类迁移期间阅读它。
  请参阅[机密](/zh-hans/secrets/)。
- **反馈**：在任意消息框输入 `/feedback` 和几句话，船员会为 Infinitary 的开发者起草一个议题，由你阅读并亲自发布。
  它包含应用和系统的相关事实，从不包含你的名字、路径或项目。
- **高级架构**：绘制项目的各个部分及其连接方式，并显示改动在这张图上移动了什么。
  它是一项实验。

当某个项目正在使用批量拉取请求时，Infinitary 不允许你关闭 **批量拉取请求**，并会写出那个项目的名称。

## 阅读操作手册 {#read-a-runbook}

点击内置操作手册旁边的 **查看**。
它会打开你电脑上该操作手册文件夹的只读副本。
要更改内置操作手册的工作方式，请让大副把它变成你的，方法见下文。

## 自己制作 {#make-your-own}

用你自己的话告诉大副。
设置中的 **自己制作** 给出了一些示例，例如：

- “给每名船员一项用通俗的话写发布说明的技能。”
- “制作一本操作手册，告诉大副我更喜欢简短的回答。”

船员会在 **你的操作手册文件夹** 中写下新的操作手册。
它会列在 **你的** 下，并立即开启，除非你要求它一开始是关闭的。

**打开文件夹** 会在你的电脑上打开 **你的操作手册文件夹**。
在那里对操作手册所做的更改，会像开关一样传达给你的大副和船员。

## 把内置操作手册变成你的 {#make-a-built-in-runbook-yours}

让大副复制一本内置操作手册，例如“复制常用工作流程，让它始终先规划再构建。”

1. 大副把整本操作手册复制到 **你的操作手册文件夹** 中，并起一个新名称。
2. 副本列在 **你的** 下，一开始是关闭的，所以暂时什么都不会变。
3. 你自己更改副本，或让大副更改它。
4. 开启副本。
   内置的那一本会同时关闭。

内置操作手册保持原样。
要恢复原状，关闭你的副本，再开启内置的那一本。

## 添加别人分享的操作手册 {#add-a-runbook-someone-shared}

让大副从一个网址或文件夹添加操作手册，例如“添加别人分享的这个网址或文件夹中的操作手册。”

在你回答它的卡片之前，什么都不会添加；卡片以操作手册的名称为标题，例如“添加发布说明？”。
卡片会写明操作手册来自哪里、由谁制作、它能访问什么，以及它会关闭哪本内置操作手册。

- **添加** 会添加该操作手册并开启它。
- **不添加** 会拒绝它，并删除已获取的内容。

你放到一边的卡片会让这个提议一直等着。
已添加的操作手册有更新时，会再次用同样的卡片询问你。

要移除已添加的操作手册，请让大副按名称移除它。
它关闭的内置操作手册会保持关闭，直到你再次开启它。

**你的** 中 Infinitary 无法读取的操作手册会显示原因，没有开关，并且在修复之前不会指导任何人。

## 从另一台电脑 {#from-another-computer}

在从别处控制你的大副的电脑上，开关会更改你的大副所在电脑上的操作手册。
**查看** 和 **打开文件夹** 只在那台电脑上可用，文件夹那一行会写出它的名称。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。

## 使用键盘 {#use-the-keyboard}

按 Tab 可以依次到达每个 **查看** 按钮和开关。
命令搜索中有 **打开操作手册** 和 **打开你的操作手册文件夹**，你可以在设置 → **键盘** 中为它们分别设置一个按键。
请参阅[键盘](/zh-hans/keyboard/)。
