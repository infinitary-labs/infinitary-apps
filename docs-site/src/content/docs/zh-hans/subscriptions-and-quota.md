你的大副和船员们通过你已有的 AI 订阅工作。
你在“设置”的 **智能** 下的 **AI 订阅** 列表中管理它们。

## 添加订阅 {#add-a-subscription}

1. 打开“设置”并选择 **智能**。
2. 在 **AI 订阅** 底部的 **添加账户** 下，选择你的服务商：Codex、Grok、Claude、Kimi Code、Copilot、OpenRouter 或 Amazon Bedrock。
3. 按服务商要求的方式登录。
   有些会打开你的浏览器，有些会显示一个代码让你在它们的网站上输入，有些则需要你粘贴一个密钥。
4. 登录完成后，新账户会出现在列表中。

你可以添加同一服务商的多个账户。
这时它的按钮会显示为 **再添加一个 Codex 账户**，诸如此类。

## 为你的账户命名 {#name-your-accounts}

每个账户都有一个标签，方便你区分个人账户和工作账户。
如果登录时没有给出账户名称，会打开一个名称框让你输入。
以后要更改它，请打开账户的菜单并选择 **重命名**。

Claude 账户有所不同。
它跟随你电脑上的 Claude Code 登录，所以它的行显示的是当前在那里登录的人。
它没有 **重命名**，如果你切换 Claude Code 的登录，这一行也会随之改变。

每个账户都会为服务商提供的每项额度显示一个小用量表，例如一个会话和一周。
数字表示还剩多少。
把指针停在用量表上，即可查看它何时重置。

- 当你跑在时间前面，也就是花得比均匀速度更快、撑不到重置时，进度条会变成琥珀色。
- 数字低于一半时变成琥珀色，低于五分之一时变成红色。
- 用量表旁边有一个词概括这个账户的情况：**正常**、**某段时间后用完** 或 **已用完**。
- **截至 3 小时前** 表示上次读取的数据已经过时，所以它的数字会变暗。
- 短横线表示这项额度没有读取到。
- 持有[已保存的重置](#saved-codex-resets)的 Codex 账户，会在它的用量表下方写明有多少次。

列表顶部的 **刷新** 会重新读取每项额度。
Infinitary 不会读取 OpenRouter 或自定义 API 的额度，这一行会说明这一点。
Amazon Bedrock 在你的 AWS 账户上按用量计费；它的行显示根据 Infinitary 记录的工作得出的本月估算。

## 选择哪个账户做什么 {#choose-which-account-does-what}

打开账户的菜单，也就是它所在行的三个点，即可看到以下选项。
设置排在最前面，每项都有一个开关显示它是否开启；选中一项即可开启或关闭，菜单保持打开。

- **优先用于船员工作** 让你的船员们优先使用这个账户。
  它会标有 ✱。
- **已暂停** 的开关打开时，这个账户上的所有工作都会停止。
- **断开连接** 把这个账户从 Infinitary 中移除。

当你有两个或更多属于你的大副所用服务商的账户时，“设置”可以让你选择你的大副使用哪一个账户回答。
那个账户会标有 **大副** 标签。

## 额度用完时 {#when-an-allowance-runs-out}

你的船员们会自行继续。
新工作会交给还有额度的模型。
如果那个级别的模型都没有额度了，船员工作会降到较弱的模型，或者等到额度重置。

当你的大副自己的账户用完额度时，它会先转到同一服务商中仍有额度的另一个账户。
如果没有这样的账户，会出现一张卡片，写着 **你的大副已用完它的额度**。
你的话会等待，不会丢失任何内容。
在这张卡片上，你可以选择 **重新检查额度**、把你的大副转到另一个服务商，或选择 **打开设置**。
如果重新检查没有发现变化，卡片还会提供再试一次服务商的选项，例如 **Try Claude again**，用于你的大副通过另一个登录连接到服务商的情况；如果额度仍然用完，它会再次暂停。

有些服务商可以用你在它们那里设置的点数继续回答。
对于 Claude 或 Codex 账户，菜单中有 **用点数继续**。
这样你的船员们只会在用完所有套餐内额度之后才花费点数。
Infinitary 从不购买点数，也不设置点数上限；这由服务商自己的网站负责。

### Codex 已保存的重置 {#saved-codex-resets}

ChatGPT 可能会给 Codex 账户若干次已保存的重置。
每一次都能让一项额度在自行重置之前恢复。
账户所在的行会写明它有多少次、在哪里使用，例如“1 次已保存的重置 · 在 chatgpt.com 使用”。

当有一次现在就能使用时，账户的菜单中会有 **使用已保存的重置**。
说明额度已用完的那张卡片也会提到这一点，并带有同样的按钮和一个指向 chatgpt.com 用量页面的链接。
随后 Infinitary 会让你电脑上的 Codex 使用最先到期的那一次。
这需要 Codex 0.143 或更高版本，而且第一次使用时 Codex 会请你登录那个 ChatGPT 账户。
用掉的重置无法退还。
“动态”会说明发生了什么，以及还剩多少次。

Infinitary 也可以不等你点击就使用它们。
在账户的菜单中或那张卡片上打开 **自动使用已保存的重置**；在你打开之前，它一直是关闭的。
此后 Infinitary 只会在有工作等待、没有账户还有额度，而且等额度恢复要很久的时候才使用一次。
还有额度的账户始终优先。
它每使用一次，“动态”都会说明。

## 重新登录 {#sign-in-again}

登录可能会过期。
过期时，账户所在的行会显示 **需重新登录**，并出现一个 **登录** 按钮。
选择它，然后按第一次的方式登录。
这会续用同一个账户，它的标签和选项都会保留。

## 自定义 API {#custom-api}

如果你的组织运行自己的 AI 服务器，请在 **添加账户** 下选择 **自定义 API**。
为它填写名称、服务器的地址、密钥（如果需要的话）以及要使用的模型。
**保存** 会在你的船员们可以使用之前检查每个模型。
之后你在 **模型** 看板上选择你的船员们是否使用这些模型。

### 来自文件的连接 {#connections-from-a-file}

如果你已经把自己的连接写在一个采用 Pi 的 `models.json` 格式的文件里，Infinitary 可以从中读取它们。
在 **AI 订阅** 下的 **连接文件** 一行，点击 **选择文件**，然后选中那个文件。
Infinitary 只读取这个文件：它从不修改文件，也从不使用写在其中的密钥。

文件定义的每个连接都会显示出来，并标有 **来自你的文件** 和 **尚未批准**。
点击 **批准**，输入这台电脑自己的密钥以及文件未写明的模型大小，然后点击 **保存**，它会检查每个模型。

此后 Infinitary 会跟随这个文件。
新的名称或价格会立即生效，而上限有变化时会重新检查那个模型。
地址、协议或请求头有变化时，连接会暂停，直到你点击 **重新批准**。
不再出现在文件中的连接会暂停，绝不会被删除。
**停止读取** 会停止跟随这个文件，你已批准的连接会保留。

### 在你的其他电脑上 {#on-your-other-computers}

当另一台电脑为你运行工作时，自定义连接所在的行会提供 **使用**，并写明是哪台电脑。
你输入那台电脑自己的密钥，它会检查每个模型并自己保存这个密钥；这台电脑不保留副本。
之后对这个连接所做的更改，也会跟着到那台电脑上。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。

## 用量 {#usage}

设置 → **用量** 显示你的大副和船员们在所有项目中用了多少。
它打开时按 **估算 $** 显示；在 **用量显示为** 下可以切换到 **Token**。
选择要统计的 **时段** 和 **工作** 类型。
估算的美元金额只是价值参考，不是账单。

**每个任务的成本** 用图表显示一个已完成的任务花费多少，连同它的审查在内。
每个点是此前 7 天内完成的任务的中位数，色带表示其中间一半。
线条上升表示任务比以前需要更多工作。
**项目** 和 **类型** 可以把范围缩小到你想比较的工作。

**最近的任务** 列出每个任务的用量。

在 **智能** 下，**任务花费超过此金额前先询问** 设置一个金额。
超过这个金额的任务会在一个安全的节点停下，并在花费更多之前用卡片询问你。

## 长对话 {#long-conversations}

对话变长时，你的大副和船员会总结它，并从总结继续，这样每条消息花费更少，对话也仍能放进模型。
在 **智能** 下，**长对话在此处总结** 设置在哪里总结。

- **自动** 在 300,000 个 token 时总结；若模型在更低的位置开始加价，则提前总结。
- **150,000 个 token**、**200,000 个 token**、**300,000 个 token** 或 **500,000 个 token** 在这个数处总结；若模型自身的上限更小，则在其上限处总结。
- **各模型自身的上限** 只在接近各模型自身的上限时才总结，这可能多达一百万个 token。

数越低花费越少；数越高，完整保留的对话越多。
当你选的数让某个模型越过请求开始加价的位置时，这一行会列出该模型和那个位置。
已经打开的对话从下一条消息起遵循更改，在你的其他电脑上也一样；与 Claude 的对话在下次开始时遵循。
