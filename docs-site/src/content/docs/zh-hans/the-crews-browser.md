船员可以为它的任务拥有一个自己的浏览器。
它会打开网站和你的项目提供的网页，阅读它们，在其中点击和输入，并为任务记录拍下它们的图片。
你可以看着它工作，在网页需要人来操作时接管控制，然后再交还给它。
购买、预订或任何其他让你作出承诺的事，始终由你自己来做。

## 任务自己的浏览器 {#a-tasks-own-browser}

浏览器在任务运行的那台电脑上运行，只属于那一个任务。
它启动时是空的，没有登录任何网站，并与你自己的浏览器分开，所以它从不使用你自己浏览器的登录、历史记录或已存储的密码。
如果那台电脑上装有 Google Chrome 或 Microsoft Edge，任务的浏览器就在其中运行，同样保持分开；否则它使用 Infinitary 自己的浏览器。
网页请求的任何内容都不会在你自己的浏览器或其他应用中打开。

船员的浏览器可以打开：

- 通过 https 访问的公共网站；
- 同一台电脑上的网页，例如船员在那里运行的项目；
- 你办公室、家庭或 VPN 网络上的网站，前提是你已把它列在[私有网站](#private-sites)下。

船员操作时，浏览器会拒绝请求使用你的摄像头、麦克风、剪贴板或通知的网页。
请求通行密钥的网站会被告知没有通行密钥，于是它会提供其他方式，例如密码或验证码。
当网页需要登录、验证码或付款时，船员会来问你（[见下文](#when-a-page-needs-you)）。

当船员关闭浏览器、你点击**停止浏览器**、它的任务结束、在无人观看时闲置 30 分钟，或 Infinitary 退出时，浏览器就会停止。
一台电脑最多同时运行四个任务浏览器。

## 看着它工作 {#watch-it-work}

打开任务的卡片，选择它的**浏览器**标签页，上面显示**浏览器**和网页的标题。
在关于这个任务的卡片上，命令搜索中的**显示浏览器**也能打开它。
船员的卡片还可以带一个按钮，例如“试一试”或“查看预订”，在那张卡片旁打开浏览器。

网页上方的一行有**后退**、**前进**和**重新载入**，显示谁在操作，还有**指向**、**接管控制**和**更多**。
你观看时，网页是船员所见内容的图片，你的点击不会传到网页上。
**更多**里有**适应**或**实际大小**、**停止浏览器**、**复制网页地址**和**报告问题**；**报告问题**会开始一条发给大副的消息，由你写完。

网页下方有一行折叠起来的“船员”，显示船员最新的话。
展开它，可以在网页旁阅读船员的对话，并给它写消息。
隐藏或按 Escape 会收起这个视图，浏览器继续运行。

已停止的浏览器会说明它为什么停止。
**重新打开**会启动一个全新的浏览器，停在它之前所在的网页，只登录这个任务仍可使用的网站；任务结束后就不再提供这个选项。

## 接管控制 {#take-control}

1. 点击网页上方那一行中的**接管控制**。
   船员会先完成它当前的操作，那一行显示“正在完成船员当前的操作…”。
2. 那一行显示“由你操作 · 船员看不到这个网页”。
   现在你的点击、滚动、输入和粘贴都会传到网页上。
3. 点击**交还控制权**把它交还给船员。
   在你点击之前，视图会提醒你：“交还控制权后，船员可以读取和使用这个浏览器，包括已登录的网页。”

其他任何事都不会转移控制权：在网页上点击、登录、重定向、隐藏、卡片关闭或计时器都不会。
命令搜索中的**接管或交还浏览器控制权**对屏幕上的浏览器有同样的作用。

在你掌握控制权期间：

- 你在网页上做的任何事都不会被记录，船员也永远不会得知网页在你操作期间显示了什么；
- 请求使用你的摄像头、麦克风、剪贴板或通知的网页，会在网页上方的一行中询问你，提供**允许一次**和**暂不**，交还控制权会收回你允许的权限；
- 请求文件的网页会为你打开 Infinitary 自己的文件选择器。

你交还之后，船员会重新查看网页。
它不会读取你在网页字段中输入的内容：这些字段显示为已填写，文字是隐藏的。
它只在给出理由时才拍下网页的图片，这个理由会写进任务的“动态”中，而且它从不拍下包含你输入内容的网页。

## 指向网页上的某个位置 {#point-at-a-place-on-the-page}

要就网页上的某个位置告诉船员，就指向它。

1. 点击网页上方那一行中的**指向**，或按 ⇧⌘A（Linux 上为 Ctrl+Shift+A）。
   网页会保持静止，你的任何操作都不会传到网页上。
2. 点按一处，拖出一个框，或选择**手绘线**并画一条线。
   用键盘时，用方向键在网页上的各项之间移动，再按 Enter。
3. 输入评论，或留空，然后点击**加入队列**。
   批注中会显示将要发送的那张图片。

按 Escape 会退出**指向**，不留下批注。

网页旁有卡片时，批注会与那张卡片的批注一起等候，并随你的回复发出。
那里没有卡片时，它会在网页旁“船员”的消息框上方等候，并随你发给船员的下一条消息发出。
在你发送之前，任何内容都不会到达船员。
发送后，船员会收到带有你的标记的图片、网页的地址和标题，以及你所标记内容的名称。

你观看时和你接管控制时，**指向**都可以使用。
你接管控制时，批注中会写着“发送后，船员会看到这张页面图片。”

## 当网页需要你时 {#when-a-page-needs-you}

需要人在网页上操作的船员，例如为了登录、验证码或付款，会在一张决定卡片上问你。
卡片会写明网站和原因，并有一个用于你那部分操作的按钮，例如“打开浏览器并登录”，旁边还有一个按钮，例如“先让它等着”。
在此期间，浏览器会等你，任务的浏览器那一行显示“已暂停，等你帮忙”。

点击卡片上的按钮，网页就会在你的控制下打开，卡片在旁边。
卡片会让它的说明和任何要复制的值保持可见，你操作时还可以用它的输入框给船员写消息。
完成后，点击**交还控制权**。
卡片随即消失，船员继续工作，卡片输入框中留下的任何文字都会随你的交还一起发送。

## 已登录的网站 {#signed-in-sites}

当船员请你登录或创建账户时，你登录的内容会保存在那台电脑自己的浏览器配置文件中。
登录适用于整个网站，所以在 example.com 单独的登录页面上登录后，它的其他网页（例如 developer.example.com）也能使用。
当你点击**交还控制权**时，网页上方会出现一个问题，询问以后的任务可以做什么，例如“你的 example.com 登录保留在这台电脑上。以后的任务：”：

- **直接使用，不再询问**排在最前，新网站默认选中它。
  以后的任务无需卡片就以已登录状态打开这个网站，而且每次它的“动态”都会说明这一点。
  它从不涵盖付款或最终提交。
- 选择**每次都问我**时，以后需要这个网站的任务会在它的卡片上询问，卡片会在**我自己登录**旁增加**使用我的 example.com 登录**。
  点一下，那个任务的浏览器就能以已登录状态使用这个网站，你什么都不用输入。

一条规则适用于那台电脑上所有项目中的任务。
使用已登录网站的浏览器只以登录状态打开这个网站以及登录过程中经过的登录页面；其他任何网站都以未登录状态打开。
任务的浏览器自行停止或应用重启后，任务仍保留它可以使用的已登录网站，直到你点击**停止浏览器**或任务结束。
当你出于其他原因登录时，例如在你自己点击**接管控制**之后，这个登录通常只持续到那个浏览器停止为止。
网页下方的一行会说明是哪一种，例如“临时 · 保留你登录的内容，直到它停止”。

每台电脑都保留自己的登录，不会把任何登录复制到另一台电脑或文件中。
它们保存在那台电脑的浏览器配置文件中，不在受保护的存储中，所以它们的安全程度与那台电脑自身的登录和磁盘相同。

在大副所在的电脑上，这个列表位于“设置”→**机密**中的**已登录的网站**下，每台电脑的网站列在它的名称下。
在从别处控制大副的电脑上，它位于“设置”→**通用**中的**网站登录**下。
每个网站都显示你登录的时间、它的**以后的任务**规则和**移除**；**移除**会立即在那台电脑上退出这个网站的登录。
**全部移除**会让那台电脑退出所有网站的登录，包括从未加入列表的登录。

网站会不时结束自己的登录，这时船员会再次请你登录。
如果保留的登录没能让网页登录，下一张卡片会把**我自己登录**放在最前，并保留**使用我的登录（上次未成功）**作为第二个选择。

## 私有网站 {#private-sites}

你办公室、家庭或 VPN 网络上的网站，只有在你把它列入列表后才能访问。
当船员需要访问这样的网站时，大副会在一张卡片上问你，例如“允许任务浏览器访问 wiki.corp.example 吗？”。
点击**允许**添加它，或点击**暂不**；大副从不自行添加网站。

这个列表位于“设置”→**集成**中的**私有网站**下，适用于你所有的电脑。

- 点击**网站**，输入一个名称，例如 `wiki.corp.example`，然后点击**添加**。
- 像 `.corp.example.com` 这样的后缀涵盖它下面的所有名称。
- 一个条目是一个名称，绝不是数字地址。
- **移除**会把一个网站从列表中删去，任务浏览器会立即停止访问它。

列表中的网站可以通过 https 或 http 从任何网页打开，就像在普通浏览器中一样。
它永远无法访问只在电脑内部监听的程序。

## 购买和预订由你来做 {#purchases-and-bookings-are-yours}

购买、预订或任何其他让你作出承诺的提交，都由你在网站自己的网页上、在你的控制下完成。
船员会一直填写到最后一个按钮，然后停在那里。

接着它会在一张审核卡片上询问你，卡片写明你要承诺的内容，内容读取自网页当前的状态。
对于一次旅行，这包括路线、日期和时间、乘客、销售方、总价和币种，以及行李和票价规则。
卡片还会写明任何仍不确定的内容，以及自你上次选择以来发生了什么变化。
它的按钮写明你那部分操作，例如“打开浏览器并付款”，旁边还有一个按钮，例如“到此为止”。

- 如果审核之后价格或条款发生变化，船员会停下来再次询问。
- 在你付款并交还控制权之后，船员会读取网页上显示的结果，并只保留结果，例如预订编号。
  你输入的银行卡信息对它保持隐藏。
- 如果网页没有确认，船员会明确说它不知道是否已经成功。
  它从不再次发送，并会先在网站列出它的地方查看，例如你的预订，然后再问你。
- 浏览器从不把一个表单发送两次：重新载入一个已经回应过表单的网页不会再次发送它。

## 文件和下载 {#files-and-downloads}

网页下载的文件，包括你掌握控制权期间下载的文件，都会和任务的证据一起保存，任务的“动态”会记下每一个。
当网页请求文件时，船员只能提供任务工作副本中的文件。
它没有的文件需要由你来提供：它会在一张把浏览器交给你的卡片上问你。

## 在你的其他电脑上 {#on-your-other-computers}

在你的另一台电脑上运行的任务，它的浏览器也在那台电脑上。
你可以从任何窗口观看它并接管控制，就像对待这台电脑上的浏览器一样。
那台电脑保留自己的已登录网站，[私有网站](#private-sites)列表在那里同样适用。
在你掌握控制权期间，那台电脑上请求文件的网页会等待船员处理，因为 Infinitary 的文件选择器无法访问那台电脑。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。
