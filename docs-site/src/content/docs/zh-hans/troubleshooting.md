下面的每个问题都以 Infinitary 显示给你的文字开头。

## 某个订阅需要你重新登录 {#a-subscription-needs-you-to-sign-in-again}

你可能会看到一张标题为“你的大副需要你重新登录”的卡片，或者在设置 → “**智能**”中看到某个订阅写着“重新登录”。
该订阅上的工作会等待：“工作已暂停，直到你重新登录。”

1. 点击卡片上的“**登录**”，或打开设置 → “**智能**”。
2. 按服务商的要求登录该订阅。
3. 等待中的工作会自动继续。

在另一台电脑上运行的任务使用那台电脑自己的登录，所以请在那台电脑的名称下为它重新登录。

## 你的套餐额度用完了 {#your-plans-allowance-ran-out}

你的大副会显示一张标题为“你的大副已用完它的额度”的卡片。
你在该订阅上回复某个船员时，会显示“已保存，尚未发送”，并写明额度何时重置。
额度重置后，工作会自动继续。

要更早继续：

- 如果你在服务商那边更改了设置，请点击“**重新检查额度**”。
- 如果重新检查没有发现变化，卡片还会提供再试一次服务商的选项，例如 **Try Claude again**：你的话会发送一次，如果额度仍然用完，大副会再次暂停。
- 如果卡片提供了另一个服务商，请点击“**转到**”该服务商。
- 请你的大副把工作转到另一个模型。

设置 → “**智能**”会显示每个套餐的额度还剩多少，以及何时重置。
对于 Claude 和 Codex，“**用点数继续**”可以让账户用你在服务商那里设置的点数继续工作。

## 你的大副没有回答 {#your-first-mate-is-not-answering}

如果某条消息没有得到任何回复，会有一张卡片写着“你的大副没有回答你的消息”。
点击“**再问一次**”重新发送，或点击“**算了**”。

如果是服务商本身没有回答，会有一张卡片写着它“暂时没有回答你的大副”。
点击“**再试一次 Claude**”，或写着你的服务商名称的同一个按钮，或点击“**打开设置**”选择另一个订阅。
当服务商出现短暂问题时，动态会说明，应用也会自行重试。

## 有船员在等待 {#a-crewmate-is-waiting}

写着“**等你处理**”的任务有一张卡片在等你。
打开这个任务，点击“**显示卡片**”，然后做出决定。

任务上的其他文字说明了它被什么拖住：

- “等待检查”：它的船员在等它的拉取请求上的检查。
- “正在向服务商重试”：服务商失败了，应用会自行重试。
- “卡在服务商处”：服务商三次拒绝了同一个请求，你的大副正在选择怎么办。
- “被另一个任务阻挡”：那个任务完成后它才会开始。

## 拉取请求上的检查未通过 {#the-checks-failed-on-a-pull-request}

检查未通过时，创建这个拉取请求的船员会修复问题，并带来一个新版本。
随后合并卡片会提供“**修复错误后合并**”。
如果你点击它，你的合并会被保留：“你的合并在等待修复：检查未通过。”
等修复的检查通过后它就会执行；如果修复改变了工作，船员会用一张新卡片再问你一次。

## 另一台电脑无法联系 {#another-computer-is-out-of-reach}

另一台电脑上的窗口会写着：另一台电脑回来之前“暂不能更改”。它可能在睡眠，或在另一个网络上。
或者写着：那台电脑上的“Infinitary 已关闭”。

1. 唤醒大副所在的电脑，并在那里打开 Infinitary。
2. 让两台电脑处于同一个网络，或同一个私有网络。
3. 在设置 → “**设备**”中，点击它那一行的“**重试**”。

如果你按地址添加的电脑有了新地址，请打开它的菜单（它那一行上的三个点），然后选择“**更改地址**”。
在 Mac 上，macOS 可能会阻止 Infinitary 使用本地网络，直到那台 Mac 前的人允许它。
这时它那一行会改为提供“**按地址添加**”。
请参阅[你的其他电脑](/zh-hans/your-other-computers/)。

## 一台电脑出现了两次 {#a-computer-is-listed-twice}

设置 → “**设备**”中同一个名称出现了两次：一行可以联系，另一行无法联系，而且上面还有任务。
当一台运行工作的电脑在它已保存的工作被删除后重新加入，或者在那里全新安装了 Infinitary 之后，就会这样。
可以联系的那一行会写着“同名同用户的一个较早条目无法联系”。

1. 在可以联系的那一行上，点击“**在这里继续它的任务**”。
2. 读一读哪些会继续、哪些会留下，然后点击“**继续这些任务**”。
3. 每个任务都从大副所在的电脑带回的最后一个提交继续。
   每个任务都移走之后，较早的那一行就会从你的列表中消失。

那个提交之后的提交、未提交的编辑以及旧任务文件夹中的文件，都会留在旧条目上。
对于一行无法联系、又没有对应条目的电脑，点击“**把它的任务移到…**”，然后选择一台电脑。
请参阅[什么会删除你已保存的工作](/zh-hans/update-and-remove/#what-deletes-your-saved-work)。

## 窗口不再响应 {#the-window-stops-answering}

先稍等片刻。
如果一直卡住，请退出 Infinitary 再重新打开。
你的大副或某个船员尚未处理完的消息，会在它打开时重新接上。

## macOS 询问其他应用的数据 {#macos-asks-about-other-apps-data}

macOS 可能会询问“‘Infinitary’想访问其他 App 的数据。”
当船员的搜索触及另一个应用保存的文件时，就会出现这种情况。
Infinitary 的工作很少需要这些文件，所以通常点击“**不允许**”就可以。
在你回答之前，任务的记录会写着“正在等待 macOS”，之后搜索会继续。

## 找不到 Claude Code {#claude-code-is-missing}

要使用 Claude 订阅，请先在那台电脑上安装 Claude Code。
没有它的话，Infinitary 会说“这台电脑上没有安装 Claude Code。请安装它，以便在这里使用 Claude。”
如果你的版本太旧，它会写出所需的版本，并提示运行 `claude update`。
在另一台电脑上，Claude Code 在那里自行登录：只需在那里登录一次，Infinitary 就会使用那个登录。

## 仍然卡住 {#still-stuck}

请参阅[获取帮助](/zh-hans/get-help/)。
说明你做了什么、你期望发生什么，以及实际发生了什么。
