開始之前，請先確認 [你需要什麼](/zh-hant/install/)。
這一頁會帶你走過第一次打開 Infinitary 的過程，以及之後會有哪些不同。

## 視窗會顯示什麼 {#what-the-window-shows}

第一次打開 Infinitary 時，大副會在視窗中央迎接你。
它上方寫著 **歡迎登上 Infinitary，船長**，還有一段大副說的話：

> 我是你的大副。
> 我會幫你管理其他船員。
> 請把我設定在一台盡量保持開機的電腦上。
> 你的其他裝置需要我保持運作。

下面是大副可以使用的每個供應商的按鈕：Codex、Grok、Claude、Kimi Code、Copilot、OpenRouter、Amazon Bedrock 和自訂 API。

底部的訊息框是暗的，上面寫著「請先連結一個訂閱方案」。
在有訂閱方案能回應大副之前，其他功能都無法使用。

## 連結訂閱方案 {#connect-a-subscription}

1. 選擇你的供應商按鈕。
2. 依照那個供應商的要求登入。
   有些會在瀏覽器裡打開登入頁面。
   Copilot 和 Kimi Code 會顯示一組代碼：按 **複製代碼**，然後在供應商的網站上輸入。
   OpenRouter 要你貼上一組 API 金鑰。
   使用 Amazon Bedrock 時，選擇一個區域，並使用這台電腦上的 AWS 設定檔，或貼上 Bedrock API 金鑰。
   兩種都提供的供應商，會問你要 **用瀏覽器登入** 還是貼上 **API 金鑰**。
3. 視窗顯示正在連結時，請稍候。
   訂閱方案可以回應後，歡迎畫面會淡出，訊息框也會開啟。

如果你使用 Claude，Infinitary 會使用你安裝在這台電腦上的 Claude Code。
沒有它的話，Claude 按鈕會告訴你先安裝 Claude Code。

如果已經連結訂閱方案但仍然無法回應，視窗會顯示 **在這台電腦上設定你的大副**，並說明還缺什麼。

## 如果你的大副已經在另一台電腦上 {#if-your-first-mate-already-lives-on-another-computer}

在供應商按鈕下方，第二組寫著「你的大副在另一台電腦上」。
用 **貼上它的連結** 或 **用位址加入**，就能從這裡控制那位大副，而不必設定一位新的。
請看 [你的其他電腦](/zh-hant/your-other-computers/)。

## 診斷通知 {#the-diagnostics-notice}

訊息框下方的通知會說明診斷傳送什麼，以及它絕不包含你輸入的內容。
選 **好** 保持開啟，或選 **關閉**。
你之後可以在 [設定](/zh-hant/settings/#general) 裡更改。
請看 [哪些東西會離開你的電腦](/zh-hant/what-leaves-your-computer/)。

## 歡迎卡片 {#the-welcome-card}

大副可以回應後，會出現一張標題為 **我們的合作方式** 的卡片。
它是一張視窗的小圖，一次顯示一個部分。
按 **下一頁** 和 **上一頁**，就能看到訊息框、卡片、左側的「動態」和右側的「任務」。

圖片下方有三個開場句：

- **複製一個專案**
- **開始一個新專案**
- **在我電腦上的資料夾裡工作**

按下其中一個，就會在訊息框裡放上一句話的開頭，例如「複製這個網址的專案：」。
把句子寫完再送出。
開場句本身不會傳送任何東西。

歡迎卡片沒有回覆欄位：你要在它下面的訊息框裡輸入。
隨時都可以關閉它。

## 加入你的第一個專案 {#add-your-first-project}

你的大副需要一個專案來工作。
最簡單的方法是用歡迎卡片上的開場句，或在你自己的訊息裡寫同樣的話。

你提出要求後，大副會顯示一張卡片，寫出專案名稱以及它會如何設定。
確認卡片上的選擇，然後按 **加入專案**，或按 **暫時不要** 先擱著。
在你按下 **加入專案** 之前，什麼都不會加入。

你也可以在設定 → 專案裡，用 **加入專案** 自己加入專案。
那裡的選項請看 [專案](/zh-hant/projects/)。

## 之後的啟動 {#later-launches}

當有訂閱方案可以回應時，Infinitary 會直接打開到訊息框。
你的卡片、任務和船員都在你離開時的位置。

Infinitary 更新後，會有一張卡片寫出新版本以及變更了什麼。
你之後可以在 [設定 → 一般](/zh-hant/settings/#general) 的「版本」底下再讀一次。
在 Mac 上，「說明」選單裡的 **Infinitary 的新功能** 也能打開它。

如果你最後一個訂閱方案停止運作，例如因為你登出了，歡迎畫面會再次出現，直到有訂閱方案能再次回應。
如果你的方案額度用完了，大副會改為顯示一張說明這件事的卡片，並保留你的訊息，直到它能回應為止。
請看 [訂閱方案與額度](/zh-hant/subscriptions-and-quota/)。

如果想在登入電腦時打開 Infinitary，請在設定 → 一般裡開啟 **登入時啟動**。
