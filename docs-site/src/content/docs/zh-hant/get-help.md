## 提出疑問或回報問題 {#ask-a-question-or-report-a-problem}

- 加入我們的 [Discord 伺服器](https://discord.gg/Wsy2NpnZDu)，在那裡發問。
- 或寫信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。

請說明你做了什麼、預期會發生什麼，以及實際發生了什麼。
附上一張視窗的截圖會很有幫助。

## 回報安全性問題 {#report-a-security-issue}

請私下寫信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。
請不要在 Discord 上公開安全性問題。
