## 提出疑問或回報問題 {#ask-a-question-or-report-a-problem}

- 加入我們的 [Discord 伺服器](https://discord.gg/Wsy2NpnZDu)，在那裡發問。
- 或寫信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。

請說明你做了什麼、預期會發生什麼，以及實際發生了什麼。
附上一張視窗的截圖會很有幫助。

## 在 App 裡傳送意見回饋 {#send-feedback-from-the-app}

你不必離開 App，就能向 Infinitary 的開發者回報問題或提出想法。

1. 在任何一個訊息框輸入 `/feedback` 和幾句話，然後送出。
   「說明」選單中的 **傳送意見回饋…** 和指令搜尋中的 **傳送意見回饋** 也能開始。
2. 一位船員會為 Infinitary 在 GitHub 上的公開專案草擬一個議題，並帶一張卡片給你。
   卡片上顯示的就是即將發布的議題。
3. 讀過之後，按 **送出意見回饋**。

你按下後，議題會用你自己的 GitHub 帳號公開發布，僅一次。
在你按下之前，不會發布任何東西。
如果 Infinitary 沒有 GitHub 登入，卡片會改成給你一個連結。
它會打開 GitHub 的議題表單，裡面已經填好回報內容，由你在那裡發布。

回報內容不包含你的名字、資料夾、專案和登入。
請參閱[哪些東西會離開你的電腦](/zh-hant/what-leaves-your-computer/#feedback-you-send)。

## 回報安全性問題 {#report-a-security-issue}

請私下寫信到 [help@getinfinitary.com](mailto:help@getinfinitary.com)。
請不要在 Discord 上公開安全性問題。
