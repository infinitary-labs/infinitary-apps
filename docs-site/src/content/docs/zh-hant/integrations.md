## 整合在哪裡 {#where-integrations-live}

開啟 **設定**，再選 **整合**。
你也可以在指令搜尋中搜尋 **開啟整合**。

每一列是一個連線。
列上會顯示連線的名稱、它以誰的身分登入或執行什麼，以及有幾個動作是開啟的。
打開一列，就能看到它的動作，以及它能通知你的自動化哪些事。

每一列最後的選單有：

- **立即檢查**：檢查連線是否仍然正常。
- **暫停**：在你按下 **繼續** 之前，誰都無法使用它。
- **登出並移除**，MCP 伺服器則是 **移除**。

清單下方的按鈕可以連結新的東西，例如 **GitHub**、**Google** 或 **MCP 伺服器**。
你也可以請大副幫你連結。
登入一定要由你自己完成，所以大副會給你一張卡片，用來開啟這個分頁。

## GitHub、GitLab、GitHub Enterprise 和 Bitbucket {#github-gitlab-github-enterprise-and-bitbucket}

你在專案所在處的登入保存在這裡。
Infinitary 如何用它來複製專案、提出變更，請看 [專案](/zh-hant/projects/#your-github-gitlab-or-bitbucket-sign-in)。

- **GitHub**：在瀏覽器裡的 GitHub 頁面輸入一組代碼。
  如果這台電腦上有 GitHub CLI，而你的組織封鎖了 Infinitary 這類應用程式，**使用 GitHub CLI** 會沿用 GitHub CLI 已有的登入。
- **GitLab**：在瀏覽器裡登入，或貼上一把金鑰，gitlab.com 或你自己的 GitLab 伺服器都可以。
- **GitHub Enterprise**：在你自己的伺服器上產生一把金鑰，貼到這裡。
- **Bitbucket**：在你的 Atlassian 帳號產生一個 API token，貼到這裡，用於 bitbucket.org。
  如果是你自己的 Bitbucket Data Center 伺服器（8.19 或更新版本），你要輸入它的位址，並貼上你在上面產生的 HTTP 存取權杖，權杖要有 Project read 和 Repository write 權限。
  Data Center 這一列目前還沒有任何動作。

每一列都有兩個動作：一個用來讀取，一個用來變更內容，例如 **在 GitHub 上變更內容**。
大副和船員在任務本身的工作之外，要在那裡查資料或採取行動時，用的就是這兩個動作。
任務的分支、pull request、檢查和合併，則依照你專案的設定進行。

如果有另一台電腦替你執行工作，它自己用來在那裡複製和推送的 GitHub 登入，也會在這裡有一列。
請看 [你的其他電腦](/zh-hant/your-other-computers/)。

登出 GitHub 後，在你重新登入之前，私人存放庫的複製和 pull request 都會停止。

## Google：Gmail 和日曆 {#google-gmail-and-calendar}

Google 用一個登入同時連結 Gmail 和日曆。

1. 按 **Google**。
2. 閱讀 **連結 Google 之前**：Infinitary 會使用你帳號中的哪些內容、這些內容會送到哪裡，以及保留多久。
3. 按 **接受並前往 Google**，或按 **取消**，不向 Google 要求任何東西。
4. 在瀏覽器裡的 Google 頁面完成登入，並允許它列出的每一項權限。

如果你有一項權限沒有勾選，Infinitary 什麼都不會保存，你可以重新登入。
每次登入 Google，都會先顯示這則說明。

連結 Google 後，大副和船員可以搜尋和閱讀你的郵件、把附件存到任務的資料夾、為郵件加標籤或封存、撰寫草稿，以及寄出郵件。
在日曆中，他們可以列出你的日曆和活動、讀取一項活動、查看你什麼時候忙碌，以及建立或更新活動。
沒有任何動作會刪除日曆活動。

大副和船員讀到的內容，會在他們保存的對話中保留 30 天。
之後會換成一則說明。
要提早刪除，請在分頁最下方 **資料** 底下的 **刪除 Gmail 和日曆內容** 那一列按 **刪除**。
存下來的附件會留在任務的資料夾中，直到任務關閉或經過 30 天。
船員在存下的附件裡讀到的文字，過了 30 天仍會留在它的對話中。
大副和船員自己寫下的內容，包括卡片、筆記和檔案，會保留到你刪除任務為止。
移除 Google 不會刪除他們已經讀過的任何內容。

任何人都可以寄給你專門用來操縱 AI 的文字。
Infinitary 把你的郵件和活動交給大副和船員時，會標示為來自外部的資訊，絕不當作指示。
但一則訊息仍然可能誤導 AI 模型。
船員可以不經詢問就連上網際網路，所以被誤導的船員可能會把讀到的內容傳到別處。

## MCP 伺服器 {#mcp-servers}

MCP 伺服器是一個程式或網址，提供動作給 AI 應用程式使用。

1. 按 **MCP 伺服器**。
2. 為它取一個 **名稱**。
3. 在 **執行** 底下，輸入一個程式和它的參數，或伺服器的 https 位址。
4. 按 **連結**。

程式會在有人使用它時，在這台電腦上啟動。
Infinitary 會立刻連結，並在新的一列打開伺服器自己的動作清單。
如果無法連結，表單會說明原因。

如果伺服器需要金鑰，請自己把它放在 **執行** 那一行的開頭，例如 `EXAMPLE_KEY=your-key npx -y @example/mcp-server`。
Infinitary 會把金鑰移到 [機密](/zh-hant/secrets/)，那一行只留下指向它的參照。
伺服器每次啟動時都會取得這把金鑰，不會詢問你。
你的大副和船員永遠看不到它。
移除伺服器時，它的金鑰也會一併忘記。

## 每個動作可以不經詢問就做什麼 {#what-each-action-may-do-without-asking-you}

打開的一列會列出每個動作和它做的事：**讀取**、**變更** 或 **傳送**。
每個動作一開始都是 **詢問你**，讀取也一樣。
按一下它的規則，就能在 **詢問你** 和 **一律允許** 之間切換。
只有你能更改規則。
動作旁邊的開關可以把它關閉，關閉後誰都無法執行它。

當大副或船員使用一個會詢問你的動作時，Infinitary 會放上它自己的核准卡片。
卡片會清楚顯示將要執行的內容，以及提出的理由。

- **一律允許** 會執行它，之後這個動作就不再詢問，直到你在設定中更改、替換這個連線，或這個動作本身改變。
- **在這項任務剩下的時間都允許**：出現在船員的請求上，會執行它，並讓這位船員在任務關閉前，可以在同一個地方不經詢問就執行同一個動作。
  卡片會說明這個地方是什麼，例如 GitHub 上的某個存放庫，或某則訊息的收件人。
- **只限這次** 會執行一次。
- **暫時不要** 什麼都不執行。

當一位船員在同一個連線上請求好幾次時，這些請求會共用一張卡片，每個請求一列，各有一個已勾選的 **允許** 方塊。
取消勾選某一列，它就永遠不會執行。
把卡片放到一旁，裡面的請求會繼續等待。

如果 Infinitary 無法確定一項變更是否已經送達，它絕不會再傳送一次。
整合回覆的內容，對大副和船員來說都是資訊，絕不是指示。

面板也可以使用它指名的整合。
它的請求會跳出同樣的卡片，並註明是哪個面板。
請看 [面板](/zh-hant/panels/)。

## 整合可以通知什麼 {#what-an-integration-can-tell}

有些連線會在某件事發生時發出通知，自動化可以等待這個通知。
打開的一列會把這些列出來，並標示 **通知**。

- GitHub：在你指定的存放庫中，**工作流程執行失敗** 和 **工作流程執行完成**。
- Gmail：**收到郵件**。
- 日曆：**日曆活動有變更**。
- 有提供這項功能的 MCP 伺服器：**資源有變更**。

在自動化的 **當某件事發生時** 底下選擇其中一個。
請看 [自動化](/zh-hant/automation/#when-it-runs)。

## Infinitary 指令 {#the-infinitary-command}

**Infinitary 指令** 方塊是給你在這台電腦上執行的程式，以及你自己的 AI 代理使用的。
只要一個指令，它們就能讀取並處理你的卡片和任務，也能以你的身分和大副對話。
船員永遠不會拿到它。

在你開啟之前，它是關閉的。
開啟後，方塊會顯示要執行的那一行，附有 **複製**，可以的話，**建立連結** 會提供一個較短的名稱。
第一次開啟時，它也會一併開啟一個自動化 **Infinitary 收件匣事件**，讓程式每傳來一則筆記，大副都會收到通知。
筆記是資訊，絕不是指示。

關閉後，這個指令會回覆錯誤，已保存的筆記則會保留。
**資料** 底下的 **刪除 Infinitary 收件匣筆記** 會移除這些筆記，並把它關閉。

## 私人網站 {#private-sites}

**私人網站** 方塊列出你公司、家中或 VPN 網路上，任務瀏覽器可以開啟的網站。
這份清單適用於你所有的電腦。
按 **網站** 新增一個，按 **移除** 拿掉一個。
大副絕不會自己新增網站：它會用卡片問你，只有你按下 **允許** 才會新增。
請看 [船員的瀏覽器](/zh-hant/the-crews-browser/#private-sites)。
