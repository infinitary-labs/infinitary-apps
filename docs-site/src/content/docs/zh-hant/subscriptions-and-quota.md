你的大副和船員透過你已經有的 AI 訂閱方案工作。
你可以在設定的 **智慧等級** 底下，於 **AI 訂閱方案** 清單裡管理它們。

## 加入訂閱方案 {#add-a-subscription}

1. 打開設定，選擇 **智慧等級**。
2. 在 **AI 訂閱方案** 底部的 **新增帳號** 底下，選擇你的供應商：Codex、Grok、Claude、Kimi Code、Copilot、OpenRouter 或 Amazon Bedrock。
3. 依照供應商的要求登入。
   有些會打開你的瀏覽器，有些會顯示一組要在它們網站上輸入的代碼，有些則要你貼上一組金鑰。
4. 登入完成後，新的帳號會出現在清單裡。

同一個供應商可以加入不只一個帳號。
這時它的按鈕會顯示像是 **再加入一個 Codex 帳號** 這樣的字。

## 為帳號命名 {#name-your-accounts}

每個帳號都有一個標籤，讓你分得出個人帳號和工作帳號。
如果登入時沒有帶出帳號名稱，會打開一個名稱方塊讓你輸入。
之後想更改，可以打開帳號的選單並選擇 **重新命名**。

Claude 帳號不太一樣。
它會跟隨你電腦上 Claude Code 的登入，所以它那一列會顯示目前在那裡登入的人。
它沒有 **重新命名**，如果你切換 Claude Code 的登入，那一列也會跟著改變。

每個帳號都會為它供應商的每一種額度顯示一個小量表，例如每次對話和每週。
數字是還剩多少。
把指標停在量表上，就能看到它何時重設。

- 當你用得比時間快時，長條會變成琥珀色：以這個速度花用，撐不到重設的時候。
- 數字低於一半時會變成琥珀色，低於五分之一時會變成紅色。
- 量表旁邊會用一個詞總結這個帳號：**剛好**、某段時間 **後用完**，或 **已用完**。
- **截至 3 小時前** 表示最後一次讀數已經是舊的，所以它的數字會變暗。
- 破折號表示那項額度沒有讀取到。

清單頂端的 **重新整理** 會重新讀取每一項額度。
Infinitary 不會讀取 OpenRouter 或自訂 API 的額度，那一列也會說明這件事。
Amazon Bedrock 依用量向你的 AWS 帳號計費；它那一列會根據 Infinitary 記錄的工作，顯示本月的估計金額。

## 選擇哪個帳號做什麼 {#choose-which-account-does-what}

打開帳號的選單（它那一列上的三個點），就能看到這些選擇。

- **優先用於船員工作** 會讓船員優先使用這個帳號。
  它會標上 ✱。
- **暫停** 會停止這個帳號上的所有工作，直到你選擇 **繼續**。
- **中斷連結** 會把這個帳號從 Infinitary 移除。

當大副使用的供應商有兩個以上的帳號時，設定會讓你選擇大副要用哪一個來回答。
那個帳號會標上 **大副** 標籤。

## 額度用完時 {#when-an-allowance-runs-out}

你的船員會自己繼續下去。
新的工作會交給還有額度的模型。
如果那個等級已經沒有額度了，船員的工作會改用較弱的模型，或等到額度重設。

當大副自己的帳號用完時，它會先換到同一個供應商、還有額度的另一個帳號。
如果沒有，會出現一張寫著 **你的大副已用完它的額度** 的卡片。
你的話會先等著，什麼都不會遺失。
在卡片上，你可以選擇 **重新檢查額度**、把大副換到另一個供應商，或 **開啟設定**。

有些供應商可以用你在它們那裡設定的點數繼續回答。
對於 Claude 或 Codex 帳號，選單裡有 **用點數繼續**。
這時船員只會在用完每一項包含的額度後才花用點數。
Infinitary 絕不會購買點數，也不會設定點數的上限；這些都在供應商自己的網站上處理。

## 重新登入 {#sign-in-again}

登入可能會失效。
失效時，帳號那一列會顯示 **重新登入**，並出現一個 **登入** 按鈕。
選擇它，然後像第一次那樣登入。
這會更新同一個帳號，它的標籤和選擇都會保留。

## 自訂 API {#custom-api}

如果你的組織自己執行 AI 伺服器，請在 **新增帳號** 底下選擇 **自訂 API**。
為它取一個名稱，填入伺服器的位址、需要的話再填入金鑰，以及要使用的模型。
**儲存** 會在船員能使用之前檢查每個模型。
接著你可以在 **模型** 看板上，選擇船員是否使用這些模型。

## 用量 {#usage}

設定 → **用量** 會顯示大副和船員在所有專案中用了多少。
可以用 **Token** 或 **估計 $** 顯示，並依 **期間** 和 **工作** 的種類篩選。
估計的美元金額是價值的參考，不是帳單。
**最近的任務** 會列出每項任務用了多少。

在 **智慧等級** 底下，**任務花費超過此金額前先問過你** 可以設定一個金額。
超過這個金額的任務，會在一個安全的時間點停下來，先用卡片問過你，才會再花用。
