船員可以為自己的任務擁有一個專屬的瀏覽器。
它會打開網站和你的專案提供的網頁、閱讀內容、在上面點按和輸入，並為任務紀錄截圖。
你可以觀看它工作，在網頁需要真人時接手控制，然後再交還給它。
購買、訂位，或其他任何會讓你做出承諾的事，一律由你自己來做。

## 任務專屬的瀏覽器 {#a-tasks-own-browser}

瀏覽器在執行任務的那台電腦上執行，只屬於那一項任務。
它一開始是空的，所有網站都是登出狀態，並和你自己的瀏覽器分開，所以絕不會用到你自己瀏覽器的登入、瀏覽紀錄或儲存的密碼。
那台電腦上裝有 Google Chrome 或 Microsoft Edge 時，任務的瀏覽器會在其中執行，同樣保持分開；否則就使用 Infinitary 自己的瀏覽器。
網頁要求開啟的任何東西，都不會在你自己的瀏覽器或其他程式中打開。

船員的瀏覽器可以打開：

- 透過 https 連線的公開網站；
- 同一台電腦上的網頁，例如船員在那裡執行的專案；
- 你公司、家裡或 VPN 網路上的網站，前提是你已把它列在[私人網站](#private-sites)中。

船員操作時，瀏覽器會拒絕要求使用你的相機、麥克風、剪貼簿或通知的網頁。
要求使用密碼金鑰的網站會被告知沒有密碼金鑰，因此它會提供其他方式，例如密碼或驗證碼。
網頁需要登入、驗證碼或付款時，船員會來問你（[見下方](#when-a-page-needs-you)）。

船員關閉瀏覽器、你按下「**停止瀏覽器**」、任務關閉、沒人觀看時閒置 30 分鐘，或 Infinitary 結束時，瀏覽器就會停止。
一台電腦同時最多執行四個任務瀏覽器。

## 觀看它工作 {#watch-it-work}

打開任務的卡片，選擇它的「**瀏覽器**」分頁，分頁上會顯示「**瀏覽器**」和網頁的標題。
在關於這項任務的卡片上，也可以用指令搜尋中的「**顯示瀏覽器**」打開它。
船員的卡片也可能附有一個按鈕，例如「試試看」或「查看訂位」，會在那張卡片旁打開瀏覽器。

網頁上方的列有「**上一頁**」、「**下一頁**」和「**重新載入**」、目前誰在操作、「**指向**」、「**接手控制**」和「**更多**」。
你在觀看時，網頁是船員所見畫面的一張圖片，你的點按不會傳到網頁上。
「**更多**」裡有「**符合大小**」或「**實際大小**」、「**停止瀏覽器**」、「**複製網頁網址**」和「**回報問題**」；「回報問題」會替你開始一則給大副的訊息，讓你寫完。

網頁下方有一行收合的「船員」，顯示船員最新說的話。
展開它，就能在網頁旁閱讀船員的對話，並寫訊息給它。
按「隱藏」或 Escape 會收起這個畫面，瀏覽器則會繼續執行。

已停止的瀏覽器會說明它停止的原因。
「**再次開啟**」會在原本的網頁開啟一個全新的瀏覽器，只登入這項任務仍可使用的網站；任務關閉後就不會再提供這個選項。

## 接手控制 {#take-control}

1. 在網頁上方的列按「**接手控制**」。
   船員會先完成目前的動作，這一列會顯示「正在等船員完成目前的動作…」。
2. 這一列會顯示「你正在操作 · 船員看不到這個頁面」。
   現在你的點按、捲動、輸入和貼上都會傳到網頁上。
3. 按「**交還控制**」把它交還給船員。
   在你按下之前，畫面會提醒你：「交還控制後，船員就能讀取和使用這個瀏覽器，包括已登入的網頁。」

其他任何事都不會轉移控制權：在網頁上點按、登入、重新導向、「隱藏」、卡片關閉或計時器都不會。
指令搜尋中的「**接手或交還瀏覽器控制**」對畫面上的瀏覽器有相同的作用。

你在控制時：

- 你在網頁上做的任何事都不會被記錄，船員也永遠不會知道網頁在你操作期間顯示了什麼；
- 要求使用你的相機、麥克風、剪貼簿或通知的網頁，會在網頁上方的一行詢問你，並提供「**允許一次**」和「**暫時不要**」，而交還控制會收回你允許的權限；
- 要求選擇檔案的網頁，會為你打開 Infinitary 自己的檔案選擇器。

你交還之後，船員會重新查看網頁。
它不會讀取你在網頁欄位中輸入的內容：那些欄位會顯示為已填寫，但文字是隱藏的。
它只會在說明理由時才為網頁截圖，理由會記在任務的「動態」中，而且絕不會截取含有你輸入內容的網頁。

## 指向網頁上的某個位置 {#point-at-a-place-on-the-page}

想針對網頁上的某個位置告訴船員，就指向它。

1. 在網頁上方的列按「**指向**」，或按 ⇧⌘A（Linux 和 Windows 上是 Ctrl+Shift+A）。
   網頁會靜止不動，你做的任何事都不會傳到網頁上。
2. 按一下某處、拖出一個框，或選擇「**手繪線**」並畫一條線。
   用鍵盤時，用方向鍵在網頁上的各個項目之間移動，再按 Enter。
3. 輸入留言，或留空，然後按「**加入佇列**」。
   筆記裡會顯示即將送出的那張圖片。

按 Escape 會離開「**指向**」，不留下筆記。

網頁旁有卡片時，筆記會和那張卡片的筆記一起等著，並隨你的回覆送出。
那裡沒有卡片時，它會在網頁旁「船員」的訊息框上方等著，並隨你給船員的下一則訊息送出。
在你送出之前，任何東西都不會傳給船員。
送出後，船員會收到畫上你的標記的圖片、網頁的網址和標題，以及你所標記項目的名稱。

你在觀看時和你正在控制時，都可以使用「**指向**」。
你正在控制時，筆記裡會寫著「送出後，船員會看到這張頁面圖片。」

## 網頁需要你時 {#when-a-page-needs-you}

船員需要真人在網頁上處理登入、驗證碼或付款時，會用一張決定卡片問你。
卡片會寫出網站和原因，並提供一個代表你要做的步驟的按鈕，例如「打開瀏覽器並登入」，旁邊還有一個像是「先讓它等著」的按鈕。
在這段期間，瀏覽器會等你，任務的「瀏覽器」那一行會顯示「已暫停，等你協助」。

按下卡片上的按鈕，網頁就會在你的控制下打開，卡片則在旁邊。
卡片會讓說明和任何要複製的值保持在畫面上，你也可以一邊操作，一邊在它的欄位中寫訊息給船員。
完成後，按「**交還控制**」。
卡片會消失，船員會繼續工作，而卡片欄位中留下的文字會隨著你的交還一起送出。

## 已登入的網站 {#signed-in-sites}

船員請你登入或建立帳號時，你登入的網站會保留在那台電腦自己的瀏覽器設定檔中。
登入適用於整個網站，所以在 example.com 獨立的登入網頁登入後，它的其他網頁（例如 developer.example.com）也能使用。
你按「**交還控制**」時，網頁上方會出現一個問題，詢問之後的任務可以怎麼做，例如「你的 example.com 登入會保留在這台電腦上。之後的任務：」：

- 「**直接使用，不必問我**」排在第一個，新網站會預先選取它。
  之後的任務會以已登入的狀態打開這個網站，不會出現卡片，而且每次都會在任務的「動態」中註明。
  它絕不涵蓋付款或最後的送出。
- 選擇「**每次都先問我**」時，之後需要這個網站的任務會在它的卡片上詢問，卡片會在「**我自己登入**」旁加上「**使用我的 example.com 登入**」。
  點一下，就能讓那項任務的瀏覽器以已登入的狀態使用這個網站，你不必輸入任何東西。

一條規則會套用到那台電腦上所有專案的任務。
使用已登入網站的瀏覽器，只會以登入狀態打開那個網站和登入過程經過的網頁；其他任何網站都會以登出狀態打開。
任務的瀏覽器自行停止或 App 重新啟動後，任務仍會保留它可以使用的已登入網站，直到你按「**停止瀏覽器**」或任務關閉。
你因為其他原因登入時，例如自己按了「**接手控制**」之後，登入通常只會維持到那個瀏覽器停止為止。
網頁下方的那一行會說明是哪一種，例如「暫時 · 會保留你登入的網站，直到瀏覽器停止」。

每台電腦都保留自己的登入，不會複製到其他電腦或檔案中。
它們保存在那台電腦的瀏覽器設定檔中，不在受保護的儲存空間中，所以安全程度和那台電腦本身的登入與磁碟一樣。

在你的大副所在的電腦上，清單位於設定 → 「**機密**」的「**已登入的網站**」下，每台電腦的網站列在它的名稱下方。
在從其他地方控制大副的電腦上，清單位於設定 → 「**一般**」的「**網站登入**」下。
每個網站都會顯示你登入的時間、它的「**之後的任務**」規則，以及「**移除**」；「移除」會立即讓那台電腦登出這個網站。
「**全部移除**」會讓那台電腦登出所有網站，包括從未加入清單的登入。

網站不時會自行結束登入，這時船員會再來問你。
如果保留的登入沒能讓網頁登入，下一張卡片會把「**我自己登入**」排在第一個，並保留「**使用我的登入（上次沒有成功）**」作為第二個選擇。

## 私人網站 {#private-sites}

你公司、家裡或 VPN 網路上的網站，要等你把它列入清單後才能連上。
船員需要這類網站時，大副會用一張卡片問你，例如「要讓任務瀏覽器連上 wiki.corp.example 嗎？」。
按「**允許**」加入它，或按「**暫時不要**」；大副絕不會自己加入網站。

清單位於設定 → 「**整合**」的「**私人網站**」下，會套用到你所有的電腦。

- 按「**網站**」，輸入名稱，例如 `wiki.corp.example`，然後按「**加入**」。
- 像 `.corp.example.com` 這樣的後綴，會涵蓋其下的每個名稱。
- 每個項目都是名稱，絕不是數字位址。
- 「**移除**」會把網站從清單中刪除，任務瀏覽器會立即停止連上它。

列入清單的網站可以透過 https 或 http、從任何網頁打開，就像一般的瀏覽器一樣。
它絕不會連到只在電腦內部監聽的程式。

## 購買和訂位由你決定 {#purchases-and-bookings-are-yours}

購買、訂位，或其他任何會讓你做出承諾的送出，都由你在網站自己的網頁上、在你的控制下完成。
船員會填寫到最後一個按鈕前，然後停在那裡。

接著，它會用一張審查卡片詢問你，卡片會寫出你要承諾的內容，並且是從網頁目前的狀態讀取的。
如果是一趟行程，內容包括路線、日期和時間、乘客、賣方、總金額和幣別，以及行李和票價規則。
卡片也會寫出任何仍不確定的地方，以及自你上次選擇以來有什麼改變。
它的按鈕會寫出你要做的步驟，例如「打開瀏覽器並付款」，旁邊還有一個像是「到此為止」的按鈕。

- 如果價格或條款在審查後有所改變，船員會停下來再問你一次。
- 你付款並交還控制後，船員會讀取網頁上顯示的結果，只保留結果本身，例如訂位代號。
  你輸入的卡片資料對它保持隱藏。
- 如果網頁沒有確認，船員會清楚說明它不知道是否已經完成。
  它絕不會再送出一次，並會先查看網站列出這類紀錄的地方，例如你的訂位紀錄，再來問你。
- 瀏覽器絕不會重複送出表單：重新載入回應過表單的網頁，不會再送出一次。

## 檔案和下載 {#files-and-downloads}

網頁下載的檔案，包括你在控制時下載的檔案，都會和任務的證據存在一起，任務的「動態」也會逐一註明。
網頁要求選擇檔案時，船員只能提供任務工作副本中的檔案。
它沒有的檔案就由你提供：它會用一張把瀏覽器交給你的卡片問你。

## 在你的其他電腦上 {#on-your-other-computers}

在你另一台電腦上執行的任務，瀏覽器就在那台電腦上。
你可以從任何視窗觀看它並接手控制，就像操作這台電腦上的瀏覽器一樣。
那台電腦會保留自己已登入的網站，[私人網站](#private-sites)清單在那裡同樣適用。
你在控制時，那裡要求選擇檔案的網頁會等待船員處理，因為 Infinitary 的檔案選擇器無法連到那台電腦。
請參閱[你的其他電腦](/zh-hant/your-other-computers/)。
