你的大副就是你在 Infinitary 裡說話的對象。
它畫在視窗正中央，負責帶領你的船員。

## 大副會做什麼 {#what-your-first-mate-does}

- 它會讀你的訊息，判斷需要的是什麼：一個回答、反問你一個問題，或是一份工作。
- 它自己能回答的問題，會直接在卡片上回答。
- 它會把工作變成任務，並為每項任務派一位船員開始。
- 它會追蹤每項任務，把你說的話轉告船員，並在工作完成時把它結束。
- 有事需要你做決定時，它會帶一張卡片給你。

## 它交給船員做的事 {#what-it-leaves-to-the-crew}

你的大副不會編輯你的檔案、讀你的程式碼，也不會在你的專案裡執行任何東西。
凡是需要你專案的檔案、需要建置，或需要查看哪裡出錯的事，都會交給船員。
每位船員都在你專案的專屬工作副本裡工作，所以你自己的檔案會維持原樣。
請參閱[任務與船員](/zh-hant/tasks-and-crewmates/)。

## 跟大副說話 {#talking-to-your-first-mate}

在視窗底部的訊息框輸入文字，然後送出。
你最近的兩則訊息和大副的簡短回覆會留在訊息框正上方。
你在卡片上給的回答也會顯示在那裡。
兩則當中比較早的那一則，過幾秒就會淡出。
點一下這幾行，就能閱讀[完整對話](#the-whole-conversation)。

有幾件事很有幫助：

- **從任何地方跳到訊息框。**
  按 ⌘L（Linux 上是 Ctrl+L）。
- **叫回你上一則訊息。**
  在空白的訊息框裡按 ↑。
- **貼上大量文字。**
  很長的貼上內容會在訊息框中變成一個檔案標籤，並完整地跟著你的訊息送出。

### 加入圖片和檔案 {#add-pictures-and-files}

把檔案拖到訊息框上，或按「**加入檔案**」。
圖片和文字檔會跟著你的訊息送出，各最多四個。
其他類型的檔案，例如 PDF，訊息框會以文字加入該檔案在你電腦上的位置，讓船員可以在那裡打開它。

### 用說的代替打字 {#talk-instead-of-typing}

按一下或按住聽寫鍵就能說話。
訊息框裡的提示會寫出是哪個鍵：「輸入文字，或按住右側 ⌥ 說話」。
在 Linux 上，這個鍵是右側的 Ctrl。
你說的話會在你的電腦上轉成文字，送出前你可以先編輯。
要更換按鍵或關閉聽寫，請使用[設定 → 一般](/zh-hant/settings/#general)中的「**聽寫**」。

### 在卡片上回答 {#answer-it-on-a-card}

大副或船員帶來卡片時，請直接在卡片上回答。
你在卡片下方輸入的內容，會送給寫這張卡片的人。
請參閱[卡片與決定](/zh-hant/cards-and-decisions/)。

### 完整對話 {#the-whole-conversation}

點一下訊息框上方的那幾行，就會打開 **對話** 卡片。
指令搜尋中的 **開啟對話** 也能打開它。

它讀起來像聊天紀錄，最早的在最上面，每一天有一行分隔：

- 你的訊息，以及大副的完整回覆；
- 你做過選擇的每張卡片，顯示成一個小方塊和你按下的按鈕；
- 你在卡片下方輸入的每一行，以及作者的第一則回答。

往上捲動可以閱讀更早的訊息。
這張卡片有兩種檢視，**全部** 和 **卡片**。
**卡片** 會先列出等你處理的卡片，再列出你回答過的卡片，最新的排在前面。
點一下卡片的小方塊，就能打開那張卡片。
你回答它或把它放到一旁之後，對話會回到你剛才讀到的地方。

對話開著時你送出的訊息會加進去，回覆隨後出現。
按 Escape 會收起對話。
打開和閱讀對話，不會讓大副知道任何事。

## 選擇它的模型 {#choosing-its-model}

你的大副會透過你的其中一個訂閱方案回應。
要選擇哪個模型，請打開設定 → 智慧等級，使用「**大副的模型**」。
「**自動（依訂閱方案）**」會讓 Infinitary 從你的訂閱方案提供的模型中挑選。
變更會在大副下一次閒置時生效。

如果你在同一個供應商有兩個帳號，這一列會顯示「**大副的模型和帳號**」，你也可以選擇帳號。
船員的工作可以優先使用另一個帳號：在該帳號的選單中使用「**優先用於船員工作**」。
請參閱[訂閱方案與額度](/zh-hant/subscriptions-and-quota/)。

如果大副使用的訂閱方案不再回應，例如你的方案額度已經用完，大副會顯示一張卡片，說明原因和你可以怎麼做。
這段期間你送出的訊息都會保留，等它能再回應時就會送出。

## 讓它的電腦保持開機 {#keep-its-computer-on}

你的大副住在一台電腦上。
你的手機和其他電腦都是連到那裡找它。
請把它設定在一台盡量保持開機的電腦上。

那台電腦進入睡眠，或那裡的 Infinitary 關閉時，大副就無法回應。
要在登入時打開 Infinitary，請在設定 → 一般中開啟「**登入時啟動**」。

要從其他地方找到你的大副，請參閱[你的其他電腦](/zh-hant/your-other-computers/)和 [iPhone 和 iPad](/zh-hant/iphone-and-ipad/)。
