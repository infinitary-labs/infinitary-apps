以下每個問題，都從 Infinitary 顯示給你的字詞開始。

## 訂閱方案需要你重新登入 {#a-subscription-needs-you-to-sign-in-again}

你可能會看到一張標題為「你的大副需要你重新登入」的卡片，或在設定 → **智慧等級** 裡看到某個訂閱方案顯示「重新登入」。
使用那個訂閱方案的工作會先等著：「工作已暫停，直到你重新登入。」

1. 按卡片上的 **登入**，或打開設定 → **智慧等級**。
2. 依照供應商的要求登入那個訂閱方案。
3. 等待中的工作會自動繼續。

在另一台電腦上執行的任務，使用的是那台電腦自己的登入，所以請在那台電腦的名稱底下，為它重新登入。

## 方案額度用完了 {#your-plans-allowance-ran-out}

你的大副會顯示一張標題為「你的大副已用完它的額度」的卡片。
回覆給使用那個訂閱方案的船員時，會顯示「已保存，尚未送出」，並附上額度重設的時間。
額度重設後，工作會自動繼續。

想早一點繼續：

- 如果你在供應商那邊改了什麼，按 **重新檢查額度**。
- 卡片提供其他供應商時，按 **移至** 另一個供應商。
- 請大副把工作移到另一個模型。

設定 → **智慧等級** 會顯示每個方案還剩多少額度，以及何時重設。
對於 Claude 和 Codex，**用點數繼續** 可以讓帳號用你在供應商那裡設定好的點數繼續工作。

## 大副沒有回答 {#your-first-mate-is-not-answering}

如果一則訊息沒有任何回音，會出現一張卡片寫著「你的大副還沒回答你的訊息」。
按 **再問一次** 再傳送一次，或按 **先這樣**。

如果是供應商本身沒有回答，卡片會寫著它「目前沒有回答你的大副」。
按 **再試一次 Claude**，或換成你供應商名稱的同一個按鈕，或按 **開啟設定** 改選另一個訂閱方案。
供應商出現短暫問題時，「動態」會說明，程式也會自己再試一次。

## 船員在等你 {#a-crewmate-is-waiting}

顯示 **等你處理** 的任務，有一張卡片在等你。
打開那項任務並按 **顯示卡片**，然後做決定。

任務上的其他字詞，會說明是什麼讓它停住：

- 「正在等待檢查」：它的船員正在等它的 pull request 上的檢查。
- 「正在供應商端重試」：供應商失敗了，程式會自己再試一次。
- 「卡在供應商端」：供應商連續三次拒絕同一個請求，大副正在決定該怎麼做。
- 「被另一項任務擋住」：那項任務完成後，它就會開始。

## pull request 的檢查未通過 {#the-checks-failed-on-a-pull-request}

檢查未通過時，建立那個 pull request 的船員會修正它們，並帶來新版本。
這時合併卡片會提供 **修正錯誤後合併**。
如果你按下它，你的合併會被保留：「你的合併正在等待修正：檢查未通過。」
修正的檢查通過後就會合併；如果修正改變了內容，船員會用新卡片再問你一次。

## 另一台電腦連絡不上 {#another-computer-is-out-of-reach}

另一台電腦上的視窗會顯示「在」那台電腦「回來之前無法進行變更。它可能正在睡眠，或在另一個網路上。」
或者：「Infinitary 已在」那台電腦「上關閉」。

1. 喚醒大副所在的電腦，並在那裡打開 Infinitary。
2. 讓兩台電腦連上同一個網路，或同一個私人網路。
3. 在設定 → **裝置** 裡，按它那一列的 **再試一次**。

如果你用位址加入的電腦換了新位址，請打開它的選單（在它那一列的三個點裡），選擇 **更改位址**。
在 Mac 上，macOS 可能會擋住 Infinitary 使用區域網路，直到有人在那台 Mac 上允許它。
這時它那一列會改為提供 **用位址加入**。
請看 [你的其他電腦](/zh-hant/your-other-computers/)。

## 同一台電腦列出了兩次 {#a-computer-is-listed-twice}

設定 → **裝置** 把同一個名稱顯示了兩次：一列連絡得上，另一列連絡不上，而且上面還有任務。
當一台執行工作的電腦在它保存的工作被刪除之後，或在那裡重新安裝 Infinitary 之後再次加入，就會發生這種情況。
連絡得上的那一列會寫著「同名同使用者的一個較早項目連絡不上」。

1. 在連絡得上的那一列，按 **在這裡繼續它的任務**。
2. 讀一下哪些會繼續、哪些會留下，然後按 **繼續這些任務**。
3. 每項任務都會從大副所在的電腦最後帶回來的那個提交繼續。
   每項任務都移走之後，較早的那一列就會從清單上消失。

在那之後的提交、還沒提交的編輯，以及舊任務資料夾裡的檔案，都會留在舊的項目上。
如果連絡不上的那一列沒有對應的項目，按 **把它的任務移到…**，再選擇一台電腦。
請看 [哪些情況會刪除你保存的工作](/zh-hant/update-and-remove/#what-deletes-your-saved-work)。

## 視窗沒有回應 {#the-window-stops-answering}

先等一下。
如果還是卡住，就結束 Infinitary 再重新打開。
大副或船員還沒處理完的訊息，會在它打開時重新接手。

## macOS 詢問其他 App 的資料 {#macos-asks-about-other-apps-data}

macOS 可能會詢問「"Infinitary" 想要取用其他 App 的資料。」
這是因為船員的搜尋碰到了另一個 App 保存的檔案。
Infinitary 的工作很少需要它們，所以按 **不允許** 通常沒問題。
在你回答之前，任務的紀錄會顯示它「正在等待 macOS」，之後搜尋就會繼續。

## 找不到 Claude Code {#claude-code-is-missing}

要使用 Claude 訂閱方案，請先在那台電腦上安裝 Claude Code。
沒有它的話，Infinitary 會顯示「這台電腦沒有安裝 Claude Code。安裝後才能在這裡使用 Claude。」
如果你的版本太舊，它會說出需要的版本，並告訴你執行 `claude update`。
在另一台電腦上，Claude Code 會自己在那裡登入：在那裡登入一次，Infinitary 就會使用那份登入。

## 還是卡住了 {#still-stuck}

請看 [取得協助](/zh-hant/get-help/)。
說明你做了什麼、你預期會發生什麼，以及實際發生了什麼。
