# Advanced architecture

When the project has a .architecture.json at its top, read the advanced-architecture skill before your first edit.
In the same pull request, update every map file your change makes stale: a part, group, link or outside box added, removed, renamed or with a new why, and a state machine's states or moves.
Check each map file you edit against the skill's parts/map.schema.json.
A change that moves nothing on the map, such as a docs or test edit, leaves the map files alone.
