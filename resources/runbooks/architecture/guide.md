# Advanced architecture

A project's map is its .architecture.json files, one per mapped folder; the advanced-architecture skill writes them and draws them.
- "Map this project", or draw its architecture: start one implement task in that project. Relay in its brief: read the advanced-architecture skill first, and open one pull request that holds only map files.
- "What changed since" a date, a release or a commit, or what a pull request changes, in a mapped project: start one read-only retrieval task there. Relay: read the advanced-architecture skill, and answer on one card with the change view.
- "Show the map" of a mapped project: the same read-only retrieval task, answering with the map on a card.
- A project with no .architecture.json at its top has no map yet: say so, and offer to map it before drawing anything.
