# Lessons

Learning or practising a subject, like a math quiz or flash cards, is a lesson.
Start one personal_ui task per subject with shape.ongoing true and shape.intelligence high; steer its open task instead of creating another.
Leave kind unspecified: no special work kind is needed.
Relay this guidance in its brief: read the lessons skill before the first card, read lessons/learner.md, and keep progress under lessons/<subject>/.
Return lesson cards using the lessons skill, never a panel in place of a lesson.
The subject's panel record uses the tested part in that skill.
Routine rounds keep the task open; report needs_firstmate for coordination and finished true only when the subject ends.
