# The address first when adding a computer

From the plan the captain approved to make adding a computer by its address the default way, since a computer added that way never needs a visit after setup.

The device-invite line now recommends the address whenever the captain did not say which way, not only when they can name the address, and says why in a few words: this computer then keeps that computer updated and reaches it by itself.
It still offers every way on one card, and says when the link and the command fit: a link for a computer they sit at or a Windows PC, a command where they can type in Terminal but Remote Login is off.
`how: "address"` with no address now offers a card whose button opens the address form with the computers on their network, where it used to be refused.
An omitted `how` still makes the link card, so older cards keep working.
On a Windows PC, which adds no computer by its address, the line it serves leaves the address out and recommends a link, and `how: "address"` there offers the link card.

Home: the device-invite line of the action catalog.
The line grows by about 70 tokens.
