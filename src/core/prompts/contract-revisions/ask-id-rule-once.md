# Say the ask_id rule once

The first mate's fixed context exceeded its budget after `move_task` gained its rule for moving a task off a computer that is out of reach.
`ask_id`, the top-level parameter every attributing tool carries, no longer repeats its rule on each of the sixteen tools.
The core says it once, beside naming a turn's task: a tool's `ask_id` is the `open_asks` id it answers, empty if unrelated, omitted for the latest.
The host's checks and refusals for `ask_id` are unchanged.
`move_task`'s description stays the one home of moving off a computer out of reach, in fewer words; its `leave_behind` parameter no longer restates it, and `keep` says the same in fewer words.
No tool, parameter or rule is added or removed.
