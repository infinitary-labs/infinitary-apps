# The first mate asks the captain to keep a secret

INF-4239, the captain's direction A on its plan: an agent asks for a secret by name, place and reason, and Infinitary draws its own masked field, so a value never reaches the agent, a card's page, its thread or the task record.
The first mate gains the tool `ask_secret`: it names each secret, an optional place, or the reference of a kept secret to replace, with a reason, and never a value.
It answers at once: waiting while Infinitary's own card asks, kept with each reference when every secret it names is already kept there, or unavailable with words.
When the ask ends, the first mate hears once, through the wake `secrets-ask-ended`, the references, names, places and versions kept, that the captain did not keep them, or that the ask was withdrawn.
`cancel` withdraws a waiting ask by its id.

Each rule has one home.
When to ask, and that the app raises the card so the first mate emits none, live in the `ask_secret` description.
What the ask's end says lives in its wake.
The refusal of an agent's own card that holds a password field lives in the card lint, which names `ask_secret` for the first mate and `infinitary-secrets-axi ask` for a crewmate.

The new tool costs the fixed part about 158 tokens by the app's count, most of them its parameters; with it the fixed part measures 19,870 against the 19,772 budget, under the hard line.
