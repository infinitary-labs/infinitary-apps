# Bounded fact retrieval

FI3-1238 implements the captain-approved FI3-1237 plan.
The built-in sequences guidance distinguishes a bounded lookup, extraction, factual summary or mechanical comparison of existing evidence from investigation, diagnosis and reproduction.
Firstmate keeps the captain's words verbatim, states the real question and source scope, carries the read-only constraint, and never chooses a kind, tier or model on that basis.
Any required non-retrieval work excludes the whole task; an uncertain ask is not broadened into an investigation by default.
The classifier owns the new `retrieval` verdict and R10 requests low, below the existing override, premium and escalation rules.
The served built-in skill is part of fixed context; its compact retrieval guidance costs about 100 tokens, while the prompt core and tool schemas stay unchanged.
The fixed-context ceiling moves from 19,600 to 19,700; the existing smallest-window conversation-space check still passes without a larger window or reduced conversation allowance.
