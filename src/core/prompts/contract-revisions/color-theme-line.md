# Color themes on the theme line

The first piece of an approved plan for color themes: a computer's window can wear a built-in color theme over Dark or Light, chosen in Settings → Appearance → Theme.
The theme action line now takes dark, light or a built-in theme's id, and lists each id with its maker's name; an unknown id is refused with the list of choices.
Its words say a theme changes colors only, that each computer's window keeps its own and that the phone keeps its own Theme setting; its current value names the chosen theme, or dark or light.
The line's one home is the theme action line; nothing else the first mate is served changes.
It adds about 150 tokens where action lines are served.
