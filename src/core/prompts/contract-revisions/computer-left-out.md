# An added computer Automatic leaves out is told once

INF-1456, from a person who added an Intel Mac mini beside an Apple-silicon MacBook and expected Automatic to use it.
Their project declared no computer requirements, so the chip was filled from the MacBook's own, and every task started on the MacBook with nothing said beyond one line in Task Details.
The captain chose direction A: keep the default, tell the Firstmate once, and fix it in one click; the Firstmate asks the captain once per project, on one card with the change as its default; the same fact covers an inherited system and a missing program or project access.
Automatic placement now carries each added computer a comparison left out for such a reason as a typed fact (`leftOut`), whichever computer took the task.
The new `computer-left-out` wake tells the Firstmate the computer, what it runs, the project, that the system or chip was inherited rather than declared, and, for an inherited one, the exact `app_change project-settings` change that lets it in, to propose on the app's exact-change card and never apply on its own judgment.
Its one home is that wake, sent once per project, computer and reasons.
The prompt and the tools are unchanged, so the fixed context does not grow.
