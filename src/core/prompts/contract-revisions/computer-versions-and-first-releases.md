# Running versions and first releases

INF-1607 implements finding 6 of the nightly product audit, which the captain chose to file.
The first mate's per-turn `computer_versions` facts name the home's running app and each paired device's live hello version, with disconnected or unsaid versions explicitly unknown.
`tasks` exposes each merged task's `first_release` and recorded merge commit without starting a worker; null means unknown.
The releasing crewmate's `report.first_release` owns verification and recording: every included merged task, including internal changes, gets its earliest verified release, page and source-membership evidence through the task owner.
That top-level report parameter is the rule's one home and reaches both runtimes; the first mate's fixed instructions and tools do not grow.
