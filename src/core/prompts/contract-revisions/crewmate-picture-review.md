# Crewmates inspect card pictures

FI3-1103 implements the every-user instruction fix from FI3-1101, whose captain chose File both fixes.
Every crewmate, on either backend and at every care level, opens each picture and demo poster with its image-reading tool before attaching it to a card.
It writes alt text from the file, retakes accidental mostly blank, half-drawn or cut-off captures, and names intentional examples as such.
When it cannot inspect the file, it leaves it off the card and reports the gap.
This judgment stays in the shared crewmate prompt; the host's format checks and the Firstmate's fixed context do not change.
The project's separate recorder fix belongs to FI3-1102.
