# Equal crewmate knowledge access

FI3-1672, the captain's Approve and build: every crewmate reads and writes factual knowledge equally, including tasks without projects, local, resumed and supported paired-computer sessions on both runtimes.
Task tools no longer offer a saving grant; existing `knowledge_access` metadata is inert.
The knowledge description says use it as needed, not first on every task; findings and sources are read before reliance, and standing directions still apply on every turn without a lookup.
All briefs and both runtimes' common crewmate instructions carry conditional saving guidance, superseding older grant or read-first requirements on resumption: save sources on request as concepts and sourced findings, reuse concepts, retain disagreements, ground personal context in the captain's words, and keep project behavior, investigations, progress, secrets and raw dumps elsewhere.
An optional publication lane distinguishes personal context from references as data, not access; revisions keep their category.
Finding authorship, source integrity, revision history, duplicates, removal and direction safeguards remain.
The fixed tool surface shrinks by removing grant parameters and their descriptions; the new category parameter and as-needed wording replace the old boundary wording, rather than adding a workflow.
