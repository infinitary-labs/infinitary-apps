# A /feedback message is a feedback request the first mate turns into a task

The approved /feedback plan, with the captain's answers: the person files with their own GitHub account, the first mate also suggests the command, and the build is careful.
A captain turn whose words start with `/feedback`, from the main message box, a card's reply or a task's crewmate tab, now carries one added line after the words, `FEEDBACK_REQUEST_NOTE` (a wake, `src/core/orchestrator/wakes.ts`): it names the message as a report for Infinitary's makers, to become a public issue after the captain reviews it, says to follow the Feedback runbook now, and says where the words were typed.
The built-in Feedback runbook's first-mate guide is the one home of what to do: start one feedback task at once with no card, pass the words verbatim with the context in the first mate's own words and no personal detail, answer in one line, relay the issue's number and link, and suggest `/feedback` when someone describes a problem with Infinitary itself.
The note costs about 70 tokens on a feedback turn only; the guide adds about 250 tokens to the served runbooks while the runbook is on.
