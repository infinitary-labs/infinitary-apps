# Files for the captain

The captain asked that a file handed to them always reach the computer they are using, and approved the plan in which a crewmate's card carries the file and the file moves only when the captain clicks Save.
A crewmate's card now carries files for the captain by reference, and each shows as a row with Save that saves into Downloads on the computer whose window was clicked.
The first mate is now told, in the context block's computers rule (its one home), that a report handing files meant for the captain goes back to its crewmate to put on its card's files, and never to start a task to copy them.
The rule appears only while another computer runs work, and adds about forty tokens there; the fixed context does not grow.
