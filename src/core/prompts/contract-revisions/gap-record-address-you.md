# Gap records address you

INF-877 builds the accepted INF-878 plan: the captain chose one open consent line with the recorded gap collapsed, left effect panels unchanged, and asked builders to address the gap to “you”.
The builder's brief is the rule's one home, in `CAREFUL_LIVE_VALIDATION`: write the gap record and its card directly to the captain as “you”, never “the captain”.
The Firstmate's fixed prompt and tools do not grow; its relayed Careful brief carries the same rule.
This changes instructions, not consent or the required-proof boundary.
