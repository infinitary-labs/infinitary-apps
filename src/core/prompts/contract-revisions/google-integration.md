# Google as an integration

INF-775 piece 5, built on its accepted plan (the captain's Approve and build, with q4 Infinitary's own Google client and q8 one Google row that signs in once for Gmail and Calendar, asking every permission up front).
The `app_change` line `integration-add` now names the kind `google` beside `github`, and refuses a kind this version of the app cannot sign in to, so the first mate offers Google only where the app has its own Google client.
Its handover opens Settings -> Integrations with Google's sign-in started, the way GitHub's is.
What Google can do reaches the first mate through the existing `integrations` and `use_integration` tools, from the binding's own action and event words, so no tool description changes.
The `schedule` refusal for an event it cannot read names `google/message_received` as its example, the event Google now tells.
The rule's one home is the catalog line; the line grows by a few words.
