# The first mate reaches integrations

INF-775 piece 1, built on its accepted plan (the captain's Approve and build, with q1 one command, q2 the GitHub sign-in moved to Integrations and q5 every change asks on a card).
The first mate holds two new tools: `integrations` lists what the captain connected outside his projects, or one integration's actions with each effect, rule and input schema, and `use_integration` runs one action.
A read runs; a change asks the captain, and from the first mate's seat a GitHub write is refused with a pointer to start a crewmate whose brief names the call, since only a crewmate's card can carry the exact write.
Its context block gains an `integrations` line naming each connected integration and who it is signed in as, and nothing when none is connected.
`app_state` and `app_change` gain the area `integrations`, with the lines `integration-add` (a handover to Settings -> Integrations), `integration-remove` (on the captain's own words), `integration-settings` and `integration-check`; `forge-sign-in` now names GitHub Enterprise and GitLab, since GitHub itself is `integration-add`.
Each rule's one home is the tool description it sits in, or the catalog line.
The two tools cost the fixed part about 250 tokens by the app's count; with them it measures 19,590, under the 19,772 boundary.
