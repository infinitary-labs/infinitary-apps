# Move task

INF-1713's accepted plan, which the captain narrowed to moving only ("this task is only about moving a task from one machine to another"), adds the move_task tool.
The tool's description is its one home: it moves started work to another computer that runs work, or to this Mac, at a safe pause, keeps its key, branch, uncommitted work, files and record, and continues in a new conversation there on the same model.
It moves only on the captain's ask, never to balance load, and cancel stops a move that has not started crossing.
The tool adds about 120 tokens to the fixed context.
