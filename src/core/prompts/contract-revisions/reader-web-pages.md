# An unsafe data reader reads public web pages

The third piece of the unsafe data reader's design: a reader task may now read public web pages through a typed web read, signed out, its words fenced as data from outside.

What the first mate is now told:

- `spawn_crewmate`'s `unsafe_data_reader` field no longer says the reader gets no web: it reads public web pages, and once it holds something of the captain's, each new address waits for the captain's click.

Home: the field's description on `spawn_crewmate`; no other text repeats it.
The host holds the rule itself: which addresses open at once, when the reader holds something, and the approval card a waiting address joins.
The fixed context grows by about fifteen tokens in that one field description.
