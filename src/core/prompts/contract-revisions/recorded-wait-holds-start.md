# A recorded wait holds the start, not the merge

INF-416 piece E, the captain's choice on the plan card: a wait the first mate records holds the start only.
`link_tasks` no longer says a blocks link on started work holds its merge.
A blocks edge still means `to` cannot start until `from` closes, and a cycle is still refused as text.
The close hold is a mark on the edge, set only by a must-merge-first filing, the host's review, and a required action's prerequisite.
The new words are shorter than the clause they replace, so the fixed part does not grow.
