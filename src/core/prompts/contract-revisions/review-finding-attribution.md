# Review findings name their review and builder

INF-63's accepted direction B adds the first mate's `review_task_id` parameter, whose one home is `CARD_PARAMS.review_task_id`.
It names the independent review the card relays; the host validates the link to `task_id`, persists it and draws Review finding and the task facts.
The review-findings wake owns the body instructions: title beginning Review of the builder's key, the change named first, then each finding's number, severity, file and reviewed version above the reviewer's verbatim words.
Every task-linked first mate card shows that task's title instead of the generic first mate metadata.
The parameter costs about 30 fixed-context tokens; the finding-body instructions live in the operational wake, not the fixed prompt.
No tool or card action is added.
