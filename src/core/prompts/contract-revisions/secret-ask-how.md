# The first mate says how to get a secret it asks for

INF-5516's plan for the card that asks the captain to save a secret, with the captain's written-in answer: the "How to get it" part is freeform, designed by the asker, guided by instructions toward a clear layout rather than one fixed shape.
`ask_secret` gains the optional top-level parameter `how`: an HTML fragment drawn on Infinitary's own card under "How to get it", such as numbered steps, a grid of exact names, a table or a folded section.
The host checks closed facts about it and draws it again from its parsed elements: only text, headings, paragraphs, lists, tables, details, code, kbd, mark and links, a class only from the frame's layout classes, and each link a safe address shown as its own text.
A refused how-to answers with words saying why, and nothing is asked.
The tool's description now also says to keep each name short and that a place only tells two secrets of one name apart.

Each rule has one home.
When to give `how` lives in the `ask_secret` description; what it may hold lives in the `how` parameter's own description.

The new parameter and words cost the fixed part about 72 tokens by the app's count; with them it measures 20,114 against the 19,772 budget, under the hard line.
