# A crewmate hears its secret run start

INF-7106, from INF-7080's session audit, finding 1: a crewmate told its Secrets request waits on the captain heard nothing more until the program ended, so it kept waiting after the captain allowed the run, and the first mate was told the task waited on the captain with no card up.
A crewmate whose request answered waiting is now told once, with the new crewmate `secrets-use-started` wake, when the captain's approval starts the program: the request, that it no longer waits on the captain, and that its end arrives as a receipt; like the end, it grants no other use or external action.
It goes when the program has started, never at the click, and always before the end; a run a saved decision starts at once sends none, since its first answer already says it runs.
The `secrets-use-ended` wake gains one sentence, sent only for a use the app's close cut off, which the crewmate now hears as Secrets opens again rather than at its next status read.
Each rule's one home is its wake. The prompt and the tools are unchanged, so the fixed context does not grow.
