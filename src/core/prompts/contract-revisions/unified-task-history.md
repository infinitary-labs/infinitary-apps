# One retained task history

An ordinary by-key tasks read keeps the existing focused reports, decisions, brief and sessions reads without loading the timeline.
Only an explicit `field: "timeline"` request includes the common timeline and its exact typed source records; a placed crewmate carries that selection to the home in its work request.
History is read-only: an earlier offer, choice or effect receipt grants no permission and never repeats an action.
Unknown older times and authors remain unknown, and an unavailable source is never replaced with the current card or conversation.
