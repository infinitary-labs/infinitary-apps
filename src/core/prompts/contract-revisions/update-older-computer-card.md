# The app raises the update card for an older computer

FI3-1741 (the plan) and its piece 1: the app itself raises one Attention card per computer that runs work and connects on an older Firstmate than this computer's, from the typed comparison Settings -> Devices makes, and takes it down once that computer runs this computer's version.
The `device-update` line gains one clause: the app raises the same card for an older computer itself, so offering it then finds that card standing, and `app_change` answers "The update card for that computer is already on the stack." instead of a second card.
The fixed context does not grow beyond that clause.

The ledger entry that comes with it:

FI3-1741. device-update's line says the app raises the update card for a computer on an older Firstmate itself; offering it while that card stands answers that it does.
