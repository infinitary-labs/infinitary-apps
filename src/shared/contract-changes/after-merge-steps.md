# After-merge steps

A card, a past card and a card's offer may carry `afterMerge`: the steps its saved story lists for the crew to start once the merge goes through (INF-2796), each as the card draws it - a title, an optional goal, an existing task's optional key and the keys it waits for (`waitsFor`).
A saved change story, and the story a computer that runs work stages for its home, may carry an optional `afterMerge` list of the steps as written: a new task's title, goal and why, or an existing task's key (`task`), with an optional project (`project`) and the tasks it waits for (`blockedBy`).
An older view ignores the field and draws no after-merge steps.
An older home refuses a staged story that lists them, so its crewmate prepares the story again without them.
