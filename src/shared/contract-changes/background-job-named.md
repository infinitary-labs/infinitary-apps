# Background job named

A computer that runs work adds an optional `job` to a Pi conversation's `background_work_changed` event while its count is above zero: the longest-running shell job's id and command, sent again when that job changes.
The home's check-back ask, the job bound's wake, a timed wait's end and the crew line name that command instead of a stand-in.
An older home ignores the field and keeps its count; from a computer that sends none, the home names the work by that computer's name.
