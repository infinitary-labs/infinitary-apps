# The care a card's button sets

A card action takes an optional `care`: the care the captain's click sets on the card's task before the choice returns to its author (`docs/delivery-rigor.md`, "Raising care from a merge card").
Only the home adds it, to a merge card's Review carefully button, and only the home runs it, on the captain's click.
An older view strips the field and draws the button as an ordinary choice; its click still reaches the home, which sets the care.
