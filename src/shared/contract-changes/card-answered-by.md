# A card names who answers a reply under it

A card in the cards snapshot admits an optional `answeredBy`, "firstmate" on the host's stuck alert (`card-stall-<task>`, INF-1670), so a view draws a reply row on it and the first mate answers the reply.
An older view ignores the field and draws the stuck alert with no reply row, as before.
An older home sends no `answeredBy`, so its stuck alert takes no reply.
