A card's script may read a data file its card names, such as a map's data, which the home keeps beside the card's pictures and answers by its minted name with `inf:cards:data`.
A computer that runs work sends a card that names a data file only to a home that lists this change, sending the file first as a card's media, and otherwise refuses it before sending anything.
A view or a phone without the change shows the card with its script unable to read the file.
