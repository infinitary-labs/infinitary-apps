Adds an optional `files` field to a card (`Card.files`) and to the card a computer that runs work sends with `inf:work:card`: files for the captain, each by its name, size, sha256 and where its kept copy is, never the bytes.
Adds the request `inf:cards:file`, which reads a piece of a card's file for the window whose Save the captain clicked, wherever the kept copy is.
A home without the change drops `files` from a work card, so a computer that runs work refuses a card naming files to that home in words instead.
A view without the change ignores `files` and draws no Save row.
