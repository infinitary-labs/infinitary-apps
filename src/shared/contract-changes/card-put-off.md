# Card put-off

A card action may carry `until`: a put-off choice ("Not until…") that names a task's close, a time, an event an Automation rule can wait for, or the captain's word.
The home keeps the card when the captain clicks it and an Automation rule raises the same card again when that comes true.
A crewmate on a computer that runs work sends `until` only to a home that lists this change, and is refused otherwise, so no put-off is dropped on the way.
An older view shows the choice as an ordinary button, and its click reaches the home as any choice does.
