# Changes by name in the hello and the welcome

The hello and the welcome carry an optional `changes`: the name of each minor change this build has, one per file in this folder but the major's (`docs/connection.md`, "The handshake and the numbering").
The home keeps what a computer that runs work listed beside its version (`WorkDeviceVersion`), and a computer keeps what its home listed (`HomeLinkState.homeChanges`).
A side built before changes had names lists nothing, so the other side gives it no feature that waits for a name.
