`inf:working-copy:status` adds the optional `dirty` to `checkedOut`: whether work is left to commit at that checkout, untracked files included whatever the repository's settings, read in the same answer as the branch and the commit.
A home binds a held batch's declared fix to the commit of a task placed on another computer only when that answer says nothing is left to commit there.
A computer without the change sends no `dirty` there, and the home then binds no commit to that task's declaration.
