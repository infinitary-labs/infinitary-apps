`inf:working-copy:status` adds the optional `renamedFrom` to `checkedOut`: the names the checked-out branch had before, oldest first, as its own log records each rename, at most 32.
A home refuses to publish a branch renamed from its task's own branch in a project that merges in batches, since only the task's own branch joins its batch.
A computer without the change sends no `renamedFrom`, and the home then refuses nothing for that task's branch.
