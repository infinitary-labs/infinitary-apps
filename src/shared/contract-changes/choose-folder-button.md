# A Choose folder button on a card

An open effect with target `projects` may carry `folder: true` (docs/fleet.md, "A folder that is not there").
A window on the first mate's own computer then opens the system's folder picker, adds the folder picked as a project as Settings -> Projects does, and only then sends the click.
A view, or a window from before, ignores the flag and opens Settings -> Projects as an open effect with target `projects` always did.
