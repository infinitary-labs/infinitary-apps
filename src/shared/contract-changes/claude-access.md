An account adds optional `access`: where a Claude account's access comes from when it is a token command and address set up for Claude Code, by an organization or in the person's own Claude Code settings, rather than a Claude subscription sign-in.
The account row reads it to name the access in place of a plan, and to offer Try again in place of Sign in when that access was refused.
An account also adds optional `gateway`: who set the address a Claude subscription's requests go to when Claude Code's settings name an address and no token command; the row names it after the plan.
An older view ignores both fields and shows the row as before; an older home omits them.
