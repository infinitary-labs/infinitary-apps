# Durable crewmate responses

A work report may declare individually correlated responses with request identity, response identity and answered or not-yet-answered status.
The home saves the exact response and its first mate inbox row together at submission, independently of ordinary turn reports.
A first mate steer expects a response by default, with an explicit guidance-only exception; dispatch briefs and host operational wakes keep their meanings.
The home sends tracked requests only to a work computer advertising this change, and a work computer refuses response submissions to a home without it rather than silently dropping their correlation.
