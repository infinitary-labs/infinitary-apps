A new `inf:work:start-program` order lets a crewmate on a computer that runs work start a program from its task, or raise the bound of one it started or stop it, answered at the home as tool text.
A computer serves its crewmates the `start_program` tool only when its home lists this change; with an older home the call is refused with nothing sent.
An older computer has no such tool, so its crewmates start no programs.
