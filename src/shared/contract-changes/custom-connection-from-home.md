Adds the order `inf:sign-ins:custom-definitions`, which sends a computer that runs work what each of the home's custom connections it approved one of its own from says now, with no key or secret header value.
Adds the optional `home` field to a custom connection's input and view, naming the home's connection it follows, and an optional `customFromHome` field to each computer of `inf:devices:sign-ins`, saying it takes the order.
A computer without the change is never sent the order, and the home's connections offer no Use on it.
A home without the change never says `customFromHome`, so a view offers no Use on any computer.
