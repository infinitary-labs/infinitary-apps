# A Mac's window folds its two entries into one

A new request, `inf:devices:fold`, which only a paired view asks, as the device it connected as.
A Mac's window that holds one entry on its home's list while that Mac's work runs as another asks the home to fold its own entry into the work's, proving it holds that entry's key with a signature.
The home keeps the work's entry, moves to it every project and unstarted task that ran on the window's, removes the window's entry and says so once in the feed.
A home from before does not list this change, so a window never asks it there, and both entries stay as they were.
