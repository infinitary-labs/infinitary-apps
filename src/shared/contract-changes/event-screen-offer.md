A card button may carry the new host operation `turn-on-event-screen`, whose argument is the version of the Screen automation events disclosure the card showed.
The home raises it on one card when an automation with an Only if condition is saved or turned on while that screen is off.
A view that lists this change draws the card's Turn on button and sends it as any card choice.
A view without it is sent the card with Not now alone, and its words name Settings → Intelligence → Decisions, where the screen turns on.
