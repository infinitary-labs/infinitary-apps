# The first crewmate's note in the first-run record

The first-run record that `inf:app:first-run` and `inf:app:first-run:crew-word` answer adds two optional fields: `firstCrewmateAt`, when a new person's first crewmate started, and `firstCrewmateNoteId`, the note that start presented.
A view from before ignores both, and the note itself reaches it as an ordinary first-mate note.
