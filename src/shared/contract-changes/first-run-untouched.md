# The first launch says whether nothing was done here

The first-run view (`inf:app:first-run`, `firstRunViewSchema`) adds `untouched: true` while the gate is up and nothing was done on this computer: no turn, no saved sign-in or connection, and no ask, task, card or project.
The window opened beside a first mate follows along when another computer adds it by its address only while that first mate answers `untouched`.
A first mate from before has no field of that name, so a window beside it never follows along and keeps its own first launch.
