# GitLab and GitHub Enterprise integrations

The home integrations view admits `gitlab` and `github-enterprise`, each with many per-host connections and an optional `host` naming the existing forge sign-in its row manages.
Like the Google addition, the view is home-only and an older paired view receives its push unchecked; no paired Settings view asks to sign in.
The existing computer integration relay carries discovery and calls as open records and words, so the new bindings need no new relay request or credential transfer.
