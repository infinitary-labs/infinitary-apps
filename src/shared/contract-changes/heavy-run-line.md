# Heavy-run admission

The `inf:computer:load` order carries the home's recorded heavy-run overrides to a work computer and returns its declared runs and their admission state, without process identifiers or command arguments.
The `computers.resources` view optionally carries each computer's line reading alongside its resource reading; an unknown line reading marks last-known runs as unavailable, never ended.
An older computer that does not list `heavy-run-line` receives no new order and shows no line reading.
The iPhone and iPad app keeps its existing surface and ignores the additional optional facts.
