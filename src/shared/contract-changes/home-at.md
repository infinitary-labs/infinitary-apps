# Setting the first mate up on another computer from the welcome screen

`inf:devices:home-at` is one step of setting the first mate up on another computer over the person's own SSH, from the welcome screen's Another computer: its key line, the password once, the question before making an account named infinitary after a root sign-in, the offer to connect where Infinitary already runs, a stop at a step, or the first mate started there.
`inf:devices:home-at-cancel` stops the setup under way at an address at its next step.
Both are new requests only this computer asks of its own first mate; a first mate without this change does not answer them, and a window beside one keeps the commands that set it up there.
