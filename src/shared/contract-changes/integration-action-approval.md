# Per-action integration approval

The captain-only `inf:integrations:rule` changes one action between Asks you and Always allowed; Off remains the existing switch.
`inf:work:use-integration` adds an optional reason, and the task command carries it with `--reason`.
The home refuses an unapproved action without a reason; an older computer can still list the action but must update to supply a reason and ask for access.
The optional `integration` field on `request_write` names the host card's Always allow, Only this time or Not now choice, with the exact call kept on its task.
Older homes never emit these host cards; older cards without the field keep their existing once-only behavior.
