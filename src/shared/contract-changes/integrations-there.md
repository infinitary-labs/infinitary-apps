# Integrations there

A computer that runs work gives its crewmates `infinitary-integrations-axi`, and asks the home two new work requests for it: `inf:work:integrations`, its list and show, and `inf:work:use-integration`, its call (`docs/integrations.md`, "On a computer that runs work").
The placed spec carries a new optional `integrations`, which the home sends only to a computer that lists this change.
A computer without it gets no command and no line for it in its crewmates' instructions, and a home without it never sends the field.
