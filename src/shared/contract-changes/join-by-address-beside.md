# Join by its address beside a command

The new request `inf:devices:link-at` is one step of Join by its address asked of the first mate a command runs, by the window opened beside it on the same computer: that first mate signs in to the other computer with this account's SSH and answers the key line, the password question, a refusal, or the one-use link with the host SSH reached (`linkAtAnswerSchema`, `src/shared/joinByAddress.ts`).
It stays on the computer where the first mate lives (`reach: "home"`), and only the window's own program asks it, never its page or `infinitary-axi`.
A window asks it only of a first mate that lists this change; beside one from before, Join by its address says it could not ask that computer for a link, as it did before.
