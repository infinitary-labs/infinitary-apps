# Join by its address names where it could not reach

`inf:devices:link-at` takes the option `reach: true`, and then an `unreachable` refusal in its answer may carry `reach`, the step and port it stopped at (`RemoteLoginReach`, read strictly in `src/shared/joinByAddress.ts`), so Join by its address says it as adding a computer by its address does.
A window asks with the option only of a first mate that lists this change, and a first mate answers `reach` only when asked, so neither side reads a field it does not know.
A window beside a first mate from before gets no `reach` and says the bare "Could not reach" lines, as before.
