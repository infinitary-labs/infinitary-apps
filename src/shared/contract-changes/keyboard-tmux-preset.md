The saved keys that `inf:settings:keys:get` answers and `inf:settings:keys:set` takes may name the `tmux` preset, and may carry an optional `prefix`, the one key every Tmux key starts with once a person changed it from Ctrl+B.
An older side refuses a saved value that names `tmux` or carries `prefix`.
A new member of a closed set would be major by the version rule, but only the computer's own window asks these two requests, and when its read fails it keeps the keys it last had (`besideWindow.readTheirs`), so the change stays minor.
