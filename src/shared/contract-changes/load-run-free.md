A run in a computer's load line gains the optional `free`: for the run first in line that waits for room, the processors and memory the line had to give when it last compared.
A run's `ahead` now counts only the runs waiting before it in the line, so the run first in line reads 0.
A home without this change reads a run without `free` and shows how many runs are ahead, as before.
A computer without this change sends no `free`, so its home shows how many runs are ahead, as before.
