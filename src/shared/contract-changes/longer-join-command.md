# Longer join command

`inf:devices:invite`'s answer may carry a command of up to 131,072 characters, the longest word Linux lets a program take, where it carried up to 16,384.
The command for another computer holds the Linux install and every address a link names, so with a long computer name it outgrew the old bound.
Only the home's own window asks for an invitation, and it is always that home's own version, so no older side reads the longer answer.
