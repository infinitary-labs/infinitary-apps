# Major 14: one merge effect

A card action's effect gains the `merge` kind, the one way to merge a pull request or branch (INF-2744): `after` says what follows (`close` or `continue`), with an optional `review`, `asksFirst` and `proceedWithOpen`.
The `settle` effect keeps only `discard`, and the `request_merge` kind is gone; saved cards that carried either convert once to `merge`.
A report's declared fields no longer carry `mergeCompletesTask`: the open merge card's `after: close` is that declaration.
This is a new member of a closed set and a removed member and field, so every computer taking work must run this major.
