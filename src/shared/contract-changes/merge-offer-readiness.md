# Readiness expressed by the merge offer

A merge offer itself expresses the crew's judgment; no separate ready/red declaration or current verdict field is produced.
The draft check-declaration request carries only flake and settlement judgments, while older ready/red ledger entries remain readable history and never grant authority.
Task check snapshots add an optional `problem` string explaining why part of the reading could not be obtained.
Actual check facts, exact-version captain consent and send-once effects remain separate.
Paired computers wait for this named change before running the current check/offer protocol, rather than silently applying an older readiness policy.
