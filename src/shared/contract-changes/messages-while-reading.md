A home answers a paired view's plain-text message to the first mate, `inf:converse` with one string, while the version rule lets that view only read (`READ_ONLY_ASKS`, `src/shared/contractFeatures.ts`).
Every other change, a message with pictures, files or hints among them, is still refused outside the window.
A view keeps its message box on while it reads only from a home that lists this change, or from a home on a newer major than its own, and sends such a home only the plain string.
A view on a newer major than its home reads the change only by its name, so the major that folds this name in adds its number beside `READ_ONLY_ASKS` for its views to read an older home by.
An older home refuses the message as a change, so a view keeps its box off for a home that does not list this change.
