# A folder dropped on the message box

`inf:repos:offer-folder` takes the path of a folder the captain dropped on the main message box (docs/composer.md, "Files").
The first mate's computer puts up the project setup card for it with Add project, as the first mate's proposal does, and answers the card's id, or the name of the project the folder already is.
Only the first mate's own window asks it, since the path is on that computer; a window from before keeps refusing a dropped folder with a notice.
