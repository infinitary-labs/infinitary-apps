A first mate a command started asks this computer's own window for what only a program in the person's session can do: the push `inf:own-window:ask` is new, and the window answers it with the new request `inf:own-window:answer`.
The window says it is open with the new request `inf:own-window:here`, tells the first mate it came to the front with `inf:own-window:focused`, and that dictation's microphone step is done with `inf:voice:primed`.
The new requests `inf:settings:keys:get` and `inf:settings:keys:set` read and change the keys the first mate keeps, `inf:runbooks:folder` names a runbook folder for the window to open, and `inf:update:hold` keeps the crew's work saved while the window installs an update.
The new push `inf:presence:dock` tells the window the first mate's Show in Dock choice.
Every one of these requests has `reach` `home`: only the window on the first mate's own computer asks them, and a paired view is refused.
A first mate without this change refuses them, and its window keeps the look, the keys and the Dock choice it last read.
