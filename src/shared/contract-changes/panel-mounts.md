# The window's answer about its panels

`inf:plugins:personal:mounts` is a new request, from this Mac's own window alone: for every panel the window knows, by its kind and id, whether it drew it and, when it did not, why (`docs/personal-panels.md`, "Placed on the rail").
A crewmate's `place_panel` waits on it and the first mate's surfaces list reads it.
An older window never sends it, and the core then says "no word from the window" for every panel, never drawn.
