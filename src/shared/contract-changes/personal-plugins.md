A home's personal set also carries the skills of the person's turned-on Claude Code plugins, each plugin under `.claude/plugins/<plugin id>/` with its manifest and its own files but none of its hooks, MCP servers, agents, commands or other parts (docs/personal-resources.md, "Claude Code plugins").
A computer with this change keeps those files and serves their skills to the home's crew.
A home sends them only to a computer that lists this change; a computer without it is sent the set without them, and keeps and serves it as before.
A home without this change sends no plugin files, and a computer with it serves no plugin skills for that home.
