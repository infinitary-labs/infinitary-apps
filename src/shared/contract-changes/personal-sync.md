A home sends a computer that runs work its personal instructions and skills, whole, by the new order `inf:session:personal`, only when its set changed and never with a task (docs/personal-resources.md, "One set, kept on each computer").
The roster's new optional `personal` and a conversation state's new optional `personal` name the version that computer keeps, and the version a conversation read when it opened.
A computer with this change, working for a home that lists it, reads only the kept set for that home's crew and never its own user's files.
A home without this change sends nothing, and the computer reads its own user's files as before; a computer without it is sent nothing, and reads its own.
The task detail's new optional `personal` names the version the task's newest conversation read, for the record's Info tab.
