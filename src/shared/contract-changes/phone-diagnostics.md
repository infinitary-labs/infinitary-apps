A paired phone may hand its computer one of its own usage events with the new `inf:settings:sharing:phone` request, a change any view may ask.
The computer keeps it only while its own Diagnostics would send, under an install ID it keeps for that phone, and answers null either way.
The sharing view's Diagnostics row gains `phones`, each paired phone's install ID and first-run steps, and a waiting event may name its phone and the phone's version.
An older computer does not list this change, so a phone sends it nothing; an older view never asks it and reads past the new fields.
