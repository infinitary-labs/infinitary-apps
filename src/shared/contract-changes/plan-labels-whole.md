# A plan keeps its crewmate's words

A plan item's `label` and `short` in `inf:tasks:detail` carry no length limit: a plan keeps the words its crewmate wrote, and each surface cuts what it cannot show (`docs/task-record.md`).
Nothing a client reads changes meaning, so an older side shows the longer words as it shows any other; a client that checks a response against an older published file may see a label longer than that file allowed.
