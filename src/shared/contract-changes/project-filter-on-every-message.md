# The project filter on every message

`inf:converse` takes a new optional field, `allProjects`, true while the window shows the project pill with All projects picked.
`inf:cards:reply`'s object takes two new optional fields, `focusedProjectId` and `allProjects`, the window's project filter as `inf:converse` carries it.
An older home drops the new fields, so its first mate hears All projects as no filter and a reply under its card without one, as before.
