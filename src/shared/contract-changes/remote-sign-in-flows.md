The computer sign-ins view adds optional `flows`, the home's complete current sign-in states, including each prompt, notice, link and terminal failure.
Settings reads these states again after step notifications instead of reconstructing a flow from events.
An older view ignores this addition; an older home omits it.
A newer view keeps account, allowance, custom-connection and project-host management rows while disabling only provider and forge sign-in starts, including pending-card starts, with an update message beside them.
