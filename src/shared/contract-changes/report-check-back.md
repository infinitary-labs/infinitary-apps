# A report names a check-back

The `inf:work:report` order's `declared` admits an optional `checkBack`: the minutes until a crewmate on a computer that runs work looks at its running job again, and what it waits for (INF-1244).
The home keeps it as the task's timed wait, whose end steers the crewmate with the job's facts, as it does for a crewmate on the home itself.
An older home drops the field, so the report counts as before and the job's bound alone wakes anyone.
An older computer never sends it, so nothing changes for its crewmates.
