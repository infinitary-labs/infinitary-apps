# Runbook switches and crew skills

Adds inf:settings:runbooks:get and inf:settings:runbooks:set, shared by Settings and the first mate's runbook catalog action.
Adds optional runbookSkills plain-file payloads to the work session specification so the computer opening a crew session stages its own third skill root.
An older view has no switches.
A task carrying runbook skills waits for a work computer to confirm this named change before its session opens; no home-computer path is handed to an older computer.
