An entry of the Secrets view may carry the new optional `forProgram`, beside `kept`, for a key an app service keeps for a program it starts, such as an MCP server's key.
A view that reads it says the server gets the key each time it starts, without asking.
An older view ignores it and shows such a key as kept for a sign-in, with Manage in Integrations.
A use in the view's history may carry the new optional `given`, for a start the key given with the program covered, with no `approval`.
A view that reads it shows Added with the program; an older view shows the use with no approval words.
