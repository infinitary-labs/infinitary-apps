# A crewmate's mark on a saved sign-in that did not work

A crewmate card's `browserHandoff` carries optional `savedFailed`, the crewmate's word that the saved sign-in its browser was given did not sign the page in.
It rides a placed crewmate's card to the home, which marks the save it lent or made for that browser.
A home without the change drops the field, so the save stays unmarked and the next request card leads with the saved sign-in as before.
