# A window says whether someone is at its computer

A window in a program of its own asks `inf:window:someone-here` with one flag: whether someone is at its computer, at each change and again at each welcome (docs/phone-push.md, "When the computer sends").
The window opened beside a first mate a command started asks it on its own connection, and a view on another Mac on its link.
The first mate keeps each connection's latest word until that connection drops, and holds a card's push to a phone while one says someone is there, sending it once none does.
The first mate pushes `inf:window:captain-on-phone`, an empty object, when the captain's own input comes from a paired phone or iPad, and each window's program untouched in the 10 seconds before says nobody is at its computer until its next touch.
A window from before the change never asks it and says only `inf:window:front`, whose true holds a card's push until it says false or drops.
A view does not ask a home that does not list this change, and a home from before never pushes `inf:window:captain-on-phone`.
