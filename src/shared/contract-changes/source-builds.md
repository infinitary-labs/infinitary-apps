A computer that runs work says the build it runs in its hello, as `build`: a release's commit, or a run from source's commit, whether it was edited and its lockfile's digest.
A home with the change compares builds by commit when it runs from source, and by version between two releases as before.
A Mac that runs work answers the order `inf:source:build` with a commit: it gets the home's committed source at `/infinitary-source` with its own key, installs its packages, builds it and has its background run Electron from that folder, going back to the copy before should the build not reach the home.
While it runs, `fm:firstmate:update-progress` says `fetching`, `installing` or `building`, which a home without the change reads as under way.
A home without the change ignores `build` and never asks the order; a computer without it is never sent source, and keeps today's updates.
