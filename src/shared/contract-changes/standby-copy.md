# Keeping a copy on another computer

A home can keep a live copy of its record on any number of paired computers that run work (docs/devices.md, "Keeping a copy on another computer").
The orders `inf:standby:hello`, `inf:standby:piece`, `inf:standby:lacks`, `inf:standby:full`, `inf:standby:apply` and `inf:standby:drop` are asked of a computer the captain named to keep a copy.
A home asks them only of a computer whose hello lists this change, and Settings, Devices says a computer from before needs an update.
A view asks `inf:standby:list`, `inf:standby:name` and `inf:standby:ready`, and hears `inf:standby:views`; a home from before answers none of them, and a view from before shows no copy.
