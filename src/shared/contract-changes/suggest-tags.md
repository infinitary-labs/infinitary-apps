# Suggest tags for a project with none

Adds `inf:projects:suggest-tags`, which sends the person's words to the first mate as their own message, with a note about the project because of the press, and answers why it sent nothing: no such project, a removed one, one that has a tag already, or a home still starting.
An older window never sends it, so it draws no Suggest tags; against an older home the request answers an unknown channel, and the window says the first mate could not be asked.
