# Check existing tasks for tags

Adds `inf:projects:tag-checks`, which reads, for one project or every project with tags, whether Tag tasks automatically asks now, who answers, how many requests each reach of Check existing tasks would make and the check under way, and `inf:projects:tag-check`, which starts or stops that check.
Adds the `tags` use to the decision model's uses, which an older side lists by the name and words the home sends.
An older side never sends either request, so it draws no Check existing tasks and behaves as before.
