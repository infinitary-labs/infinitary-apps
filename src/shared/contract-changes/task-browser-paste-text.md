# Task browser paste text

The captain's key input to a task's page (`inf:browser:input`, and the `inf:task-browser:input` order to a computer that runs work) accepts optional `clipboard` with a paste, the words on the clipboard of the computer where the captain pressed it.
The computer that runs the page types those words when its own clipboard holds other words, so a paste reaches a page that runs on another computer.
An older side drops the field, and the page pastes from its own computer's clipboard, as before.
