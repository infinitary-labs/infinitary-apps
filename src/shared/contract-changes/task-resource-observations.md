Resource observations add optional process counts, per-task process-tree shares and unclaimed process use, with cumulative processor-time deltas and resident bytes.
Memory observations add optional swap occupancy.
Older computers omit the additions and continue to supply CPU and memory readings; older readers ignore the optional facts.
The existing firstmate_note event adds an optional info-or-warn tone for task-less host notices; older views still receive its text and ignore the new tone.
