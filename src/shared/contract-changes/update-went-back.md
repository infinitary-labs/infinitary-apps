A computer that runs work may say `failedUpdate: true` in its hello.
It says it after it went back to the copy it kept, because the copy an update brought did not reach the home, and until the home has heard it.
The copy that did not start is the one the home sent, so the home's own version names it.
A home with the change names that version once in its feed and does not send it to that computer again.
A home without it ignores the field, and may send the same version again.
