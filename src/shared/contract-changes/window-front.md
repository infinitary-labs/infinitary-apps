# A window says whether it is in front

A window in a program of its own asks `inf:window:front` with one flag: true when it comes to the front, false when it leaves it (docs/phone-push.md, "When the computer sends").
The window opened beside a first mate a command started asks it on its own connection, and a view on another Mac on its link.
The first mate keeps each connection's latest word until that connection drops, and pushes no card to a phone while one says it is in front.
A view does not ask a home that does not list this change, and a home from before refuses it, so its phone hears every card as before.
