# A Windows PC runs work

A Windows PC that joins with its window, sending `system: "windows"`, is paired as a Mac is: a computer that controls the first mate and runs its work.
Its work mode says its user by `sid` in its pair request, as its window does.
A home from before pairs that PC as a device that only controls, and the PC then runs no work for it, as before.
A home on this change sends a Windows PC no update order, since no build for it is published, and its Devices row says to install the newer Infinitary on that PC.
A Windows PC that joined a home from before as a device that only controls stays one, and joins again with a new link to run work.
Its answer to the placement order (`inf:computer:placement`) names its system `windows`, a member only that order's answer has, which a project still cannot declare.
A home from before never asks a Windows PC that order, since it pairs that PC as a device that only controls.
