# A Windows PC joins as a window

The pair request's `user` may carry `sid`, a Windows security identifier, in place of `uid`, since Windows gives a user no number.
A user's name may hold a space inside it, as a Windows user name can, such as `Kun Chen`.
A Windows PC that joins with its window sends `system: "windows"`, and the home lists it as a device that only controls, since a Windows PC runs no work yet.
A home from before refuses a request with `sid` as malformed, as it refused a Windows PC's join before.
Where devices find a Windows home now carries `windowsFirewall`: the port, the program and the network profiles where Windows Defender Firewall may keep devices out, and whether a rule blocks the app or the profile blocks every incoming connection.
A view from before has no field of that name and shows no firewall line for a Windows home.
